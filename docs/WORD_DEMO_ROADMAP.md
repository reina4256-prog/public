# 新方式Steam体験版の残作業とチャット単位の進行

更新: 2026-09-25

## 位置付け

現在は一部実装。既存島・BGM、六職の初歩の手伝い、限定的な作業語学習と会話、空腹・体力表示、専用保存が土台としてある。以下は残作業を管理する実施順の案であり、未決定の仕様を採用済みに変えるものではない。内容仕様の正本は [experimental_word_learning.md](specs/core/experimental_word_learning.md)。

公開対象の合意は、一人の子との暮らし、開始三軸・八設定、基本職6種との出会い・初歩の仕事、不在進行切替。次の子・住人化・世代継承・終盤エンディングは製品版側。旧版の全機能を体験版へ移植する計画ではない。職業体験量、能力上限、製品版への保存引継ぎ等の未決定は正本に従う。Steamへの公開操作は別段階。

## 残作業10単位

ID 1は下記の対応範囲で実装・通し検証済み。ID 2〜10は未完了。一部の土台は既に実装済みなので、作り直さず接続・拡張する。

| ID | 作業 | この単位の到達点 |
|---|---|---|
| 1 | 会話の文脈と自然な受け取り | 直前の本人発話への聞き返し、言い換え、話題の継続を共通処理で扱う。現在・過去、本人・プレイヤー、理解できた部分・不明部分を区別し、生活や仕事の経験に照らして返す。現実の出来事の声かけも対象から除外しない。個別の正解台詞を要求しない。 |
| 2 | 未知語の経験学習 | 六作業語の専用処理を越え、体験版で扱う物・行動・感覚の言葉を、注目・説明・実体験から育てる。候補・限定的理解・応用・訂正を分け、初期未知設定でも学習が進む。無制限な自由語義理解を完成条件にしない。 |
| 3 | 文の関係の習得 | 質問・お願い・否定・時点等を、関係未知設定から育てられるようにする。正本の確定範囲と未採用の設計案を照合し、関係ごとの成立条件・体験版での対象を具体化して検証する。語の獲得と文全体の理解を混同しない。 |
| 4 | 記憶・ノート・発話の成長 | 知識／今の文脈／残した記録の三分類を行動へ接続。経験の想起、睡眠整理、訂正、後日の気づき、しぐさからの表現の成長を体験版の範囲で整える。閲覧で経験を水増しせず、他人の報告と実体験を区別する。未決定の成長規則は着手時に具体化する。 |
| 5 | 本人の判断と暮らしの循環 | 興味・体調・学んだ回復方法・過去の結果から行動を選ぶ。提案は強制指示にせず、仕事・食事・休息・散策が循環する。未知設定でも初回学習に到達でき、同じ巡回だけに固定されない。 |
| 6 | 既存施設・生活機能・ステータスの接続 | 既存マップの施設を棚卸しし、体験版での用途と未接続を明示する。対象施設の利用・入退場・生活行動を新方式の経験へ接続し、対応する実値を確認できるようにする。旧AI／旧生活更新は重ねない。旧能力等を採用する範囲は先に正本と照合する。 |
| 7 | 六職の仕事体験を仕上げる | 今の短い手伝いを、各職の初歩の実技・結果・師匠とのやり取り・次の試みまで広げる。本人の興味で他職を試せ、各職の体験量と区切りを試遊で確認する。皆伝までの旧進行を自動移植しない。 |
| 8 | 開始から体験版の区切りまでの導線 | 初期設問と個体差、三軸・八設定、初回案内、出会いへの導線、体験範囲の案内を整える。設問の未決定な配点等は具体化する。職業の区切り後も日常を続けられる。 |
| 9 | 不在進行・保存・試遊記録 | 不在進行切替を前向きに適用し、再開時の二重更新・成果重複を防ぐ。更新前セーブの移行、異常時保護、ノート／経験の整合を検証する。終了後の会話ログ保持は改善候補として扱い、保持範囲・容量等を決めてから実装する（現行はセッション内のみ）。 |
| 10 | 配布版の作成と通し検証 | 新方式専用の配布構成を作り、別環境で初回起動・保存再開・音声・表示・操作・七言語・対象施設・六職を通して確認する。内部検証操作を公開ビルドへ出さず、旧版の起動・保存も回帰確認する。公開用の素材・設定の不足を整理する。Steam公開自体は別途実施。 |

## チャット単位の進め方（ユーザー指定）

### ID 1の分割と現在地（2026-09-25）

- **1a 完了**：生活・仕事の実際の回答を主体・質問時点・出典付きで直近文脈へ保持し、七言語の明示的な聞き直しから共通参照する。回答反復による経験・学習・興味の水増しなし。意味の説明や自由な言い換えの完成ではない。
- **1b 完了**：「一息って？」「甘いの？」等の意味確認・省略・言い換えを、共通の直近文脈から生活／仕事の根拠へ接続した。七言語の基本形、六職の原経験、本人／プレイヤー・元の時点・既知／未理解・本人発話／観察描写の区別を保持。対応範囲と未対応の境界は正本の1b節を参照。自由文全般の理解・未知語習得を完成扱いしない。
- **1c 完了／ID 1完了**：現実の出来事・気持ちの部分理解と話題継続を共通処理へ接続。主体・時点・既知／未理解・発話／観察描写・原経験／原報告参照を保持し、ID 1全体を通し確認した。対応範囲は正本の1c節を参照。自由文全般の理解・未知語学習の完成ではない。ID 2は未着手。
- 1c／ID 1全体検証：新方式77件＋旧版2件。八設定・七言語・六職の原経験、別話者／他者／否定／条件／未知／観察の境界、JSON再開を確認。実Electron --contextで1a→1b→1cと専用保存再開、通常移動制限・BGM readyState=4・旧AI未起動・旧保存キー非作成・食事経験一回を確認。追加表示3文を七言語へ翻訳し14,726文のi18n、変更JS構文・差分検査通過。非表示画面の再描画後にPNGで会話・島・入力欄を目視した。実際の聴感・友人試遊・配布ビルドは後工程。
- 1a検証：新方式61件と旧版2件、変更JS構文、七言語チェック、差分検査。追加の実画面試遊は未実施。新しい表示文はなく、既存七言語の返答を使用する。
- 1b検証：新方式70件（六職×八設定、七言語、元の経験／時点、未理解・他者・話題変更の境界、保存検証を含む）、旧版2件。専用一時プロファイルの実Electronで意味確認・再開・食後描写・甘味質問と通常画面の移動制限を確認。追加表示2文を七言語へ翻訳し、14,723件のi18n、変更JS構文、差分検査を実施。

- 継続承認（2026-09-25）: 各実装チャットの区切りに、検証・仕様・引き継ぎ更新を済ませた対象変更をstage・commitし、現在ブランチの既定リモートへpushする。再承認は不要。無関係な変更の混入、reset・破棄・force push・履歴改変は含まない。変更なしなら空コミット不要。最終回答にコミットID・push成否を含める。失敗時はローカル変更・コミットを保持し、残作業を引き継ぐ。

- 次のチャットはID 2から。着手時にこの単位で完了させる範囲と確認方法を明示し、必要な未決定事項だけを具体化する。今回のチャットではID 2へ着手しない。
- 原則として一つの単位を実装・検証・仕様更新まで行ったら一区切りとし、別の単位へそのまま進まない。
- 一単位が大きすぎる場合は、着手時または判明時に7a・7b等の完了条件を持つ小単位へ分割し、この表に追記する。「一チャットで必ず完了」とは約束せず、未完を完了扱いしない。
- 小さな不具合・調整は該当単位に含める。前工程への修正は理由と範囲を記録する。
- 区切りでは正本の仕様、CURRENT_IMPLEMENTATION.md、本表の進捗を更新する。未コミット・未追跡の実装を保持し、ユーザー保存を操作しない。
- 最終出力には毎回、完了した単位／実装内容／検証結果／残件を簡潔に書き、引き継ぎメモへのリンクと「次チャットに貼る文章」をコードブロックで付ける。未完時は同じ単位の続きを指定する。
