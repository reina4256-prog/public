# 新方式Steam体験版の残作業とチャット単位の進行

更新: 2026-09-30

## 位置付け

現在は一部実装。既存島・BGM、六職の初歩の手伝い、限定的な作業語学習と会話、空腹・体力表示、専用保存が土台としてある。以下は残作業を管理する実施順の案であり、未決定の仕様を採用済みに変えるものではない。内容仕様の正本は [experimental_word_learning.md](specs/core/experimental_word_learning.md)。

公開対象の合意は、一人の子との暮らし、開始三軸・八設定、基本職6種との出会い・初歩の仕事、不在進行切替。次の子・住人化・世代継承・終盤エンディングは製品版側。旧版の全機能を体験版へ移植する計画ではない。職業体験量、能力上限、製品版への保存引継ぎ等の未決定は正本に従う。Steamへの公開操作は別段階。

## 残作業10単位

ID 1・2は下記の対応範囲で実装・通し検証済み。ID 3〜10は未完了。一部の土台は既に実装済みなので、作り直さず接続・拡張する。

| ID | 作業 | この単位の到達点 |
|---|---|---|
| 1 | 会話の文脈と自然な受け取り | 直前の本人発話への聞き返し、言い換え、話題の継続を共通処理で扱う。現在・過去、本人・プレイヤー、理解できた部分・不明部分を区別し、生活や仕事の経験に照らして返す。現実の出来事の声かけも対象から除外しない。個別の正解台詞を要求しない。 |
| 2 | 未知語の経験学習 | 六作業語の専用処理を越え、体験版で扱う物・行動・感覚の言葉を、注目・説明・実体験から育てる。候補・限定的理解・応用・訂正を分け、初期未知設定でも学習が進む。無制限な自由語義理解を完成条件にしない。 |
| 3 | 文の関係の習得 | 質問・お願い・否定・時点等を、関係未知設定から育てられるようにする。正本の確定範囲と未採用の設計案を照合し、関係ごとの成立条件・体験版での対象を具体化して検証する。語の獲得と文全体の理解を混同しない。 |
| 4 | 記憶・ノート・発話の成長 | 知識／今の文脈／残した記録の三分類を行動へ接続。経験の想起、睡眠整理、訂正、後日の気づき、しぐさからの表現の成長を体験版の範囲で整える。閲覧で経験を水増しせず、他人の報告と実体験を区別する。未決定の成長規則は着手時に具体化する。 |
| 5 | 本人の判断と暮らしの循環 | 興味・体調・学んだ回復方法・過去の結果から行動を選ぶ。提案は強制指示にせず、仕事・食事・休息・散策が循環する。未知設定でも初回学習に到達でき、同じ巡回だけに固定されない。 |
| 6 | 既存施設・生活機能・ステータスの接続 | 既存マップの施設を棚卸しし、体験版での用途と未接続を明示する。対象施設の利用・入退場・生活行動を新方式の経験へ接続し、対応する実値を確認できるようにする。旧AI／旧生活更新は重ねない。旧能力等を採用する範囲は先に正本と照合する。 |
| 7 | 六職の仕事体験を仕上げる | 今の短い手伝いを、各職の初歩の実技・結果・師匠とのやり取り・次の試みまで広げる。本人の興味で他職を試せ、各職の体験量と区切りを試遊で確認する。皆伝までの旧進行を自動移植しない。 |
| 8 | 開始から体験版の区切りまでの導線 | 初期設問と個体差、三軸・八設定、初回案内、出会いへの導線、体験範囲の案内を整える。設問の未決定な配点等は具体化する。職業の区切り後も日常を続けられる。 |
| 9 | 不在進行・保存・試遊記録 | 不在進行切替を前向きに適用し、再開時の二重更新・成果重複を防ぐ。更新前セーブの移行、異常時保護、ノート／経験の整合を検証する。終了後の会話ログ保持は改善候補として扱い、保持範囲・容量等を決めてから実装する（現行はセッション内のみ）。 |
| 10 | 配布版の作成と通し検証 | 新方式専用の配布構成を作り、別環境で初回起動・保存再開・音声・表示・操作・七言語・対象施設・六職を通して確認する。内部検証操作を公開ビルドへ出さず、旧版の起動・保存も回帰確認する。公開用の素材・設定の不足を整理する。Steam公開自体は別途実施。 |
