# ゲーム仕様書インデックス

更新日: 2026-10-01

## この仕様書群の役割

このディレクトリは、ゲームに現在実装されている恒久仕様と、ユーザーが考えている将来仕様をコンテンツ単位で管理する。

- `AGENTS.md`: Codexの作業規則。
- `docs/CURRENT_IMPLEMENTATION.md`: 現在進行中の作業、直近の変更、未検証事項。
- `docs/specs/`: コンテンツごとの恒久仕様と将来構想。
- `game_system.md`: 移行元の旧マスター仕様。移行確認が終わるまで削除しない。
- [工程6の再開メモ](../STEP6_CHECKPOINT.md): 一旦中断する実装の到達点、残作業、検証入口。機能仕様の正本は引き続き本仕様書群とする。

新しい作業では、`AGENTS.md`、`docs/CURRENT_IMPLEMENTATION.md`、この索引、対象コンテンツの仕様書、関連コードの順に確認する。

## 記載区分

各仕様書では、次の区分を混同しない。

- **現在の実装仕様**: コード上で現在動作する内容。
- **確定している将来仕様**: 実装前だが、ユーザーが導入を決定した内容。
- **構想段階の案**: 候補であり、採用・詳細・数値が未確定の内容。
- **未決定事項**: 実装前にユーザー判断が必要な点。

状態ラベルは `実装済み`、`一部実装`、`未実装・仕様確定`、`未実装・構想段階` を使う。ユーザーの最新指示が常に優先され、共通仕様と個別仕様が衝突するときは個別仕様を優先する。

## 更新ルール

1. 挙動を変更した実装ターンでは、対象仕様書の「現在の実装仕様」を更新する。
2. 将来構想を追加・変更したときは、該当仕様書の将来区分とこの索引の状態を更新する。
3. 同じルールを複数ファイルへ複製せず、所有する仕様書を1つ決めて他からリンクする。
4. 作業途中の試行錯誤、検証ログ、次の作業点は `CURRENT_IMPLEMENTATION.md` に置き、恒久仕様書を変更履歴にしない。
5. コードと仕様書が食い違う場合は、勝手に片方へ合わせず「実装不一致」として記録し、ユーザー意図を確認する。

新しい仕様書は [`_TEMPLATE.md`](_TEMPLATE.md) を基準に作成する。

新方式はSteam体験版を次の実装目標に変更。基本職6種の出会い・初歩の手伝いに、実演付き経験からの作業語習得、振り返り／再試行意向の会話、興味による次の訪問先選択を接続した。通常画面の直接移動指定を外し、空腹・体力の実値を表示。他の師匠の仕事も試せる。本格的な職業実技・対象外の未知語・応用・訂正／関係習得・不在進行切替・配布構成は残作業。新方式の正本は [言葉の経験学習](core/experimental_word_learning.md) とする。

言葉の比較版は `start:word` から既存の島生成・描画・キャラクター・種族BGMを使う画面へ接続済み。新方式の単一生活更新で移動・採食・休息・注目を会話・ノート・レポートへ渡し、島配置も専用保存へ保持する。旧AI・旧生活・旧保存は起動しない。仮広場は内部検証用として残す。設問詳細・未知語／関係の習得・全施設接続は未完成。詳細は[正本の現在仕様](core/experimental_word_learning.md#現在の実装仕様)を参照。

言葉の経験学習・初回比較版は一部実装。専用Electron、一画面操作、八設定、散策と会話、食事・空腹／疲労・回復経験・睡眠整理・専用自動保存に加え、教わったこと／自分の経験／答えられなかった質問を読むノートを接続した。対象外の未知語・応用・訂正／関係の習得や後日の気づきの追記は未実装で、友人等による比較プレイの完成版ではない。到達点と残りは[正本](core/experimental_word_learning.md)の現在仕様を参照。

言葉の経験学習・比較実験版では、お願い・説明を受け取る土台を持って始めるか、その土台から育てるかも開始時に選べる方針を追加。詳細・未決定事項は[正本](core/experimental_word_learning.md)を参照する。

入力から文章化までの六段階と、知識・育った関連／今考えている文脈／残した記録の三分類は合意済みで、会話試作の状態を分離した。同正本の構想欄に具体化資料を記録し、保持・更新・選択規則等の未実装詳細は確定事項と区別する。

本人の理解について、同正本の「本人の理解：状態項目と更新条件の一覧」に状態項目・更新イベント・更新しない境界・未決定条件を整理。フィールド名や保存形式は設計案であり未実装。

同正本の「関係別の理解成立条件」には、否定・質問・条件等の必要要素、未解決部分、回答・行動との分離を具体化した設計案を記録。判定表の細目・対応文型は検討中。

同正本の「初回比較版：開始時の三軸と初期状態」には選択肢と八通りの組合せを整理。初期範囲・短文と未知内容の分離・生活未知側の学習入口、基本的な感情評価語・短い理由や訂正等の関係、既定値（土台あり／生活知識あり／短文）は合意済み。文型・学習規則・環境資源の細目は未決定。
