# パティシエ

状態: 実装済み / 分類: 上級職 / 内部ID: `pastry_chef`

## 現在の実装仕様

- 料理人・冒険家・農家の皆伝後、料理人から幻のスイーツレシピを受け取って解放する。
- 固有施設は持たず、料理人のレストランと自分のレストラン研究開発を使う。
- 入門試験の正解概念は砂糖、泡立て器、オーブン。

| Rank | 課題 |
|---:|---|
| 1 | 森でハチミツ3個を採取 |
| 2 | イチゴを種から3個収穫 |
| 3 | イチゴ系スイーツを研究開始 |
| 4 | メロンを種から1個収穫 |
| 5 | メロン系スイーツを研究開始 |
| 6 | ハチミツ系スイーツを研究開始 |
| 7 | スイーツレシピ完成度50%以上 |
| 8 | スイーツレシピ完成度100% |
| 9 | デザートを客へ合計10個販売 |

- 皆伝称号は `グラン・パティシエ`。料理技能を最低15、菓子技能20、賢さ+35、美しさ+35、機嫌+20、ハチミツを獲得する。
- 次世代特別依頼は、受注後に指定スイーツを新しく作って一皿納品する。
- レシピ、仕込み、販売は `business/restaurant_business.md` が所有する。

## 確定している将来仕様

### 住人の職業実技（承認済み・未実装）

- Rank 1・2・4は既存の採取・栽培・収穫課題を使う。
- Rank 3・5・6は師匠のレストランで本人の材料を使い、指定スイーツの研究を行う。研究記録は住人個人へ保存する。
- Rank 7・8は本人のレシピ完成度50%・100%を条件とする。
- Rank 9は本人が成功させたデザート10皿を師匠の試食用に納品する課題へ置き換える。架空の客・売上・Goldは発生させない。

- 受注後の本人の成果だけを認める。個人所有・皆伝報酬の共通規則は [弟子入り共通仕様](../apprenticeship_common.md) を参照する。

### その他の確定仕様

- 共通余生方針 `希代の職人` の菓子系設計図は、本人がその世代で実際に完成させた既存菓子レシピを元にし、元と同じ材料、設備、技能、工程、主要効果を要求する署名入りレシピとして登録する。初期固有差は鮮度上限10%だけとし、元レシピ解放・職業皆伝を迂回せず、名工作品を素材とした補正重複を禁止する。余生中には材料や完成菓子を生成せず、選出と永久図鑑記録は [`../../core/evolution_lifecycle_inheritance.md`](../../core/evolution_lifecycle_inheritance.md) が所有する。
