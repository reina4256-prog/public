# 美容師

状態: 実装済み / 分類: 上級職 / 内部ID: `hairdresser`

## 現在の実装仕様

- 農家・冒険家・建築士の皆伝後、農家から幻の染料花の噂を聞く。森で花を入手して建築士へ見せると美容室の図面と職業を解放する。
- 入門試験の正解概念はハサミ、クシ、カラー剤。

| Rank | 課題 |
|---:|---|
| 1 | 自由探索で清らかな湧き水を採取 |
| 2 | アロマハーブを3個栽培・収穫 |
| 3 | 小屋にドレッサーを設置 |
| 4 | 初めてカラーチェンジ |
| 5 | 初めてオーラを付与 |
| 6 | 深部探索で虹色のしずくを入手 |
| 7 | 虹色のしずくで最大7色のカラーチェンジ |
| 8 | 虹色カラーと虹色オーラを両方適用 |
| 9 | ドレッサーLv10後にカラーとオーラを適用し究極の美容アイテムを得る |

- 皆伝称号は `カリスマ美容師`。美容技能を最低20、美しさ+60、機嫌+30、究極の美容アイテムを獲得する。
- カラー・オーラは通常姿とダンジョン歩行、レストラン、マイホーム描画へ反映する。
- 姿と性格を引き継ぐ場合、皆伝済みならカラー・オーラも次世代へ引き継ぐ。
- 次世代特別依頼は受注後の新しいカラー・オーラ。条件不足時はドレッサーLv18のフォールバックがある。

## 確定している将来仕様

### 住人の職業実技（承認済み・未実装）

- Rank 1・2・6は既存の素材入手課題を使う。
- Rank 3は美容室で設備準備実習を行う課題へ置き換える。
- Rank 4・5・7・8は美容室でカラー・オーラの実技を行う。通常と同じ素材と虹色条件を満たす。
- Rank 9は通常のドレッサーLv10までと同等の費用・工程で設備実習を進め、カラー・オーラの総合実技を行う。
- 実習中の外見は練習記録として分離し、プレイヤーが選んだ住人の外見へ上書きしない。

- 受注後の本人の成果だけを認める。個人所有・皆伝報酬の共通規則は [弟子入り共通仕様](../apprenticeship_common.md) を参照する。
