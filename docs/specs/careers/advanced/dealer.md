# ディーラー

状態: 実装済み / 分類: 上級職 / 内部ID: `dealer`

## 現在の実装仕様

- 建設済みカジノへ初めて入ると遭遇する。カジノ入場自体に思い出60枚条件はない。
- 入門試験の正解概念はカジノ、スロット、カードゲーム。

| Rank | 課題 |
|---:|---|
| 1 | 受注後にカジノコインを累計20枚購入 |
| 2 | 図鑑解放済み種族柄のトランプを1種類購入 |
| 3 | 解放されたポーカーでディーラーに勝利 |
| 4 | 受注後のポーカー純利益を合計100コイン以上 |
| 5 | 解放された大富豪で最終1位 |
| 6 | 思い出60枚以上で60枚TCGデッキを保存 |
| 7 | ディーラー固定60枚デッキにTCG勝利 |
| 8 | 自分が保存したデッキにTCG勝利 |
| 9 | 受注後、ポーカー・大富豪・TCGを各3勝 |

- Rank 9にはスロット、インディアンポーカー、テキサスホールデムを数えない。
- 皆伝称号は `カジノ支配人`。賢さ+40。
- 皆伝後は設備購入・配置、追加トランプゲーム購入、来客師匠とのゲーム、6ゲーム勝敗表を利用できる。
- インディアンポーカーとテキサスホールデムはRank進行では解放せず、皆伝後に各100コインで購入する。
- 皆伝時はカジノを正式退出してから余生選択へ進む。
- 現在、次世代特別依頼の対象外。
- カジノ本体は `casino/casino_dealer_and_map.md`、各ゲームは同ディレクトリの個別仕様が所有する。
