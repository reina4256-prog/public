# 販売員

状態: 一部実装・将来仕様確定 / 分類: 上級職 / 内部ID: `merchant`

## 現在の実装仕様

- 弟子入り職業としては未実装。
- TCGには販売員の上級人物カードが先行実装され、CPUとの交換に関係する効果を持つ。
- 通常ショップ、島訪問売買、相場、レストラン販売、カード競売は既存実装だが、販売員職業とはまだ接続されていない。
- 城の競売所に販売員NPCを定位置で配置し、チャット指示による移動・到着会話で通常会話を表示する。課題操作は準備中表示のみ。城内配置の人物IDは `merchant`、会話画像分岐の師匠種別は `salesperson` と現在のコード上で混在しているが、弟子入り保存状態はまだ存在しない。

## 確定している将来仕様

- 販売員を実装予定の上級職として正式に追加し、職業、師匠、弟子入り、Rank、皆伝、セーブ条件を含む正規の `MasterType` を `merchant` に統一する。現在会話・画像分岐等で使っている `salesperson` は実装時に `merchant` へ移行し、新しい保存データには書き込まない。表示名や翻訳から内部判定しない。
- 実装時は1職業1仕様書、共通Rankルーチンを利用する。
- 城の屋内マップにある競売所を職業拠点として使う。
- 城が建築済みであれば、競売所の販売員へ行くだけで入門クエストを受注できる。城を建築できる時点で冒険家・建築士皆伝は成立済みとして扱い、それ以外の職業皆伝、店舗建築、能力値条件、オンライン状態を追加の解放条件にしない。
- 主人公が販売員を免許皆伝すると、自分のショップを経営できる。ショップの建築自体は建築士側の条件で先に完了できるが、販売員皆伝済みの担当者がいなければ開店、仕入れ、買取、販売、経営UIからの確定操作、オフライン営業を開始できない。
- 現在の資格不要なおつかい売買は、販売員経営の実装時に正式な店舗取引へ統合する。ショップのレジ金、在庫、相場、買取価格、住人客と住人売却は [`../../business/general_shop.md`](../../business/general_shop.md) が所有する。
- 販売員の弟子入り用に研修店舗、仮店舗、露店等を新設せず、Rank課題で自分のレストラン、鍛冶屋、ショップその他の店舗建築・経営を要求しない。Rank 2以降も、城、競売所、冒険家・建築士皆伝までに利用可能な所持品、Gold、既存行動、師匠との会話・課題UIだけで完了できる内容にする。能力値上昇を達成条件へ含めない。
- Rank 0の入門試験は、Q1「物を売買するときに使う金属の丸いものは？」、Q2「安く買って高く売ることで得られるものは？」、Q3「お客さんを呼んで商品を売る場所は？」とする。正解概念はそれぞれ `硬貨`・`コイン`・`お金`、`利益`・`儲け`・`黒字`、`店`・`ショップ`・`店舗` とする。
- Rank 1は、受注後に `古びた硬貨` を3個販売員へ納品する。納品した3個は課題達成時に消費し、返却しない。
- 販売員の入門試験とRank課題では、プレイヤーが試験問題の答え、価格、売買判断、仕入れ構成、交渉内容を直接選択・入力しない。プレイヤーの介入は、AIキャラクターへ必要な言葉を事前に教える、必要品を本人に持たせる、競売所へ行くよう指示する、課題を受注・報告させる等の間接的な準備に限定する。
- 入門試験は現行職業と同じく、AIキャラクターが覚えている言葉を3つの正解概念群と照合し、試験中に本人が自動回答する。回答ボタンやプレイヤー用の自由入力欄は表示しない。
- Rank 2以降の査定、計算、需要判断、仕入れ、交渉、帳簿、最終試験もAIキャラクター本人が自動で回答・実行する。合否は受注後に本人が覚えている意味のある言葉、前Rankまでに得た販売知識、準備済み所持品、課題用の固定条件から決定し、能力値やランダム成功率を使用しない。同じ準備状態と問題状態なら同じ結果にする。

| 4 | `仕入れ`・`売上`・`利益` | 仕入額、販売額、手数料が提示される3件について、最終的な利益または赤字額を自動回答し、全問正解する |

- Rank 2の対象は同じセーブ系譜で入手済みで、課題受注者本人が現在所持している品に限定する。物語用品、装備中、別予定で予約中、譲渡不可品は除外し、条件を満たす5種類がなければ本人は試験を開始せず不足種類数を伝える。
- Rank 3～9の出題条件と仮想取引は言語非依存の問題IDと固定値で構成し、問題中にプレイヤー向け回答操作を出さない。販売員との会話イベントウィンドウには、師匠の出題、AIキャラクターが自動で選んだ回答・行動、その理由、正誤・合否を順番に表示する。
- 表の必要概念は言語非依存の正式語IDで判定し、表示語と入力別名はローカライズする。`値段` と `価格`、`利益` と `儲け` 等、同じ意味の表記揺れは一つの概念として扱い、表示文字列の一致だけで別概念を重複習得させない。
- Rank 2～8の合格時には、そのRankで学んだ内容を本人の販売知識としてRank進行とともに永続記録する。後から対応語を忘れても、合格済みRankと獲得済み販売知識は失わず、Rank 9はそれらを参照する。ただし店舗で専用アクション `交渉` を指示するには、Rank 7合格に加えて本人が現在も正式語 `交渉` を覚えている必要がある。
- 必要語が不足していても本人は課題へ自動回答し、分からない内容は分からない、または誤った判断として表示する。失敗時に販売員が本人へ正解語を直接教えたり、`learnedWords` へ自動追加したりしない。代わりに観測者であるプレイヤーへ、1回目は考える方向、2回目は不足概念を絞る説明、3回目は具体例を含む分かりやすい説明へ段階的に近づくヒントを表示する。4回目以降は3回目の最も具体的なヒントを繰り返し、正解語そのものを自動習得させない。
- Rankごとの失敗回数は段階ヒントの選択だけに使い、入門試験の挑戦回数、破門、出入り禁止、Rank低下へ加算しない。失敗回数はゲーム終了・再読込後も保持し、合格後は完了済みRankの履歴へ畳んで次Rankのヒント段階へ持ち越さない。
- Rank 2～9では実際のアイテムとGoldを消費・獲得しない。失敗しても品、Gold、Rankを失わず再挑戦でき、実物を消費する課題はRank 1だけとする。各課題は受注後に成立させ、販売員へ本人が報告して次Rankへ進む。受注前の所持数、Gold、取引実績だけでは自動達成しない。
- `交渉` は正式語とし、Rank 7合格で本人の店舗用専用アクションを解放する。Rank 7合格後も、実際に指示・実行する時点で本人が正式語 `交渉` を現在習得している必要がある。言葉を忘れた場合もRankとアクション解放実績は失わないが、再び正式語を覚えるまで実行できない。
- プレイヤーは交渉対象の商品、価格、会話内容を直接選択しない。本人のAIマインドまたは時間割へ `交渉` を組み込むことで、AIキャラクターが在庫、設定価格、相場、客の傾向、評判から対象を自動選択して実行する。
- 交渉準備は初期30ゲーム分と本人の体力5を消費する。効果は対象商品の次の3件の販売、または開始から2ゲーム時間のうち先に到達した時点で終了する。効果中に再実行しても重ね掛けせず、残り件数と時間を初期値へ更新する。時間、体力、件数は後から調整可能にする。
- 交渉中は対象商品の価格許容率 `acceptableRatio` へ初期 `+0.15` を加える。販売員皆伝者が実際の店舗担当者である間は、全商品の価格許容率へ常時 `+0.10` を加え、ぼったくりによる評判低下の発生率を通常の50%にする。交渉と皆伝の許容率補正は合計 `+0.25` を上限とし、主人公と住人等の複数資格者から重複加算しない。各値は後から調整可能にする。
- 許容範囲を超える高値では交渉中も購入拒否と評判低下が発生し得る。交渉や皆伝補正によって無料の商品、架空のGold、保証された購入を生成せず、通常の在庫、客Gold、店舗レジ金、相場更新を適用する。
- 皆伝済み販売員が実際の担当者である間は、実在する入居住人がその店舗を来店先候補に選ぶ重みを初期1.5倍にし、同じ住人の再来店間隔を20%短縮する。匿名NPCを生成せず、住人の時間割、移動、空腹、所持Gold、店舗収容人数、閉店状態を上書きしない。入居住人が0人なら来客も0人とし、画面外・オフラインでも同じ規則を使う。倍率と短縮率は後から調整可能にする。
- Rank 9を報告するとRank 10と販売員皆伝を確定し、皆伝称号 `豪商` と賢さ+40を本人へ付与する。Goldや販売商品は皆伝報酬として生成しない。店舗経営資格と皆伝補正はこの時点で有効になるが、店舗の建築・開店・担当者設定を自動実行しない。店舗をまだ建てていなくても皆伝でき、後から建築して利用できる。
- 販売員の人物思い出は、本人がその世代で新規皆伝した場合に皆伝時の1枚を取得する。職業ライセンスを引き継いだ次世代以降は、既存師匠と同じ1世代1回の思い出クエストを販売員にも用意し、達成時にその世代の販売員人物思い出を1枚取得できる。`一度だけ` はセーブ系譜全体で1枚という意味ではなく、同じ師匠について同一世代の重複取得を防ぐ意味とする。
- 販売員の次世代思い出クエスト名は `時代を読む商い` とする。販売員ライセンスを引き継いだ現世代の主人公が、現世代で販売員と競売所にて再会した後に受注できる。店舗、オンライン機能、能力値、他職業を受注条件にせず、同じ世代の販売員人物思い出を皆伝その他の経路ですでに取得している場合は提示しない。
- `時代を読む商い` は競売所の仮想市場情報だけを使う。価格、在庫、需要が異なる固定5件について、本人が `買う`・`売る`・`待つ` を自動判断し、4件以上正解で達成する。必要な正式語は `相場`、`需要`、`供給` の3概念とし、前世の皆伝・販売知識だけでは補わず、現主人公が挑戦時に現在習得している正式語を参照する。プレイヤー用の回答選択・入力は表示せず、プレイヤーは事前に言葉を教える間接介入だけを行える。
- `時代を読む商い` の5件は基準相場を100Gに統一し、次の固定順で出題する。第1問は現在価格70G、在庫1個、需要上昇、供給減少から `買う`。第2問は現在価格140G、在庫5個、需要低下、供給増加から `売る`。第3問は現在価格100G、在庫3個、需要・供給とも変化なしから `待つ`。第4問は現在価格90G、在庫10個、需要急落、供給増加から値下がり前の在庫削減として `売る`。第5問は現在価格110G、在庫0個、需要急上昇、供給不足から将来を見越して `買う` を正解とする。
- 第1問は `相場` と `需要`、第2問は `相場` と `供給` の各2概念、第3問から第5問は3概念すべてを必須判断材料とする。4問正解には `相場`、`需要`、`供給` の全習得を必要とする問題割当とし、必要概念を知らない問題ではランダム回答せず `判断材料が足りない` と回答して不正解にする。問題内容と順序は固定し、ロードや再挑戦でも並べ替えない。
- 思い出クエストの問題セットは受注時に言語非依存IDと固定値で確定し、失敗・再読込・再訪問で引き直さない。再挑戦時は同じ問題へ、その時点の本人の習得語を使って改めて自動回答する。失敗時は販売員が正解語を直接教えたり自動習得させたりせず、プレイヤーへ1回目は方向、2回目は不足概念の絞込み、3回目以降は具体例を含む同じ最詳細ヒントを表示する。失敗ペナルティと挑戦回数制限は設けない。
- 第1段階ヒントは `値段だけでなく、客と品の動きも見てみな` とする。第2段階は本人が未習得の概念に応じ、`基準となる値段`、`欲しがる客の多さ`、`出回る品の数` のうち見落としている判断材料をプレイヤーへ示す。第3段階以降は課題本体と異なる数値の具体例をプレイヤーへ提示する。ヒントを聞いても正式語を本人へ自動追加しない。
- 出題と進行表示は通常の師匠会話イベントウィンドウではなく、既存の入門試験用一問一答UIである `examOverlay`、試験用キャンバス、台詞欄、進捗バー、問題遷移、結果表示を再利用する。3問固定を前提にせず販売員思い出クエストでは5問を安全に扱い、師匠と主人公の表示、AIの自動回答、判断理由、正誤、最終結果を同じ試験進行内で一問ずつ表示する。プレイヤー回答操作は追加しない。
- 思い出クエストへの各挑戦は初期30ゲーム分と本人の体力5を消費する。開始前に不足している場合は挑戦を開始せず、時間も体力も消費しない。時間と体力は調整可能な規則値にする。達成報酬はその世代の販売員人物思い出1枚だけとし、Gold、商品、能力値を追加しない。
- 成功時は入門試験UIの結果表示で、販売員が `お見事！時代が変わっても、その商売勘は本物だね。こいつは今のあんたと私の、商いの思い出さ` と伝えてから、その世代の人物思い出を付与する。
- 販売員Rank、合格済みRankから得た販売知識、正式語の現在習得状態、皆伝資格は本人の個体データとして扱う。主人公が世代交代後に住人となっても保持する。職業ライセンスを引継ぎ対象として選択した場合は、既存の職業引継ぎ規則に従って次の主人公へRank 10と皆伝履歴を引き継ぐ。引き継がなかった場合も店舗建物は選択されたマップ引継ぎに従って残せるが、現在の主人公自身は販売員として経営できず、販売員皆伝済み住人を実担当者にすれば営業できる。
- 住人も、現世代の主人公が販売員と出会い、競売所を利用可能にした後であれば販売員へ弟子入りできる。住人の試験とRank課題も本人の正式語、販売知識、個人所持品を使って自動回答・自動判断し、プレイヤーは言葉を教える、予定を組む、本人の所有物を準備する、訪問を指示する等の間接介入だけを行える。Rank 1は受注後に住人本人が所有した `古びた硬貨` 3個を消費し、主人公の所持品や共有収納から自動徴収しない。Rank 2～9は主人公版と同じ仮想課題とし、実物のGoldやアイテムを増減させない。
- 住人の課題実行は保存済みスケジュールにより画面外・オフラインでも進行できるが、受注と報告は本人が競売所へ実際に移動した時点で行う。住人の皆伝では本人へ `豪商`、賢さ+40、販売知識、店舗担当資格を付与する一方、主人公向けの人物思い出、世界・建物解放、余生選択を重複発生させない。
- 販売員皆伝後の余生も、職業から専用方針を選ばず、その世代での行動と育て方から拡張可能な共通余生方針カタログで判定する。初期11方針と将来追加される共通方針を他職と同条件で利用し、販売員専用の方針、専用モニュメント、専用指南書その他の職業別余生効果は追加しない。余生入りの自律決定、現役期間、排他的な余生進行、加齢は [`../../core/evolution_lifecycle_inheritance.md`](../../core/evolution_lifecycle_inheritance.md) に従う。
- 性格は、お金が大好きで計算高い一方、義理人情には厚いちゃっかり者とする。
- 会話フレーバーは次を正本とする。
  - 通常会話: 「チャリン♪ うんうん、今日もいい音が鳴ってるね！儲け話なら私に任せな！」
  - 課題提示: 「次の商談は『${qName}』だよ！ガッポリ稼いで、私を唸らせておくれよ！」
  - 報告成功: 「お見事！見事な商売の手腕だね！あんた、商人としての才能あるよ！」
  - 報告失敗: 「あちゃー、それは赤字ってもんだよ。相場ってものをもう一回見直してきな！」

## 構想段階の案

- 以前の職業案では、販売員を生産品へ付加価値を付け、店舗経営と行商取引を最適化する経済職としていた。店舗外の行商人活動や、交渉を仕入れ条件へも適用する拡張は未確定とする。
- レストラン、鍛冶屋、オンライン売買、カード競売と販売員技能を接続する可能性がある。
- 販売員の画像制作案は、16ビット風フロントビューJRPGポートレートの若い商人女性とする。羽根飾り付きの帽子、華やかで動きやすい旅商人服、首の宝石、腰の大きなコイン袋、片手で弾く金貨、自信に満ちた抜け目のない笑顔、単純な陰影、白単色背景という要素を候補にする。現在の `merchant_battle_enemy.png` を置き換えるかは完成画像を比較して決める。
