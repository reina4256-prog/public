# 薬剤師

状態: 実装済み / 分類: 上級職 / 内部ID: `pharmacist`

## 現在の実装仕様

- 体験版では薬局と病気を無効にする。版別制限の正本は [体験版仕様](../../internal/steam_demo_and_full_release.md)。以下は製品版の仕様。

- 通常主人公と住人の日課の制作処理は `craft_core.js` の個人材料・成功判定・成果付与を共用する。住人は既存Rankでの実技に対応し、新規弟子入り・自律受注・報告・皆伝は未接続。日課側の時間と保存境界は [AI・日課仕様](../../core/ai_words_and_tasks.md) を参照する。

- 薬局を拠点とする。未入門または冒険家皆伝前の訪問では買い物専用になる経路がある。
- 入門試験の正解概念は薬草、すり鉢・乳鉢、水。

| Rank | 課題 |
|---:|---|
| 1 | 薬草3、きれいな水3を集める |
| 2 | 薬局で薬草＋水を消費し、風邪薬の調合に3回成功 |
| 3 | 風邪薬2個を作る |
| 4 | 森で毒キノコ3個を集める |
| 5 | 解毒薬2個を作る |
| 6 | 集中薬1個を作る |
| 7 | 集中薬の効果中に勉強3回成功 |
| 8 | 大成功で万能の霊薬を作る |
| 9 | 万能の霊薬を納品して皆伝 |

- 皆伝称号は `宮廷薬剤師`。調合技能20、賢さ+50、万能の霊薬を獲得する。
- 風邪薬はRank 2から調合できる。Rank 1以前の真似動作は材料・成果・成功回数を発生させない。調合成功回数は対象の薬剤師Rank課題だけへ加算する。
- 次世代特別依頼は、受注後に指定薬を新しく調合して納品する。
- 人物カードの固有効果は回復・状態異常解除系。

## 確定している将来仕様

### 住人の職業実技（承認済み・未実装）

- Rank 1～9は主人公と同じ課題を使う。素材の収集、調合、集中薬の使用、服薬中の勉強、納品は住人本人の所持品・効果・実績で判定する。

- 受注後の本人の成果だけを認める。個人所有・皆伝報酬の共通規則は [弟子入り共通仕様](../apprenticeship_common.md) を参照する。

### その他の確定仕様

- ダンジョン状態異常から発症する低体温症・凍傷、火傷、眼病、身体硬直、心労、強い倦怠等へ対応する治療薬を、薬剤師皆伝後の追加レシピとして用意する。現行Rank課題へ途中挿入せず、既存セーブの進行を壊さない。特効薬と万能の霊薬は追加病を含む全病気を治療できる。
