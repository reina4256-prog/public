# 仕立屋

状態: 実装済み / 分類: 上級職 / 内部ID: `tailor`

## 現在の実装仕様

- 通常主人公と住人の日課の制作処理は `craft_core.js` の個人材料・成功判定・成果付与を共用する。住人は既存Rankでの実技に対応し、新規弟子入り・自律受注・報告・皆伝は未接続。日課側の時間と保存境界は [AI・日課仕様](../../core/ai_words_and_tasks.md) を参照する。

- 鍛冶師・冒険家・建築士の皆伝後、鍛冶師からアトリエの図面を受け取る。神秘の霊糸を持って建築士へ見せるとアトリエ建築と仕立屋を解放する。
- 入門試験の正解概念は糸、針、リボン。

| Rank | 課題 |
|---:|---|
| 1 | 野イチゴから染料3個を作る |
| 2 | 薬草から丈夫な糸3個を作る |
| 3 | 染料と糸から色鮮やかな布3個を作る |
| 4 | てるてる坊主のブローチを作る |
| 5 | 探求者のリボンを作る |
| 6 | 豊穣のタッセルを作る |
| 7 | 健康のミサンガを作る |
| 8 | 神秘の織物を作る |
| 9 | 悠久の懐中時計を作り納品する |

- 皆伝称号は `カリスマ仕立屋`。裁縫技能20、美しさ+50、神秘の織物を獲得する。
- 次世代特別依頼は新しいお守りの作成・強化。所有品が上限なら新規作成へフォールバックできる。

## 確定している将来仕様

### 住人の職業実技（承認済み・未実装）

- Rank 1～9は主人公と同じ課題を使う。素材消費、制作・強化、納品は住人本人の所持品と実績で判定する。

- 受注後の本人の成果だけを認める。個人所有・皆伝報酬の共通規則は [弟子入り共通仕様](../apprenticeship_common.md) を参照する。

### その他の確定仕様

- 共通余生方針 `希代の職人` の裁縫系設計図は、本人がその世代で実際に完成させた既存衣装を元にし、元と同じ材料、設備、技能、工程、主要性能を要求する銘入り衣装レシピとして登録する。初期固有差は最大耐久値10%だけとし、元レシピ解放・職業皆伝を迂回せず、名工作品を素材とした補正重複を禁止する。余生中には材料や衣装を生成せず、選出と永久図鑑記録は [`../../core/evolution_lifecycle_inheritance.md`](../../core/evolution_lifecycle_inheritance.md) が所有する。
