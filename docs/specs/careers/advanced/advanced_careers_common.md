# 上級職共通仕様

状態: 一部実装

## 現在の実装仕様

- 上級職は、複数の基本職皆伝、特別素材、設計図、施設、既存コンテンツ進行などを組み合わせて解放される。
- 上級職もRank 0～10、三問試験、課題報告、皆伝、人物思い出、余生という共通ルーチンを使う。
- 固有施設を持つ職と、既存施設を共有する職がある。パティシエはレストラン、コンシェルジュはマイホーム、ディーラーはカジノを使用する。
- 薬剤師、仕立屋、パティシエ、美容師、コンシェルジュ、ディーラーが実装済み。
- 占い師、科学者、販売員は職業として未実装だが、TCG上級人物カードの定義は先行実装済み。

## 解放連鎖の原則

- 解放に必要な基本職・素材は、現在世代のRank 10または過去皆伝履歴を参照できる。
- 噂、図面、素材取得、建築、初回入場、師匠遭遇を別フラグで管理する。
- 旧セーブで施設や素材が先行して存在する場合は、可能な範囲で解放フラグを補完する。

## 確定している将来仕様

- 占い師、科学者、販売員はいずれも上級職として追加候補にする。
- 将来構想と実装予定として確定した仕様を各職業ファイルで明確に分ける。

## 構想段階の案

- 新しい上級職も複数コンテンツを横断する解放ルートを持つ可能性がある。

## 未決定事項

- 新3職の前提基本職、解放素材、施設、追加順は未決定。
