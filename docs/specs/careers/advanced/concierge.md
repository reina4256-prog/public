# コンシェルジュ

状態: 実装済み / 分類: 上級職 / 内部ID: `concierge`

## 現在の実装仕様

- 倉庫、冷凍庫、金庫、ドレッサーを備え、冒険家の巡回記録、建築士の家の鍵、美容師皆伝後の紹介をそろえると、マイホーム初回入場で遭遇する。
- 入門試験の正解概念はおもてなし、家具、ベッド。

| Rank | 課題 |
|---:|---|
| 1 | 屋内を掃除し落とし物3個を回収 |
| 2 | 支給ベッドを置き、睡眠完了 |
| 3 | 受注後に倉庫と冷凍庫へ各1個収納 |
| 4 | ホワイトボードでカスタム作戦を1つ作成 |
| 5 | マイホーム環境スコア12以上 |
| 6 | 受注後に金庫へGoldを預ける |
| 7 | `アップグレード` で家具を1つ強化 |
| 8 | 来客へ接客し、食事後の退室まで完了 |
| 9 | 支給された観葉植物とキャンドルを配置 |

- 皆伝称号は `極上のコンシェルジュ`。コンシェルジュ技能20、賢さ+30、美しさ+30、機嫌+40。
- 次世代は最初の実際のマイホーム入場時に再会イベントを1回だけ行う。
- コンシェルジュとマイホーム屋内状態を次世代へ保持するには、マップ引継ぎとライセンス引継ぎの両方が必要。片方でも欠ければコンシェルジュは不在となり、屋内マップへは入れない。
- 次世代特別依頼は環境スコア上昇、代替として接客を利用する。
- 屋内マップの詳細は `myhome/myhome_and_concierge.md` が所有する。

## 確定している将来仕様

- コンシェルジュ皆伝後、マップ引継ぎとライセンス引継ぎの両方を選んだ次世代に、コンシェルジュとの必須会話でマイホーム自由エディットを永久解放する。
- マイホームに最初の収納設備が完成した後の会話で、主人公へ収納共通の正式語 `だす` と `いれる` を同時に教える。島の住人も本人がコンシェルジュと会話した場合に個別に習得できる。記憶容量、旧語彙移行、ツボや防衛戦での再利用は [`../../core/ai_words_and_tasks.md`](../../core/ai_words_and_tasks.md) を正本とする。
- 解放後は、PCのローカル日付の終わりを期限とする `かんたん`、`ふつう`、`むずかしい` の3件の日替わり依頼をコンシェルジュから提示する。任意の件数を個別受注でき、報告時の達成報酬は順に2、3、5ポイントとする。未達成の受注済み依頼は期限切れ1件ごとに1ポイント減るが、未受注日は減点しない。
- 期限までに目標を達成していれば、日付をまたいでも達成状態を維持し、未報告による減点は行わない。ポイント獲得には後日でもコンシェルジュへの `報告する` が必要。
- 達成済み・未報告の日替わり依頼は件数・日数の上限なく蓄積でき、翌日以降の新しい3件と共存する。報告時は蓄積したコンシェルジュ日替わり依頼の報酬をまとめて受け取る。
- 日替わり依頼は報告または期限切れになるまで、日付、内容、難易度、進捗、受注・キャンセル・達成状態等を個別記録として保持し、保守時に一件ずつ追跡できるようにする。報告済みは報酬加算後、期限切れはペナルティを一度だけ適用した後に削除し、長期履歴は残さない。同日の3件は原則として内容を重複させず、候補不足等で避けられない重複が生じた場合は、一つの行動を条件に合う複数依頼へ加算する。
- コンシェルジュ日替わり依頼は専用種別として保持し、一括報告では別の師匠の課題・バイト・特別依頼や、コンシェルジュ自身のRank課題・次世代特別依頼を報告対象に含めない。
- 受注後はコンシェルジュ会話で無減点キャンセルでき、同日の同じ依頼を進捗維持のまま再受注できる。同日の依頼内容は変更しない。未完了でゲームを終了する際はゲーム内UIで `ゲームを終了する`／`ゲームを続ける` を確認する。
- コンシェルジュポイントは0から始まり、0未満にならず、上限を設けない。コンシェルジュが物理的に不在となる世代交代では0へ戻す。
- ポイント条件で将来のマイホーム関連機能を利用可能にし、現在ポイントが条件を下回れば対象機能を再び利用不能にする。永久解放済みの自由エディット自体は再ロックしない。
- ポイント到達による増築と付随家具は到達実績として永久保持し、後のポイント低下では通常機能を停止しない。ただしコンシェルジュ不在となる世代交代では初期化する。
- マップ引継ぎとライセンス引継ぎの両方を選んだ場合だけ、ポイント、達成済み未報告依頼、受注／キャンセル中の当日依頼と進捗を次世代へ保持する。一方でも欠けてコンシェルジュが不在になる場合はすべて初期化する。
- 一度に複数の増築・機能条件へ到達した場合は、一回のコンシェルジュ会話へ追加内容を集約して告知してから反映する。無告知で追加せず、一度受領した永久報酬は再付与しない。
- 自由エディット、コンシェルジュポイント、部屋増築の詳細は [`../../myhome/myhome_editor_and_concierge_points.md`](../../myhome/myhome_editor_and_concierge_points.md) が所有する。
