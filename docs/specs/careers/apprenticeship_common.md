# 弟子入り共通仕様

状態: 実装済み

## 現在の実装仕様

### 遭遇から弟子入りまで

1. 解放条件を満たすと師匠の遭遇イベントが発生する。通常フィールドで出会う基本職の師匠は、任意の言葉を3語以上学習していることを共通の最低条件とする。
2. 初回は職業固有の動画・挨拶を表示し、`metMasters` と師匠名の学習語を記録する。
3. 基本職はテント・畑・レストラン等の拠点を作る。上級職は既存施設や専用屋内マップを使う場合がある。
4. Rank 0で三問の一問一答試験を受ける。問題文は概念を示し、正解語を直接教えない。
5. 三問合格で正式に弟子入りし、Rank 1以降の課題へ進む。

- いずれかの師匠と初めて顔合わせを完了したとき、具体的な師匠名や職業名を伏せた `修行への入口` チュートリアルを追加する。

### Rankと課題

- 内部職業IDごとに `apprentice.rank[masterType]` を持つ。
- Rank 0は入門前、Rank 1～9は修行、Rank 10は免許皆伝。
- 課題は `activeQuests` に保持し、開始時処理、達成判定、報告時消費を持てる。
- 能力上昇課題は受注時能力を基準に目標値を保存する。
- 回数課題は受注時に `qVal` 等を初期化し、対象行動の成功時だけ進める。
- 納品課題は報告時に対象物を消費するものと、所持確認だけのものがある。個別仕様とコードを正本とする。
- 師匠訪問では課題報告とバイト報告を安全に分け、特別依頼を通常Rank報告へ混ぜない。

### バイト・破門

- 各師匠は通常課題とは別に手伝い・バイトを提供し、主にGoldを報酬とする。
- 長期間の放置、失敗回数等により破門・出禁となる経路がある。具体条件とセリフは個別職業・実装を確認する。
- 世代交代では中途Rank、破門、リタイア等を未入門へ戻し、皆伝履歴だけを恒久職歴として扱うのが基本。

### 免許皆伝

- Rank 9課題の報告後、Rank 10、`isGraduated`、職業称号、能力・技能・アイテム報酬を確定する。
- 同じ世代で対応師匠の人物思い出を1枚獲得する。思い出が60枚未満等ではTCG用語を前面に出さない。
- 皆伝後は6種の余生方針から選び、寿命まで自動行動できる。
- ディーラーはカジノを正式退出してから余生選択へ進む。コンシェルジュはマイホーム屋内状態を維持できる。

### 世代交代と再会

- 職業ライセンスを引き継ぐとRank・皆伝履歴と次世代特別依頼の候補を保持する。
- 能力が十分高い次世代は、師匠初対面時にRankスキップまたは即皆伝となる場合がある。
- 皆伝済み師匠は新世代を前世と区別した再会セリフで迎える。
- 実装済み職のうちディーラーを除く11職は、次世代で1世代1回の特別依頼候補を持つ。
- 特別依頼は受注後に新しく行った成果だけを認め、アイテム成果は `masterSpecialProof` で個体を証明する。
- 特別依頼は同時に複数保持でき、対象師匠本人への個別報告で完了する。
