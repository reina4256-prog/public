# 鍛冶師

状態: 実装済み / 分類: 基本職 / 内部ID: `smithing`

## 現在の実装仕様

- 任意の言葉を3語以上学習した後、屋外で睡眠・勉強・筋トレ・ランニングのいずれかを指示すると初回遭遇が発生する。3語未満では通常の行動を行い、遭遇しない。
- 初回遭遇後に鍛冶師のキャンプを作り、`鍛冶師` を学習する。
- 入門試験の正解概念は鉄、ハンマー、炉。

| Rank | 課題 |
|---:|---|
| 1 | 活力+15 |
| 2 | 鍛冶5回 |
| 3 | 賢さ+15 |
| 4 | 練習用装備3個を納品 |
| 5 | 活力+30 |
| 6 | 美しさ+10 |
| 7 | 賢さ+30 |
| 8 | 大成功の芸術品3個を納品 |
| 9 | 活力+50 |

- 皆伝称号は `伝説の鍛冶屋`。鍛冶技能20、活力+25、賢さ+25。
- 冒険家・建築士とともに皆伝済みなら、アトリエの図面を渡して仕立屋解放へつなぐ。
- 次世代特別依頼は、受注後に指定品を新しく鍛造して納品する。
- 自分の鍛冶屋経営は `business/blacksmith_business.md` が所有する。
