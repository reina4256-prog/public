# 漁師

状態: 実装済み / 分類: 基本職 / 内部ID: `fishing`

## 現在の実装仕様

- 初回遭遇後に漁師の小屋を作り、`漁師` を学習する。
- 入門試験の正解概念は釣り竿、釣り糸、エサ。

| Rank | 課題 |
|---:|---|
| 1 | 活力+15 |
| 2 | 支給された古い釣り竿で釣り5回 |
| 3 | 素早さ+15 |
| 4 | 魚3匹を納品 |
| 5 | 活力+30 |
| 6 | 美しさ+10 |
| 7 | 素早さ+30 |
| 8 | 川または海のヌシ1匹を納品 |
| 9 | 活力+50 |

- 皆伝称号は `伝説の漁師`。活力+25、賢さ+25、存在すれば最高級釣り竿を獲得する。
- 次世代特別依頼は、受注後に指定魚を新しく釣って納品する。
