# 漁師

状態: 実装済み / 分類: 基本職 / 内部ID: `fishing`

## 現在の実装仕様

- 初回遭遇後に漁師の小屋を作り、`漁師` を学習する。
- 入門試験の正解概念は釣り竿、釣り糸、エサ。

| Rank | 課題 |
|---:|---|
| 1 | 活力+15 |
| 2 | 支給された古い釣り竿で釣り5回 |
| 3 | 素早さ+15 |
| 4 | 魚3匹を納品 |
| 5 | 活力+30 |
| 6 | 美しさ+10 |
| 7 | 素早さ+30 |
| 8 | 川または海のヌシ1匹を納品 |
| 9 | 活力+50 |

- 皆伝称号は `伝説の漁師`。活力+25、賢さ+25、存在すれば最高級釣り竿を獲得する。
- 次世代特別依頼は、受注後に指定魚を新しく釣って納品する。
- 現行のヌシ抽選はRank 8課題の受注状態を見ず、活力30・素早さ30以上なら通常の釣りごとに `0.05 + 活力×0.001` の確率で汎用 `fish_boss_river` または `fish_boss_sea`へ上書きする。捕獲済み・報告済みの抑止フラグがないため、同じ汎用ヌシを課題前や報告後にも複数回釣れる。Rank 8の達成判定は所持品内のどちらかを見て、報告時に最初の1匹を消費する。

## 確定している将来仕様

- 免許皆伝後に漁師ライセンスを引き継いだ次世代に、小型魚、中型魚、大型魚を釣り上げる3系統の水槽依頼を提供する。一度経験した後も受注できるのは、自由な釣りが可能な漁師ライセンス引継ぎ世代だけとする。3件は同時受注でき、受注後に対応する固定魚種区分の魚を新しく1匹釣り、漁師本人への `報告する` で納品・消費すると同じ型の水槽を1個渡す。報酬水槽には納品魚の生息区分に対応する淡水または海水が最初から入る。各依頼は繰り返し受注・達成できる。
- 受注中の水槽依頼と進捗は、漁師ライセンスを引き継いだ場合だけ次世代へ継続し、引き継がなければ初期化する。
- 魚の型は個体の実測サイズではなく魚種ごとの固定区分とし、同じ型へ複数魚種を登録できる。3系統を各1回以上報告すると、建築士が池の作り方を知っているという会話を一度発生させ、建築士の小型池制作クエストを解放する。一度達成した各型の初回報告と池案内の解放状態は、漁師ライセンスを引き継がない世代でも永久保持し、ゲーム全体の完全初期化だけで初期化する。水槽・池設備、生態系、依頼の継承条件は [`../../core/indoor_aquariums_and_ponds.md`](../../core/indoor_aquariums_and_ponds.md) が所有する。
- 汎用 `川のヌシ`・`海のヌシ`を抽選する現行方式は不具合として廃止し、淡水のイトウ、オオナマズ、ピラルク、海水のクロマグロ、ダイオウイカ、リュウグウノツカイの6種へ置き換える。固有ヌシはRank 8受注前・受注中・報告後のどの段階でも出現し、同じ魚種を含めて複数匹釣れる普通の収容対象とする。ヌシ判定は魚種カタログの言語非依存属性を使い、表示名に `ヌシ`を含むかどうかには依存しない。
- Rank 8は固有ヌシ6種のいずれか1匹を漁師へ渡す。受注前から所持していた鮮度有効なヌシも提出候補にできる。受注中に新しく釣ったヌシは個体ごとに全て鮮度を停止し、報告時に候補一覧から課題達成に使う1匹を選ぶ。保護対象のヌシは報告後も消費せず、漁師の専用生け簀へ移して保管できる。生け簀では鮮度と生態進行を停止し、対応する淡水または海水の大型池を用意した後に漁師との会話から引き取れる。大型池以外には収容できない。
- 固有ヌシの通常時出現率は、出現季節と釣り場の条件を満たした釣り1回につき全ヌシ合算1%とする。Rank 8受注中は合算5%へ上げる。各魚種へ個別に1%／5%を適用して合算確率を増やさず、最初にヌシ当選を判定してから現在の季節・水域で出現可能な魚種を選ぶ。通常時はヌシ抽選に100回連続で外れた次の対象釣り、Rank 8受注中は20回連続で外れた次の対象釣りをヌシ確定とする。ゲーム内の春・夏・秋・冬のどの季節にも、少なくとも1種類の固有ヌシを必ず抽選対象へ含める。現実に通年活動する魚種は通年出現へできる。
- 固有ヌシの収容ポイントは全種共通にせず魚種ごとに定義し、大型池の200収容ポイントに入れられる最大匹数もヌシごとに異なるようにする。
- Rank 8の報告では課題達成に使う1匹を選んだうえで、受注中に釣って保護されているヌシを同種複数個体も含めて全て漁師の生け簀へ預けられる。生け簀の保管匹数に上限は設けず、預けた全個体の鮮度と生態進行を引取りまで停止する。
- ヌシの通常時天井カウンターとRank 8中カウンターは、川・海ごとに別々に持ち、季節が変わっても保持する。Rank 8受注時は通常カウンターをその値で凍結し、川・海それぞれのRank 8用カウンターを0から開始する。Rank 8報告時はRank 8用カウンターを破棄し、凍結していた通常カウンターを再開する。ヌシ当選では釣った水域のカウンターだけを0へ戻す。
- 生け簀は現在のマップ、持ち物、漁師ライセンスとは別に、漁師が家系から預かっている恒久保護領域として扱う。漁師ライセンスを引き継がなかった世代でも個体を消さず、全時間進行を停止したまま保持する。現世代で漁師と再会した後は、ライセンスの有無にかかわらず漁師との会話から引き取れる。ゲーム全体の完全初期化だけで生け簀内の全個体を初期化する。
- 生け簀にヌシがいる状態で漁師ライセンスを引き継がない場合は、世代交代の最終確認UIへ、保管個体数と「現世代で漁師と再会するまで引き取れない」ことを表示する。預けた個体を失うという警告にはしない。
- 生け簀からの引取りUIは、1匹ずつの個体選択、複数選択、すべて引き取るを用意する。対応する大型池の水種、空き収容ポイント、通常の環境判定を満たした個体だけを確定移動し、容量不足、不適合、キャンセル等で引き取れない個体は失わず生け簀へ残して時間停止を続ける。
- ヌシが抽選された時点で、その水域と状態に対応する天井カウンターを0へ戻す。釣り上げに失敗しても遭遇済みとしてリセットし、天井は捕獲保証ではなく遭遇保証とする。
- 現行の全ヌシ共通 `活力80・素早さ60未満なら自動失敗` は廃止する。捕獲成功率（%）は `10 + 活力×0.25 + 素早さ×0.20 + 釣り竿補正 - ヌシ難易度` とし、5～90%へ制限する。釣り竿補正はボロの釣り竿0、普通の釣り竿15、名人の釣り竿30とする。ヌシ難易度はイトウ20、オオナマズ25、ピラルク35、クロマグロ30、ダイオウイカ40、リュウグウノツカイ32を初期値とする。
- 一度も入手したことがない魚種が掛かった場合は、魚画像をシルエットで表示し、名称を `？？？` として正体を伏せる。未発見でも今回の捕獲成功率は表示する。初回釣獲では掛かっている間までシルエットと `？？？` を維持し、釣り上げ成功の結果画面で通常画像と名称を初公開する。次回以降の釣りでは最初から公開状態にする。購入、交換、オンライン取引、水槽・池や漁師の生け簀からの受取等、釣り以外の経路でも一度所有が確定した魚種は公開済みとする。この発見表示はヌシだけでなく通常の釣獲対象へ共通適用し、詳細は [`../../core/world_items_and_facilities.md`](../../core/world_items_and_facilities.md) が所有する。
- 捕獲失敗時のAI吹き出しでは、`活力不足`、`素早さ不足`、必要値、現在値、成功率計算式等を直接話させない。能力や装備を見直す余地があることを世界観に沿った間接的なヒントとして表現する。活力、素早さ、釣り竿が捕獲へ影響するという一般説明は釣りのチュートリアルUIへ載せてよい。
