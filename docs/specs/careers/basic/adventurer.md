# 冒険家

状態: 実装済み / 分類: 基本職 / 内部ID: `explore`

## 現在の実装仕様

- 初回遭遇後に冒険家のキャンプを作り、`冒険家` を学習する。
- 入門試験の正解概念は地図、水筒、コンパス。類義語も許可する。

| Rank | 課題 |
|---:|---|
| 1 | 受注時から活力+15 |
| 2 | 素早さ+15 |
| 3 | 探検で木材5、石5を集めて納品 |
| 4 | 賢さ+20 |
| 5 | 活力+30 |
| 6 | 美しさ+10 |
| 7 | 素早さ+30 |
| 8 | 深層の良質な木材3、硬い石3を納品 |
| 9 | 活力+50 |

- 皆伝称号は `大冒険家`。活力+50、機嫌+50、クリスタルを獲得する。
- 次世代特別依頼は、受注後の新しい探索成果を持ち帰る。
- Rank 3・8素材は、旧文字列所持品と鮮度付きオブジェクト所持品を同じアイテムIDとして数える。HUD、達成判定、納品消費は同じ数になり、途中帰還や鮮度正規化で進捗表示だけが0へ戻ることはない。
- 通常探検は手動・自律とも、弟子入り中、Rank 10以上、または `retired.explore` のいずれかを必要とする。疲労・中層/深層の能力不足による帰還は理由と育成ヒントを表示し、探検完了回数には数えない。
- 通常探検の開始資格、森・山の選択、階層能力条件、良質素材、体力・満腹度、中断、特別依頼ドロップの正本は [`../../core/field_exploration.md`](../../core/field_exploration.md) とする。
- カジノ解放では、建築士皆伝と対岸へ接続した橋を確認後、クリスタル迷宮5/10/20階素材の噂を教える。
- コンシェルジュ解放では巡回記録を渡す。
