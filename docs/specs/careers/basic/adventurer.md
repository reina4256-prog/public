# 冒険家

状態: 実装済み / 分類: 基本職 / 内部ID: `explore`

## 現在の実装仕様

- 2026-11-17試遊修正：新方式の課題／入口案内は通常の師匠会話ウィンドウを開き、普段の荷運び文へ差し替えず、そのときの課題と本人の実報告を表示する。おまかせ時の確認待ち／自動再開と素材の扱いは[新方式ダンジョン](../../dungeon/word_dungeon_preview.md)を参照。

- 新方式の皆伝は旧Rank表とは別。森・山での実地課題と師匠の確認からダンジョンへ接続し、能力値／語彙を付与しない。[新方式ダンジョンの現在仕様](../../dungeon/word_dungeon_preview.md)が所有する。以下は旧本編の仕様を保持する。

- 2026-11-17・新方式の会話方針：四つの実地課題は、提案／受注時に現在の課題と目的・報告に戻る場所を冒険家が話し、本人の実行報告を聞いてから修了した課題と次の目的を伝える。同行訓練でも、その階の実行を確認した後に次の階で試すことを案内し、帰島後に修了を伝える。課題中の再訪では普段の荷運び手伝いの会話を重ねない。初対面の紹介／動画は保持する。本人の実イベントに結ぶ発言・読取専用の課題案内・発話設定と音声の処理は[新方式ダンジョン](../../dungeon/word_dungeon_preview.md)へ接続し、これらの会話から皆伝条件や語彙を補完しない。以下の旧Rank報酬は新版へ採用しない。

- 初回遭遇後に冒険家のキャンプを作り、`冒険家` を学習する。
- 入門試験の正解概念は地図、水筒、コンパス。類義語も許可する。

| Rank | 課題 |
|---:|---|
| 1 | 受注時から活力+15 |
| 2 | 素早さ+15 |
| 3 | 探検で木材5、石5を集めて納品 |
| 4 | 賢さ+20 |
| 5 | 活力+30 |
| 6 | 美しさ+10 |
| 7 | 素早さ+30 |
| 8 | 深層の良質な木材3、硬い石3を納品 |
| 9 | 活力+50 |

- 皆伝称号は `大冒険家`。活力+50、機嫌+50、クリスタルを獲得する。
- 次世代特別依頼は、受注後の新しい探索成果を持ち帰る。
- Rank 3・8素材は、旧文字列所持品と鮮度付きオブジェクト所持品を同じアイテムIDとして数える。HUD、達成判定、納品消費は同じ数になり、途中帰還や鮮度正規化で進捗表示だけが0へ戻ることはない。
- 通常探検は手動・自律とも、弟子入り中、Rank 10以上、または `retired.explore` のいずれかを必要とする。疲労・中層/深層の能力不足による帰還は理由と育成ヒントを表示し、探検完了回数には数えない。
- 通常探検の開始資格、森・山の選択、階層能力条件、良質素材、体力・満腹度、中断、特別依頼ドロップの正本は [`../../core/field_exploration.md`](../../core/field_exploration.md) とする。
- カジノ解放では、建築士皆伝と対岸へ接続した橋を確認後、クリスタル迷宮5/10/20階素材の噂を教える。
- コンシェルジュ解放では巡回記録を渡す。

## 確定している将来仕様

- 2026-11-16新方式でも「冒険家皆伝＋初回5階同行訓練修了」を本探索条件として維持する合意。ステータスや語彙の一括付与は使わず、実地練習と本探索の経験から学ぶ。新方式の戦闘・持ち物・接続順序の合意と未決定事項は[新方式ダンジョン](../../dungeon/word_dungeon_preview.md#確定している将来仕様)を参照。以下の旧本編向け状態異常／病気・用語規則を新方式へそのまま採用する合意ではない。

- 冒険家皆伝後の初回ダンジョン入場時は、冒険家本人が専用の5階固定マップへ同行し、移動、戦闘、生存、道具、状態異常、帰還後の病気と全ダンジョン用語を会話と実地行動で教える。店舗チュートリアルと同様に、出所のない説明役ではなく既存の冒険家を引率者として使う。既習語があっても実地訓練は省略せず、初回は全5階の修了を通常ダンジョン解禁条件とする。初回完了後は普段の師匠会話イベントウィンドウから全階または任意の階を選んで再履修でき、後世代で語彙を引き継がなかった場合は初回物語を繰り返さない復習訓練として使える。修了後は通常の生還と同じ育成画面へ戻る。具体的な進行と用語解放は [`../../dungeon/dungeon_common.md`](../../dungeon/dungeon_common.md) が所有する。
