# 農家

状態: 実装済み / 分類: 基本職 / 内部ID: `farming`

## 現在の実装仕様

- 初回遭遇時に既存の畑を農家の畑として使用し、`農家` を学習する。
- 入門試験の正解概念は太陽、土、水。

| Rank | 課題 |
|---:|---|
| 1 | 活力+15 |
| 2 | 支給種を使い農業5回 |
| 3 | 美しさ+15 |
| 4 | 賢さ+15 |
| 5 | 活力+30 |
| 6 | 美しさ+30 |
| 7 | 農業15回 |
| 8 | `high_` 品質の作物3個を納品 |
| 9 | 活力+50 |

- 皆伝称号は `農業マスター`。活力+50。
- 次世代特別依頼は、受注後に種から新しく育てた指定作物を納品する。高品質品も基本作物を満たす。
- 冒険家・建築士とともに皆伝済みなら、幻の染料花の噂を教えて美容師解放へつなぐ。
- パティシエ解放の前提職でもある。
