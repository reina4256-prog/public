# 建築士

状態: 実装済み / 分類: 基本職 / 内部ID: `building`

## 現在の実装仕様

- 初回遭遇後に建築士のテントを作り、`建築士` を学習する。
- 入門試験の正解概念は図面、木材、トンカチ。

| Rank | 課題 |
|---:|---|
| 1 | 賢さ+15 |
| 2 | 建築5回 |
| 3 | 活力+15 |
| 4 | 練習用の図面3個を納品 |
| 5 | 賢さ+30 |
| 6 | 美しさ+15 |
| 7 | 活力+30 |
| 8 | 大成功の精巧な建築模型3個を納品 |
| 9 | 賢さ+50 |

- 皆伝称号は `一流建築士`。建築技能20、活力+30、賢さ+30。
- 皆伝後は知識の手帳で全施設の設計条件を確認できる。
- アトリエ図面＋神秘の霊糸で仕立屋、幻の染料花で美容室、カジノ素材3種でカジノレシピを解放する。
- 次世代特別依頼は受注後の新規建築。1個限定施設が埋まっている場合は設備強化へフォールバックできる。

## 確定している将来仕様

- 建築士を免許皆伝し、魂の引継ぎで建築士ライセンスを引き継いだ次の世代に限り、建築士から島の6地点を好きな順番で調査する専用クエストを受注できる。各地点では同行中という設定の建築士が通常の師匠会話UIへ登場し、最後は建築士へ `報告する`。未完了進捗はライセンスを引き継ぐ間だけ世代を越える。達成すると育成メイン画面の島自由エディットを永久解放する。詳細は [`../../core/main_map_editor.md`](../../core/main_map_editor.md) が所有する。
- 漁師の小型・中型・大型水槽依頼を各1回以上報告し、池の作り方を知っているという漁師の会話を聞いたうえで、建築士免許皆伝と建築士ライセンス引継ぎを満たす世代に限り、建築士から小型池制作クエストを受注できる。指定材料を集めて建築士本人へ報告すると小型池を1個制作して渡し、初回報告後は大型池制作クエストも解放する。小型池・大型池とも以後は建築士ライセンス引継ぎ世代だけ繰り返し受注でき、報告ごとに指定材料を消費して対応する池を1個渡す。受注中の池制作依頼は建築士ライセンスを引き継いだ場合だけ次世代へ進捗を残す。小型池初回報告と大型池解放の達成済み状態はライセンスを引き継がない世代でも永久保持し、ゲーム全体の完全初期化だけで初期化する。受注中は通常の `探検` へ川・海の素材収集ルートを追加するが、冒険家ライセンスや皆伝を池制作依頼の直接条件にはしない。水槽・池の共通仕様と材料は [`../../core/indoor_aquariums_and_ponds.md`](../../core/indoor_aquariums_and_ponds.md) が所有する。
- 共通余生方針 `希代の職人` の建築系設計図は、本人がその世代で実際に完成させた建築制作を元にした固有外観の記念家具・装飾に限定し、新しい施設種や機能を増やさない。後世での制作には登録済みの通常材料、設備、技能、工程を必要とし、建築士皆伝や施設解放を迂回しない。余生中には材料や家具を生成せず、選出と永久図鑑記録は [`../../core/evolution_lifecycle_inheritance.md`](../../core/evolution_lifecycle_inheritance.md) が所有する。
