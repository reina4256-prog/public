# 料理人

状態: 実装済み / 分類: 基本職 / 内部ID: `cooking`

## 現在の実装仕様

- 初回遭遇時は既存レストランを師匠の店として利用し、`料理人` を学習する。
- 入門試験の正解概念は包丁、鍋、火。

| Rank | 課題 |
|---:|---|
| 1 | 賢さ+15 |
| 2 | 料理5回 |
| 3 | 美しさ+15 |
| 4 | 普通の試作料理3個を納品 |
| 5 | 賢さ+30 |
| 6 | 食事3回 |
| 7 | 美しさ+30 |
| 8 | 大成功の究極の試作料理3個を納品 |
| 9 | 賢さ+50 |

- 皆伝称号は `三ツ星シェフ`。料理技能20、賢さ+50。
- 冒険家・農家とともに皆伝済みなら、幻のスイーツレシピを渡してパティシエを解放する。
- 次世代特別依頼は、受注後に指定料理を新しく作り、食べずに一皿納品する。
- 自分の店舗経営は `business/restaurant_business.md` が所有する。
