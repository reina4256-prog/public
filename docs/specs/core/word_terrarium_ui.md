# 新方式のテラリウムと操作パネル

## 現在の実装仕様

- 2026-11-20：共通UIの描画用経過時間をworld.elapsedと分離し、入力中／返答生成待ちも島と旧試作画面の本人スプライトのアニメーションを継続する。座標・世界時計・疲労／空腹・学習／探索は既存の保留を維持する。明示一時停止／設定・図鑑等の画面保留／非表示とOSの動きを減らす設定を尊重する。比較版の本人活動と会話の所有は[比較版](word_llm_reply_comparison.md)。ダンジョンの既存の静止chipや判定は変更しない。
- 2026-11-16ユーザー選択：木・真鍮・ガラスの温かい箱庭。現在の島マップをそのまま枠内に収め、この子が歩く。島の地形・移動・カメラ・暮らしの判定は変更しない。
- 中央は木枠／真鍮縁／ガラスの反射を持つテラリウム。名前札と吹き出しはその子を示す。隣に会話・ノート・星座・図鑑・思い出アルバム・解放済み育成を置き、下に体力／満腹度と一時停止の操作台を置く。狭い画面では縦に積む。
- ボタンは厚みと押下時の沈み込みを持つ。操作台の小さな灯りはゆっくり明滅し、一時停止中は止める。思い出取得は短い通知とアルバムの灯りで示し、閲覧すると灯りを消す。図鑑の見開きには短い開き演出を付ける。動きを減らすOS設定を尊重する。
- 言語・BGM音量・読み上げ・録音補正・声／名前の設定・録音比較・試遊レポート・自分用記録・URL指定時の診断は、ヘッダーの「設定」に集約。録音開始／音声停止は会話操作として残す。おまかせ育成はゲーム操作として残す。
- 設定／図鑑／アルバムを開くと島の更新を保留し、おまかせと音声再生を停止する。設定から開く本人情報・声選択は既存の明示保存／取消規則を維持する。
- 図鑑は紙の見開き。左に登録済み一覧、右に姿・当時名履歴・旧説明・前後ページ操作。未解放の枠・姿・総数は作らない。狭い画面では一覧と本文を上下にし、スクロールで閲覧する。解放と名前の所有は[図鑑仕様](../collections/pokedex_and_grazing.md)。
- 育成画面の姿／中身は画像ボタンで選ぶ。旧分類名のプルダウンを使わず、現在選択のチェックと枠を表示する。選択対象と保存・停止境界は[進化仕様](evolution_lifecycle_inheritance.md)が所有する。
- 思い出アルバムは写真を貼った紙のカード状表示。取得条件／世代保持は[思い出仕様](word_memory_card_game.md)。カジノ開設前の能力・カード操作は表示しない。
- 育成・師匠会話の外装は紙／木／真鍮へ合わせる。2026-11-23のユーザー復元指定により初期設問・本人情報／署名は対象から外し、[設問の近未来書面と手描き署名](experimental_word_learning.md#設問の近未来書面と手描き署名2026-10-06ee94bd8後)の濃紺／水色を保持する。native版の接続は[新正本](word_llm_native_system.md#開始導線と近未来書面の復元2026-11-23)。旧演出動画・署名・声設定・星座の夜空は維持する。旧ゲーム全画面の改修やダンジョン本接続ではない。
