# この子の名前・一人称・プレイヤーへの呼び方

## 現在の実装仕様

2026-11-15ユーザー依頼。名前を最初に名乗り合って覚える扱いは確認済み。一人称も設定し、「ご主人様」「あなた」等の非固有名の呼び方も使う。音声の所有は[星座と音声](word_constellation_and_voice.md)、検証・発行状態は[現行handoff](../../CURRENT_IMPLEMENTATION.md)。

### 入力・確定・表示

- 全設問後の濃紺／水色「はじめまして」画面で、決まった姿の右、声選択の上に名前・一人称・プレイヤーへの呼び方の3欄を置く。各欄は候補3つ＋自由入力。名前候補は決まった姿のものだけで、他種族一覧／種族数は出さない。狭幅は縦並び。
- 日本語の一人称候補は「ぼく／わたし／おれ」、プレイヤーへの呼び方は「ご主人様／あなた／相棒」。名前や呼び方は1〜32 Unicodeコードポイント、一人称は1〜16。前後の空白だけ除き、制御文字・改行・方向制御文字を拒否する。文字列をHTMLや正規表現として解釈しない。
- 設定内容を含むあいさつの表示・試聴ができる。試聴は選択した本人の声・調整値・演出を使い、読み上げオン・本人への教示・発話記録・本体保存を作らない。初回の確定はサイン時。その瞬間の値を複製し、演出中の後発変更を持ち込まない。
- 既存の子は音声設定内「名前と呼び方」から開き、明示保存で設定できる。設問・サインは不要。編集／試聴だけでは本人や世界を変更せず、保存せず閉じた入力は破棄する。表示中は従来どおり世界を止める。保存失敗は既存のゲーム内表示を使う。
- 候補と案内は7言語に対応する。言語切替時は候補・テンプレートを更新し、入力した名前／一人称／呼び方の文字は保持する。確定済みの文字列や会話原文・保存識別子を翻訳しない。

### 自己紹介情報と保存

- `experimental_word_identity.js`が`state.identity = {version:1, characterName, firstPerson, playerAddress}`を所有する。実際に設定した自己紹介情報として土台なしでも使う。一般の意味・質問・名付け等の関係やassociationを取得した扱いにはしない。
- 現在の設定を変更すると旧設定を`state.identityHistory`に残す。旧名での呼びかけも認識する。過去の入力・当時理解・返答・知識・ノートを書き換えず、忘却／記録削除を導入しない。
- 旧セーブの未設定は未設定のまま読み込む。候補を見せただけで自動設定しない。デスクトップの既存storageで現在値と履歴を検査・保存する。開始回答／姿／土台・生活・発話様式の対応は変えない。
- 個人別の文字を含む本人会話と試聴は、師匠／しぐさの定型WAV永続キャッシュに登録しない。生成元へ渡す範囲は音声所有仕様に従う。

### 呼びかけと会話

- `core.receive`入口で現在／過去の自己名単独（末尾句読点1〜3文字可）を照合する。比較だけNFC・大文字小文字を正規化し、保存した原文字列は保つ。名前付きの文全体や複合命令へ一般化しない。
- 名前・一人称・プレイヤーへの呼び方を尋ねる有限表現に7言語で応答する。日本語例は「名前は？」「一人称は？」「私の呼び方は？」。元から理解できた挨拶の返答にも、選んだ呼び方を使う。
- 今の子と`player`の関係だけに適用する。「あなた」を世界全体の固有名にしたり、一人称を対象物の名前にしたりしない。他speakerや未設定の子、その他の文は既存処理へ渡す。
- 既存の報告応答3種（本人の休息／非休息・プレイヤーの休息）も設定した一人称／呼び方を表示・読み上げに用いる。報告の理解条件や学習は変更しない。未設定の旧セーブは従来の表現を維持し、師匠の一人称・引用された原発言・ノートの説明文は本人の口調へ置換しない。
- 実input／serialと、その時点の自己紹介を持つunderstandingを保持し、出所を`introduction`とする。架空の教示・経験や一般知識を作らず、設定後に古い未理解を更新しない。
- 会話する子は本人の声、会話しない子は仕草で応じる。共通UIで翻訳済みテンプレートへ原文字列をliteral補間し、師匠・ナレーションの台詞を置換しない。
- 島・learning・既存ダンジョン試作で同じstateを使う。ダンジョンでも自己への呼びかけは物体名付け／移動と分ける。通常島からの橋接続とDW／DXは進めない。
