# タイトル画面・キャラクター自由エディット仕様

状態: 未実装・仕様確定

## 対象範囲

タイトル画面に表示する図鑑解放済みキャラクターの配置と、プレイヤー向け自由エディット機能を扱う。図鑑の解放・世代保持は [`../collections/pokedex_and_grazing.md`](../collections/pokedex_and_grazing.md)、魂の引継ぎ購入処理は [`evolution_lifecycle_inheritance.md`](evolution_lifecycle_inheritance.md)、タイトルのゲーム設定は [`../internal/runtime_platform_and_audio.md`](../internal/runtime_platform_and_audio.md) が所有する。

## 現在の実装仕様

- タイトル画面は、図鑑で解放済みかつ `TITLE_SCREEN_DATA` に定義されたキャラクターを表示する。
- `TITLE_SCREEN_DATA` には現在152体分の制作者指定データがあり、座標、切り抜き、大きさ、回転、左右反転、前後調整値等を持つ。
- 現在の本番表示は制作者指定データを使い、Y座標を基本とする描画順とドラゴンを最前面にする特別規則を適用する。
- 開発用タイトル画面エディターでは、ドラッグ移動、座標、大きさ、回転、左右反転、前後調整、表示・非表示、画像切り抜きを調整できる。
- プレイヤー向けの解放購入、ゲーム設定からの編集入口、個人別配置保存はまだ実装されていない。

## 主な状態と実装

- `window.TITLE_SCREEN_DATA`: 制作者が用意した152体分の初期表示データ。
- `window.TITLE_RANDOM_LAYOUT`: 現在のタイトル描画に使う解放済みキャラクターの配置。
- `aiPet.discoveredMonsters`: タイトルへ出せる図鑑解放済みキャラクター。
- `main.js`: タイトルデータ、デバッグ編集、タイトル操作、配置生成。
- `view_renderer.js`: タイトル画面とデバッグ編集画面の描画。
- プレイヤー向けの解放状態・保存配置データは未実装であり、フィールド名は未決定。通常の端末内セーブとして保持し、クラウドへ送らない別領域にする。

## 他コンテンツとの依存関係

- 図鑑で解放されていないキャラクターは、プレイヤー向け編集候補にもタイトル表示にも追加しない。
- 図鑑履歴は引継ぎ購入なしで世代を越える。詳細は [`../collections/pokedex_and_grazing.md`](../collections/pokedex_and_grazing.md)。
- 解放購入に使うGoldは、既存の魂の引継ぎ購入処理へ接続する。
- 編集入口はタイトル画面のゲーム設定へ追加するが、未購入時は入口自体を表示しない。

## 確定している将来仕様

### 解放

- タイトル画面のキャラクター自由エディットは、1世代を完了した後の魂の引継ぎ時に10Gで購入するおまけ機能とする。
- 解放は一度だけ購入する永久解放とし、次の世代から利用できる。
- 未解放時は、タイトル画面のゲーム設定にエディット項目を表示しない。
- 解放後は、タイトル画面のゲーム設定からエディットモードへ入れる。
- エディットモード中は通常のタイトル遷移操作を無効にし、ゲーム開始や続きから等へ進めない。
- セーブデータがない初回起動または完全初期化直後だけ、通常タイトルへ `はじめから` を表示する。セーブデータがある場合は通常タイトルから非表示にし、誤操作で既存系譜を失う入口を残さない。
- セーブデータがある場合の新規開始は、ゲーム設定の `データ管理` に置く多段階確認付きの完全初期化だけから行えるようにする。完全初期化後は図鑑、永久解放、保存配置、自作曲・音声等を初期化して `はじめから` を再表示する。端末譲渡、データ破損、検証等に必要な初期化手段そのものは削除しない。

### 編集対象と保存

- 編集候補は、そのプレイヤーが図鑑で解放しているキャラクターだけに限定する。
- 図鑑解放済みの全キャラクターを配置候補にし、各キャラクターについて表示・非表示を選べる。
- 非表示にしてもキャラクターの配置情報を削除せず、再表示時に以前の配置を復元できるよう保持する。
- 新しく図鑑解放されたキャラクターは、制作者が `TITLE_SCREEN_DATA` に設定した初期位置と初期表示状態で追加する。既存キャラクターのプレイヤー配置は変更しない。
- 最初に機能を解放した時点では、解放済みキャラクター全員へ制作者指定の初期配置を使用する。
- 解放状態と配置データはその端末内のプレイヤーセーブだけに保持し、ログイン中であってもクラウドバックアップ・復元の対象に含めない。この境界は将来変更する可能性がある。

### プレイヤーが変更できる内容

- 画面上の配置位置。
- 大きさ。
- 回転。
- 左右反転。
- 表示・非表示。
- 奥・手前の描画順。
- 画像ファイル、画像切り抜き位置、切り抜き範囲はプレイヤーに変更させない。
- 自由エディットではドラゴンを含めてプレイヤーが完全な前後順を決める。現在のドラゴン最前面規則はプレイヤー配置へ適用しない。
- キャラクターはタイトルロゴやメニューより手前にも配置できる。
- キャラクターは一部だけでなく全体を画面外へ移動できる。画面内へ収める制限は設けず、見失った場合は選択中の1体を初期状態へ戻す操作から復帰できる。
- タイトルロゴとタイトルメニューも自由エディットの対象とし、編集作業中はそれらの表示・非表示を切り替えられるようにする。
- キャラクターがタイトルメニューより手前に描画されていても、重なったキャラクターによって通常タイトルのメニュー選択を妨げない。
- 背景画像は唯一の移動不可要素として固定し、常に最背面に置く。ほかの編集対象を背景より奥へ移動することはできない。
- メインタイトル、サブタイトル、`はじめから`、`つづきから`、`ゲーム設定`は、それぞれ独立した編集対象にする。
- 5つの文字要素は座標、大きさ、回転、前後順を変更できる。フォント、色、文言、左右反転は変更できない。
- メインタイトルとサブタイトルは、通常タイトルでの表示・非表示も保存できる。
- `はじめから`、`つづきから`、`ゲーム設定`の3項目をプレイヤーが任意に非表示へ設定することはできない。ただし `はじめから` はセーブ有無によるシステム側の表示条件を優先し、セーブデータがある通常タイトルでは保存配置を保持したまま描画・クリック対象から外す。
- 文字要素は完全に画面外へ出た状態では保存できない。一部だけが見える配置は許可する。
- そのセーブ状態で表示対象となるタイトルメニュー項目は、表示領域とクリック可能領域が完全に画面外へ出た状態では保存できない。わずかでも画面内にクリック可能部分が残っていれば保存を許可する。システム条件によって非表示中の `はじめから` はこの保存検査から除外する。
- メインタイトルとサブタイトルを非表示で保存する場合は、完全な画面外に置いた座標もそのまま保存できる。見失った場合は対応するリセット操作で制作者指定位置へ戻せる。
- 初回起動時の `はじめから` と、ゲーム設定のデータ管理にある完全初期化確認画面は編集対象に含めない。
- キャラクターの大きさは制作者指定サイズを100%として1%～1000%、5つの文字要素は10%～500%の範囲で編集できる。回転は−180度～180度とし、数値入力とスライダーの両方を用意する。

### 操作と終了

- デバッグ機能を基礎にするが、キーボード専用にはせず、マウスで直接キャラクターを選択・移動できる直感的なプレイヤー向け操作にする。
- 選択中キャラクターの座標、大きさ、回転、反転状態、表示状態、前後関係を画面上で確認できるようにする。
- `保存して終了`、`変更を破棄して終了`、`全員を初期配置へ戻す`、`選択中の1体だけ初期状態へ戻す`を用意する。
- 画面上のキャラクターを直接クリックして選択できる。重なった位置を繰り返しクリックした場合は、その位置にある候補を順番に選択する。
- 一覧パネルからもキャラクターを選択できる。一覧には画像、名称、表示・非表示状態を示し、種族絞り込みと名前検索を用意する。非表示キャラクターも一覧に残して再表示できる。
- 前後関係の操作は `一つ手前へ`、`一つ奥へ`、`最前面へ`、`最背面へ`を用意し、現在位置を全編集対象中の順位として画面へ表示する。
- 前後順位はキャラクターと5つの文字要素を共通の並びで管理する。ただし、固定背景より奥へは移動できない。
- 編集セッション内の `元に戻す` と `やり直す` を用意する。
- Escや戻る操作で未保存の変更がある場合は、ゲーム内のデザインに合わせた確認UIで `保存して終了`、`破棄して終了`、`編集を続ける`を提示する。ブラウザ標準またはシステム標準の `alert` / `confirm` は使用しない。
- リセットは `選択したものだけ`、`キャラクターだけ`、`メニュー・タイトルだけ`、`すべて`の4種類を別々に用意する。
- 座標は現在のタイトル画面と同じ論理キャンバスを基準とする `X / Y` 数値で表示し、実際のウィンドウサイズが変わっても全体を比例拡大・縮小して同じ構図を維持する。
- 配置データは全表示言語で共通にする。言語変更で文字要素が完全に画面外へ出る場合だけ、現在言語の描画位置を最低限見える位置へ一時的に自動補正し、ゲーム内デザインの通知UIで補正を知らせる。この補正は現在言語の表示だけへ適用し、プレイヤーが保存した共通座標自体は書き換えない。別の言語へ戻した場合は同じ共通保存座標から改めて判定する。
- 保存時に画面内表示・クリック可能条件を満たさない文字要素がある場合は、対象を赤枠で示してゲーム内デザインのメッセージを表示し、保存せず編集を継続する。Windowsやブラウザのシステム `alert` は使用しない。
