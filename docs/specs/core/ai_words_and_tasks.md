# AI・言葉・タスク仕様

状態: 実装済み

## 対象範囲

学習語彙、記憶容量、チャット解釈、自律行動、予定タスク、AIマインドを扱う。職業試験の正解語は各職業仕様、ダンジョン専用作戦は `dungeon/dungeon_common.md` が所有する。

## 現在の実装仕様

- AIへの指示は自由入力チャットと、学習済みの言葉一覧から送信できる。
- 通常は学習済みの言葉だけが実行可能。施設名、師匠名、行動語、アイテム名には類義語の正規化がある。
- `aiPet.apprentice.learnedWords` が学習語彙を保持する。引継ぎショップで語彙を選ぶと、拡張された記憶容量とともに次世代へ持ち越す。
- 記憶容量を超える学習には忘却処理が関係し、言葉を失うと対応UIや行動が使えなくなる場合がある。
- チャットは入力を正規化して、師匠訪問、施設移動、通常行動、建築、収納、経営、ダンジョン、カジノなどへルーティングする。
- 複数段階の会話待ちがある。例としてマイホームのドレッサー、カジノ設備配置、師匠会話があり、無関係な入力は待ち状態を解除して通常解釈へ戻す。
- タスクは行動種別、時間、対象、開始済み状態、屋内状態などを持つ。通常フィールド、マイホーム、レストラン、余生で同じ進行基盤を一部共有する。
- AIの自律行動は性格、欲求、現在地、学習語、職業、施設、所持品、安全条件から選ぶ。
- AIマインドは「条件なら行動」の優先順ルール。カスタム作戦、コピー、挿入、候補パレットなどを持つ。
- ダンジョンでは基礎コマンドの閃きが段階的に発生する。必要語がそろうと `作戦` を理解し、作戦会議室とダンジョン指示UIが解放される。
- HP30%以下では `にげる` と `かいふく` の閃き対象となり、侵入時、罠、地形、反動、通常攻撃、特殊攻撃による到達を共通判定する。

## 安全規則

- 体力・満腹度不足では回復行動以外の長時間タスクを中断する。マイホームでの睡眠・食事へ向かう中継移動は回復行動として扱うため、詳細は [`myhome_and_concierge.md`](../myhome/myhome_and_concierge.md) を参照する。通常探検は共通開始前判定に加えて探索処理ごとの消費と5以下での強制帰還を持つため、詳細は [`field_exploration.md`](field_exploration.md) を参照する。
- 到達不能な目標は経路再計算、別対象選択、スタック救済または失敗報告を行う。
- 屋内タスクは所有する画面を閉じたときにタイマー・経路・待ち状態を残さない。
- 同じ入力語が複数コンテンツで使われる場合、現在モードと進行Rankを優先する。`スロット` は `カジノ` の類義語ではなく独立語である。
- カジノ外の入場語とカジノ内で表示・実行できる語の区別、およびDealer Rank・購入状態による表示条件は [`casino_dealer_and_map.md`](../casino/casino_dealer_and_map.md) が所有する。

## 関連実装

- `ui_controller.js`: `handleChat()` 系、言葉パネル、施設・師匠ルーティング。
- `ai_core.js`: タスク開始・進行・完了、自律判断、学習・忘却。
- `feature_arena.js`: 闘技場作戦。
- `dungeon_turn.js`: ダンジョン作戦とAI判断。
- `myhome_map_core.js`, `casino_map_core.js`, `shop_map_core.js`: 屋内チャット。

## 確定している将来仕様

- 新職業の語彙・試験語は、共通チャット辞書へ直接混在させるだけでなく各職業仕様を正本として追加する。

## 構想段階の案

- 職業増加に伴い、言葉カテゴリと記憶容量のバランスを拡張する可能性がある。
