# 同じ子のおまかせ育成

## 現在の実装仕様

- 2026-11-17試遊修正：課題・入口・同行訓練の師匠案内も既存会話ウィンドウで待つ。本人の報告→師匠の確認を含め、実際に表示した本文と選択声／配役の発声終了を待ち、既存の自動確認で探索へ戻る。ウィンドウを開いた同一フレームも次の育成入力を保留する。初対面の動画・影表示の扱いは下記を維持する。

- ダンジョンの実動作後の声かけは未知の動作だけを直前の一手へ結び、既知語を毎手繰り返さない。歩行は共通のwalkへ、新7動作は共通のaction知識へ接続する。島の持ち物が手を塞ぐ場合は現地への一時置きと実復路での拾い直しを使う。物／所在の条件は[ダンジョン正本](../dungeon/word_dungeon_preview.md)が所有する。

2026-11-15ユーザー依頼。「土台から育てる」場合の難しさを補助し、入力する言葉と学習過程が見えるオートを追加。「暮らし・会話・探索」の3コースから選ぶ方式ではなく、3項目の優先度をそれぞれ設定する方式をユーザーが選択。ゲーム内の適応的な育成補助で、外部生成AIサービスやAPIキーは使わない。検証／受入／発行の状態は[現行handoff](../../CURRENT_IMPLEMENTATION.md)。

- 2026-11-17最新依頼：専用パネル／定型命令を撤去。通常島の実移動で師匠に会い、共通入力で仕事を尋ね、理解済みの声かけで実地課題／製作／橋／入口へ参加する。adventure_connection.autoConversationの会話・実移動候補を探索方針の既存重みと比較し、暮らし／会話の機会を一律に上書きしない。提案だけで工程／語彙を与えず、関係の未習も保持する。実作業中に次の依頼を重ねず、本人の身体状況に応じて実食事／休息を挟む。自分で現地へ置いた現物の回収は原dropと実復路に基づく本人の実行として扱い、その直後に必要な語だけ教示する。物を選ぶUIや生の文字列命令で先に動かして理解済みとする経路は使わない。
- AUTOは理解済みの声かけから同じ一手口を使う本人探索。おまかせは師匠への誘導／会話・入場・探索・実動作の声かけ・通常階段での帰還まで担当する。参加した5階訓練の実動作は冒険家の同行指導で進める。師匠の原発話も同じformを通り、余分な一手や語彙一括付与はない。元から知る動作語は毎手繰り返さない。具体ルールと保存する原照合は[ダンジョン正本](../dungeon/word_dungeon_preview.md)。

- 通常島の会話欄に「おまかせ育成」を置く。各方針は見送る0／控えめ1／ふつう2／優先3、初期値は全て2。全て0では開始しない。開始・停止は明示操作で、初期停止／再起動後停止。既存の子にも利用でき、設問をやり直さない。土台ありにも同じ補助を使える。
- 優先度は実行可能な教示の機会に対する重みで、時間の厳密な割合や性格値ではない。空腹や疲れなどの現場条件を無視して方針の比率を満たすことはしない。`experimental_word_auto_training.js`が候補と重みを所有し、本人・世界・知識を書き換えない。
- 暮らしは実食事中の木の実／食べ物／食べる／甘い／空腹、実休息中の休む／眠る／疲れを、[既存2b](experimental_word_learning.md#walking-experience-learning)の条件が合う場合だけ教える。引用符付き一語を使用し、感覚をプレイヤーの報告から補わない。習得済み／同活動で教示済みの語を反復加算しない。
- 会話は実食事・休息の意味が必要なら先にその一語を教え、意味が分かった後に「今何してるの？」と活動の答えを組にした既存の質問実演を送る。実演は本人の実回答ではない。既存関係の成立後には同じ問いを実際に尋ねる。有限の現行文法の範囲であり、任意の自然文や未実装の挨拶を理解済みにはしない。
- 探索は通常の実移動を行い、実移動中だけ歩行語を教える。歩行・質問を既に知る場合は移動中の活動を尋ねる。食事／仕事／休息を移動で中断せず、空腹が強い／疲れている場合は新しい誘導移動を避ける。橋と新ダンジョンは上記の実地接続を使い、旧職業のRank／能力値報酬を自動取得しない。
- 計画した声かけと意図を2秒以上見せ、送信直前に現場・理解・言語を再照合する。変化した計画は破棄する。送信後は通常6秒以上待ち、経験の完了も通常の世界時間で進める。移動後の歩行教示だけは0.5秒後から次の2秒予告を準備する。背景復帰時の高速消化はしない。
- 実行は既存の`worldApi.approach`とチャットの`form.requestSubmit`を通す。チャットに「おまかせの声かけ」と原入力を表示し、自分の入力と区別する。本人の当時理解・実返信・ノート／星座・音声・保存は通常経路のまま。知識の一括付与、過去原記録の書換え、経験・完了の捏造、発話様式の変更はしない。
- 学習表示は「経験の完了や反応を見守る」と、開始時以降に実際に増えた意味の件数を分ける。語の送信だけで「覚えた」としない。停止後に送信済み教示の経験が完了した場合も件数を更新する。件数は本人全体の増分で、その間の手動教示を除外した因果寄与の推計ではない。未理解や不足はそのまま通常返信に残る。
- 入力・マイク・手動移動・一時停止・声選択・言語変更で停止し、下書きを送信／上書きしない。ダイアログ・星座・録音・出力等で通常世界が止まる間は予告を破棄して待つ。通常のダンジョン入場では補助を保持し、探索・声かけ・帰還まで同じ一手の時計を使う。明示URL指定の旧Web仮接続は従来の入場停止を維持する。
- 2026-11-15追加依頼：おまかせ実行中の師匠会話は手操作なしで進む。初対面動画のloading／videoを自動で飛ばさず、動画終了または既存の欠落／失敗fallbackを待つ。影表示の「話を聞く」と会話の「わかった！」を既存advanceMasterで自動進行し、閉じた後は通常育成を続ける。職業参加や報酬等の選択を追加・代行する機能ではない。
- tickAutoMasterは表示中のフレーム時間だけを最大0.1秒ずつ数え、本文＋しぐさの文字数に応じ4〜15秒以上表示する。読み上げを有効にした場合はplayMasterVoicesのPromise（師匠→しぐさ、または影の案内）の終了も待ち、その後1秒以上置く。読み上げ無効・未対応言語・生成失敗でも文字表示時間で進む。音声側の既存120秒上限は維持。動画・音声・cache所有は[音声仕様](word_constellation_and_voice.md)。
- 手動モードでは従来どおり確認待ち。おまかせ停止／一時停止／下書き／別画面の操作中は自動確認せず、非表示の経過を復帰時に消化しない。会話のphase変更・close・stopAutoで時計をリセットし、音声の世代番号で古いPromiseの完了を次の会話へ流用しない。auto_trainingのmaster_continueは私用診断記録であり、本人の知識や経験を付与しない。
- 方針だけ`state.autoTraining={version:1,weights:{life,conversation,exploration}}`へ保存し、storageで整数0〜3と形式を検査する。旧未設定セーブを許容。実行フラグ／予告／重みの実行回数は起動中のみ。設定変更は知識・土台・開始回答・名前／一人称／呼び方を変えない。
- 七言語で、その言語の既存カタログに一致する教示だけを使う。原入力は翻訳して保存しない。ドイツ語のEssenはfood/eatが重なる既存文法のため、foodの自動教示を見送る。食べるは一意なspeisenを使い、既存の理解規則を変更しない。
