# 新方式の思い出とカード遊び

## 現在の実装仕様

- 新方式の思い出取得／アルバムを接続。カード能力・対戦・カジノ開設は未実装。旧TCGの本接続、ダンジョン本接続、4e DW／DXは行わない。
- 2026-11-16ユーザー選択：実際に起きた節目で自動取得し、短い通知から思い出アルバムを閲覧。現在の取得対象は、新しい子との出会い、各師匠との初対面、初めて完了した食事／休息、各職の初めて完了した手伝い、必須演出を終えて新姿を表示した進化。作業開始・単なる移動・未理解入力からは取得しない。
- collectionの任意memories配列に、体験者のcollectionId・当時名・当時の選択中の姿・種類／対象・島内時刻・実イベントID／独立した原イベントsnapshotを保存。同じ子・種類・対象は一度のみ。仕事は職ごと、進化は姿ごと。本人の知識／原経験／ノートへ書き戻さず、原資料を補わない。初回出会いと進化は各明示完了境界そのものが出所となる。
- 改名しても当時名を変更しない。新しい子の開始待ち保存を越えて歴代の思い出を保持。旧saveはmemories省略を許容して空から始め、過去のpath・会話・試遊ログから思い出を捏造しない。既存の子は導入後に初めて実完了した対象を登録する。
- [アルバム画面](word_terrarium_ui.md)には姿・節目・当時名、師匠／仕事では相手と実際の手伝い本文を表示。導入前にも体験済みの子を考慮し、食事／休息／手伝いの見出しは「初めて」と断定しない。取得の重複防止は初回記録単位とし、人生最初の体験を補完した意味にはしない。カード能力・未開設カジノの案内は表示しない。現在のbuilding体験は図面の写しであり、建築完成やカジノ開設へ昇格しない。
- 旧版の思い出／TCGは[アルバム](../collections/memories_and_album.md)と[TCG](../casino/tcg.md)が所有する。以下は新方式向けの最新合意であり、旧版の挙動を変更しない。

## 確定している将来仕様

- 2026-11-16ユーザー合意。育成・進化・出会い・冒険などの実経験を「思い出」として集める。カードショップとスターターデッキは採用しない。
- 冒険・建築によってカードで遊ぶ場所であるカジノを開けたとき、集めた「思い出」が「カード」として扱われ、カードゲームを遊べるようになる。旧版の60枚／Dealer Rank6条件は新版へ自動移植しない。
- カードゲームを実際にプレイするのは、この子自身。プレイヤーは他コンテンツと同様、共通の自由チャットでこの子を導く。
- 追加回答により、歴代の子の思い出も引き継いで、次の子がカードとして使える。元の体験者・当時の名前を保持し、使った子自身の経験として書き換えない。
- 育成ステータスを持たない新版に合わせ、カードの能力と対戦ルールを設計し直す。追加回答により、能力は思い出の種類ごとの固定値ではなく、体験の内容から個別に決める方向を採用。
- 同じ種類の経験でも、実際に残った状況・行動・結果等の違いを区別する。欠けた事実や心理、成功、因果を推定して能力の根拠へ足さない。具体的な効果・数値への対応はまだ合意していない。

## 構想段階の案

- 能力の根拠となった経験をカード詳細からたどり、その子の思い出と遊びを結び付ける。

## 未決定事項

- 冒険／本格建築等を接続した後の追加取得対象・個別能力の導出・強さの調整・カードの表示構成。
- カジノの開設工程、最初に遊べる枚数／形式、少数枚での成立方法。スターター追加や店で補う方式へ戻さない。
- 勝利条件、ターン／手札／場／デッキ構成、相手、チャットによる方針と具体的な一手の伝え方、本人の理解・判断・自律プレイ。
- 図鑑／タイトルの解放履歴はカード所持枚数ではなく、移行時の図鑑登録から思い出を生成しない。
