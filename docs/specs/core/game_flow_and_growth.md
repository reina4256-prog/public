# 基本ゲーム進行・育成仕様

状態: 実装済み

## 対象範囲

起動、新規開始、性格診断、AIキャラクターの基本状態、通常育成、寿命までのゲームループを扱う。進化と世代交代の詳細は `evolution_lifecycle_inheritance.md`、言葉とタスクは `ai_words_and_tasks.md` が所有する。

## 現在の実装仕様

- ゲームはクォータービューの島でAIキャラクターを育成・観察するブラウザゲームで、Electron/Steam版と通常ブラウザ版が同じソースを使う。
- 起動時はスタジオロゴからタイトルへ遷移する。タイトルには図鑑で解放した種族・進化形態が描画され、Y座標で奥行きを決め、ドラゴンは最前面になる。
- ニューゲームは性格診断と初期種族選択を通る。引継ぎで姿と性格を選んだ場合は診断を省略し、前世の基本形態と性格を使う。
- 基本能力は `intel`（賢さ）、`power`（活力）、`beauty`（美しさ）、`speed`（素早さ）。行動、職業課題、進化、闘技場、ダンジョンなどが参照する。
- 生存状態として体力、満腹度、機嫌、年齢、寿命、病気、過労などを持つ。通常行動で時間と欲求が進み、寿命到達で思い出生成と引継ぎへ進む。
- チャット指示と性格に基づく自律行動が共存する。タスク中に体力・満腹度が危険域へ入ると、神モードを除き過労防止処理が中断する。
- 性格は能力の偏りから判定され、種族・進化形態ごとのセリフへ反映される。
- 腐った食べ物や生魚は病気の原因になり、病気は寿命や機嫌へ不利益を与える。薬剤師系の薬や特効薬で対処する。
- UIは育成キャンバスとコマンドセンターを基本とし、各コンテンツは全画面または独立オーバーレイとして開く。

## 解放と主要な流れ

1. ロゴ、タイトル、新規開始または続きから。
2. 新規世代は性格診断または引継ぎ済みの姿・性格で開始。
3. 食事、睡眠、勉強、筋力訓練、ランニング、探索などで成長。
4. 師匠と遭遇し、1世代につき1つの職業を免許皆伝まで進める。
5. 条件を満たすと進化し、寿命後半は余生方針を選ぶ。
6. 寿命到達時に現在の姿を思い出化し、魂の引継ぎを選んで次世代へ進む。

## 永続状態とリセット境界

- 中心状態は `aiPet`。能力、欲求、年齢、現在姿、履歴、所持品、職業、言葉を保持する。
- `assets` は島の地形・施設・師匠拠点を保持する。
- 図鑑履歴と音楽館履歴は世代交代時に無条件で保持される。
- その他の能力、所持品、言葉、職業、姿・性格、マップ、Goldは引継ぎショップの選択に従う。

## 関連実装

- `main.js`: 初期化、ゲームループ、画面モード。
- `system.js`: 初期状態、性格診断、マップ、保存、音楽。
- `ai_core.js`: AI更新、状態、タスク、寿命、進化、引継ぎ。
- `view_renderer.js`: フィールドとキャラクター描画。
- `ui_controller.js`: 育成UIとコマンド。
