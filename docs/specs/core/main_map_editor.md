# 育成メイン画面・島自由エディット仕様

状態: 未実装・仕様確定

## 対象範囲

通常育成画面の島、地形、自然物、建物、橋等を、解放後にプレイヤーが並べ替える自由エディット機能を扱う。施設の建築条件と通常機能は [`world_items_and_facilities.md`](world_items_and_facilities.md)、建築士の通常進行は [`../careers/basic/builder.md`](../careers/basic/builder.md)、世代交代時のマップ保持は [`evolution_lifecycle_inheritance.md`](evolution_lifecycle_inheritance.md) が所有する。

## 現在の実装仕様

- 通常マップは `assets` / `map_data_v6` に地面、水、自然物、施設等を保存する。
- 初期島は地面タイルと2列または2行の川を生成し、手前側と対岸側へ自然物・施設を配置する。
- 開発用カタログには `terrain.png` 中段の横道、縦道、交差点を `road_h`、`road_v`、`road_x` として登録しているが、現行の初期島生成、通常建築、通常ゲーム進行には道路を配置する導線がない。
- オブジェクトは原則としてY座標順で描画し、AIの移動・探索・建築・施設入場は各 `assets` の位置を参照する。
- 開発用マップエディターはカタログから任意の項目を追加し、ドラッグ移動、拡大縮小、左右反転、削除、保存を行える。
- プレイヤー向けの解放クエスト、追加・削除を禁止した島編集、保存前経路検証は未実装。

## 主な状態と実装

- `assets` / `map_data_v6`: 現在の地形、自然物、施設、橋とそれぞれの位置・状態。
- `defaultCatalog` / `catalog`: マップ項目の描画定義。
- `main.js`: 開発用マップエディター、選択、ドラッグ操作。
- `view_renderer.js`: 地面・水・道路とその他オブジェクトのY座標描画。
- `ai_core.js`: AI移動、橋建築、施設目的地、世代交代。
- `casino_map_core.js`: 現在の2連橋による対岸到達判定。
- プレイヤー向け永久解放フラグ、解放クエスト、編集セッション状態は未実装であり、フィールド名は未決定。

## 他コンテンツとの依存関係

- エディットは既存施設の建築・解放条件を代替しない。未建築物の追加や既存物の削除はできない。
- 保存後もAIが必要地点へ移動し、施設入場、探索、職業、橋、城、防衛、カジノ等の既存処理を継続できなければならない。
- 地形変更により歩行可能領域そのものを変形できるため、見た目だけでなく移動判定も保存後の地形へ追従させる。

## 確定している将来仕様

### 解放

- ある世代で建築士を免許皆伝し、魂の引継ぎで建築士ライセンスを引き継いだ場合だけ、次の世代で建築士と会話して専用クエストを受注できる。
- 専用クエストを達成すると自由エディットを解放する。
- 一度解放すれば、以後の世代ではマップ引継ぎの有無にかかわらず永久に利用できる。
- ゲーム設定のデータ管理から行う完全初期化では解放状態も失う。
- 解放済みの状態で完全初期化を選ぼうとした場合は、自由エディット機能も失われることをゲーム内デザインの多段階確認UIで事前に警告する。Windowsやブラウザのシステム `alert` は使用しない。

### 編集対象

- 編集開始時点で自分のマップに実在する項目だけを並べ替える。
- 新しい地形・自然物・建物等の追加、複製、削除はできない。
- プレイヤー建築物、師匠施設、畑、小屋、橋、城、カジノ、カードショップ、余生で完成して現在有効なモニュメント、森、山、洞窟、クリスタル、地面、川を含む、現在マップ上のすべての通常配置物を編集対象にする。通常プレイで使われていない開発カタログ専用の道路3種 `road_h`、`road_v`、`road_x` は初版のプレイヤー向け島自由エディットから除外する。モニュメントの位置変更は遺産効果や有効期間を変更しない。
- 橋を2個かけていない状態では、橋の先にある対岸側の配置物を移動できない。
- 対岸側編集の解放は橋の単純な個数ではなく、2本以上の橋が実際に連結し、手前側から対岸まで渡れることを条件にする。2本が離れている等、実際に渡れない配置では対岸側を編集できない。

### 編集内容

- 配置物の移動。
- 左右反転。
- 前後順。
- 大きさ、回転、表示・非表示は変更できない。
- 地面を移動して島の形を変え、従来は移動できなかった場所を歩行可能な場所へ変更できる。
- 地面を移動して空いた場所は、位置に応じて海または川へ置き換える。
- 地形変更後に歩行可能になった場所には、ほかの配置物も移動できる。
- 地形はクォータービューのマス単位で移動する。陸地を海マスへ移すと移動先が陸地、元の場所が海になり、川マスへ移すと元の場所が川になる。地形の総マス数は増減させない。
- 建物、自然物等の地形以外の配置物はマスへ固定せず、自由座標へ移動できる。
- 建物同士が重なる配置は保存できない。
- 地面の上へ配置する建物、施設、自然物等は、種類を問わず互いに重ねられない。

### 保存検証

- 編集中の見た目だけではなく、保存後の歩行可能地形、AI移動、各目的地への到達可能性を検証する。
- 編集の最後に、プレイヤーがAIの開始位置を配置する。AIは編集後の地形で実際に到達可能な範囲だけへ置ける。
- 配置したAI開始位置を基準に、小屋、畑、各店舗、城、カジノ等の入口、各師匠拠点、森、山、洞窟、クリスタル、川・海の釣り地点、橋の両岸を含む全必要目的地への到達可能性を検証する。
- 必要目的地の有無にかかわらず、すべての陸地マスがAI開始位置から陸路または有効な橋でつながっていることを保存条件にする。橋で接続されていれば離れた陸地も有効とする。
- 一つでも到達検証に失敗した場合、または保存によってAIが移動不能になる場合は保存できない。
- 保存不可の場合は問題をゲーム内デザインのUIで警告し、配置を保存せず編集を継続する。Windowsやブラウザのシステム `alert` は使用しない。
- 配置物の重なりや到達不能は編集中から赤い配置枠で示す。最終保存時は全体を再検証し、到達不能な施設名や問題の橋等を一覧表示する。一覧から問題箇所を選ぶと、その場所へカメラを移動する。

### 橋

- 橋は川または海をまたぎ、両端が歩行可能な陸地へ接続し、橋上から両岸へ実際に移動できる場合だけ有効とする。
- 橋は建物、自然物、別の橋と不正に重ならないようにする。
- 現在の川幅を渡る2本連結だけに限定せず、3本以上を連結した長い橋も作れる。
- 有効条件を満たさない橋が一つでもある配置は保存できない。

### 世代交代

- 編集済みの島配置は、魂の引継ぎで `マップ引継ぎ` を選んだ場合だけ次世代へ保持する。
- `マップ引継ぎ` を選ばなかった場合は編集済み配置を失い、新しい通常マップを使うが、自由エディット機能の永久解放状態は保持する。
- 自由エディット済み配置がある状態で `マップ引継ぎ` を選ばずに進めようとした場合は、配置が初期化されることをゲーム内デザインのUIで警告する。この警告は配置消失の確認であり、自由エディット機能の永久解放は失われない。
- 島配置の通常保存、ログイン中のクラウドバックアップ・復元、マップ引継ぎは、現在の `assets` / `map_data_v6` と同じ保存境界を使う。

### 解放クエスト

- クエストでは、最初から手前側へ配置されている薬局、レストラン、森、山、橋を架けずに行ける川、海の6地点を調査する。
- 6地点は好きな順番で調査できる。
- 調査は探検行動や別の師匠との会話ではなく、各対象地点へ入ると通常の師匠会話UIを開き、その場所で建築士との調査会話を行う形式にする。
- 建築士を移動キャラクターとして実際に追従させず、各地点の調査会話時だけ師匠会話UIへ登場させる。ただし、会話上は建築士がAIへ同行して島を調査していることを明記する。
- 6地点の調査後は建築士へ戻り、通常のRank課題や師匠の思い出カード取得と同じ `報告する` 導線で最終報告する。報告完了時に島自由エディットを永久解放する。
- クエストを未完了のまま世代交代する場合、魂の引継ぎでライセンス引継ぎを選ぶと受注状態と地点別調査進捗を次世代へ継続する。ライセンス引継ぎを選ばなければ、受注状態と全進捗をリセットする。

### 編集入口と地形範囲

- 解放後は建築士との会話から島自由エディットへ入る。
- 島を構成する地形マスの総数は固定し、地形を追加・削除しない。
- 編集可能範囲を長方形へ限定せず、固定枚数の地形マスを周囲の海へ移動して島を変形できる。最終的に非常に縦長・横長・不定形の島になることも許可する。

### 編集セッションと操作

- エディット中はゲーム時間、体力、満腹度、年齢、天気、AIタスクをすべて停止し、通常育成を進行させない。
- 編集開始時のマップを作業用コピーとして扱い、保存が成功するまで通常の `assets` へ反映しない。
- 右ドラッグまたは中ドラッグでカメラを移動し、マウスホイールで拡大・縮小できる。
- 島全体を確認できるミニマップを表示する。
- 配置物一覧から選択中の対象へカメラを移動できる。
- 編集の最後にAIを置く専用操作を用意する。
- `元に戻す`、`やり直す`、`保存して終了`、`変更を破棄して終了`を用意する。
- リセットは `選択物を編集開始時の位置へ戻す`、`地形だけを最後に保存した状態へ戻す`、`地上配置物だけを最後に保存した状態へ戻す`、`マップ全体を最後に保存した状態へ戻す`を別々に用意する。

### 描画順

- 手動の前後順は建物、施設、自然物等の固定配置物同士へ適用する。
- 歩行中のAIは固定順に含めず、Y座標に応じて自然に配置物の手前・奥へ切り替える。
