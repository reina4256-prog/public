# 同じ子の言葉の星座と音声入出力

## 現在の実装仕様

2026-11-09ユーザー依頼による新方式共通UIへの追加。検証・公開状態は[現行handoff](../../CURRENT_IMPLEMENTATION.md)を参照。独立見本を実本人の証拠と混同しない。

- learning／island／dungeonの3入口で同じ本人のstate・知識・ノート・自由入力を保持。旧AI／通常ゲームの保存形式は変更しない。
- `experimental_word_voice.js`は音声認識と読み上げを独立提供する。文字→文字、音声→文字、文字→音声、音声→音声を選べ、文字の会話は常に表示する。読み上げは初期オフ・音量／停止付き。オン／オフ・音量は今回起動中だけ。声の選択だけは端末内の独立localStorage `wordVoiceProfiles:v1`へ言語別に保存し、本人state・知識・ノート・共通自由入力・旧ゲーム保存は変更しない。
- 明示押下でSpeechRecognition／webkitSpeechRecognitionを一度開始し、確定認識文を下書きへ追記する。修正後に共通送信でき、自動送信・常時録音・音声ファイル保存はしない。1000文字を超える追記は下書きを変えず案内する。
- 認識／読み上げは既存7言語設定に従う。認識と本人の理解を分け、拒否・無音・未対応・サービス失敗は本人の未理解として記録しない。送信時のplayer記録に入力手段・認識文／認識言語を添える。本人へ渡す原文は最終送信文。新解釈規則は追加しない。
- 音声がブラウザーの認識サービスへ送信される場合がある旨を画面に示す。未対応環境では機能を個別に無効表示し、文字経路を維持。APIの存在だけで認識サービス成功とはしない。外部有料API・鍵・モデルは追加しない。
- 2026-11-10の読み上げ修正依頼：表示済み返答をそのまま読み、「しぐさの読み上げ」という接頭辞は発声しない。しぐさ・観察・attendは専用ナレーター、本人の会話は出会った種族の選択声で読む。ナレーターに確保した実音声は全11種族の会話候補から除外する。種族間の会話声は共有できる。音程変更だけで別音声と扱わない。
- 全7設問の回答後、サイン前に種族別の声選択・試聴画面を開く。初期選択は出会う種族。11種族の切替は試聴対象だけを変え、設問結果の姿／土台／生活／発話様式を変えない。会話3例としぐさ1例を選んだ声で聞ける。試聴は学習・本人発話・対話記録・本人保存を作らず、読み上げオンにも変更しない。設問へ戻れる。既存の子は会話欄の音声設定から同画面を開ける。
- 利用可能な声はブラウザー／端末提供の現在言語の実音声。同言語の声が2つ未満なら別声が必要な案内を表示し、文字だけで先へ進める。同じ声や既定音声への無言fallbackはしない。遅延取得はvoiceschangedで更新。保存声が消えたときは再選択を案内し、端末の声で明示的に選び直せる。保存失敗時は案内し起動中の選択を保つ。
- 入力開始・停止・pause・非表示・言語変更・タイトル／新規開始・星座開始・声選択開始／変更／終了で停止。声選択中は世界進行と通常返答の読み上げを止める。旧認識の遅延到着は世代番号で破棄する。
- ユーザー確認は読み上げ部分の上記指摘のみ。他の音声入力・星座機能はユーザー未試用であり、Codex検証結果と区別する。
- `experimental_word_constellation_live.js`は現在知識の読取投影。初期生活意味／関係、経験由来の習得、感情教示の限定知識、個体名、説明語、現地教示語を星で示す。最初から知る土台と後の学びを区別し、土台なしの空状態を案内する。
- 線は明示された教示／経験IDから元記録へ、または呼び名から対象への結び付き。初期土台は当時実際に使った意味／関係から入力記録へつなぐ。線から新しい意味関係・原因・感情・真偽を生成しない。初期土台へ架空原文を足さず、異なるscopeの習得を統合しない。
- 元入力は現セッションの既存report timelineと現地inputsの原resultから参照し、本人記録・経験とID対応する。旧記録に原文がない場合は欠落を表示し復元しない。未知／部分理解原文は別欄で参照し、後知識で原当時理解を変更しない。
- 星／記録／接続先選択、検索、拡大縮小、全体復帰、スクロール、キーボード操作、選択周辺強調を持つ。正確な知識数値・確率・数値詳細モードなし。閲覧中は世界進行を止め、学習・経験・本人記録を書換えない。閲覧状態は本人保存対象外。
- 独立見本は保持し、固定見本記録は持ち込まない。日記captureと140/129/138母数へ追加しない。七言語表示を更新し、プレイヤー原文・呼び名・保存IDは非翻訳。
