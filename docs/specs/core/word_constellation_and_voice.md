# 同じ子の言葉の星座と音声入出力

## 現在の実装仕様

### 2026-11-11：加工可能な音声・生成元の分離

- ユーザーはPC内生成①で試し、将来の外部生成②を追加しても①へ戻せる方式を依頼。`experimental_word_audio_provider.js`が生成、`experimental_word_voice_effects.js`がデコード／加工／再生、既存voiceが停止・設定・入力との排他を所有する。音声生成元の契約は`listVoices({signal,locale})`と`synthesize({text,voice,locale,pitch,rate,signal}) -> encoded audio ArrayBuffer`。外部サービス／サーバー／課金／鍵は今回追加せず、②の実装済みとはしない。
- 端末音声は既定のまま残し、同じ子の声欄で「PC内のVOICEVOX（演出付き）」を明示選択、接続ボタンで`http://127.0.0.1:50021/speakers`を取得。ページ表示／方式切替だけでは接続・文章送信をしない。VOICEVOXの別途起動が必要。接続許可の設定は自動変更しない。[試用手順](../../word/VOICE_TRIAL.md)を参照。
- VOICEVOXは日本語だけ。talkのstyle ID・speaker UUIDで声を識別し、歌唱styleは候補にしない。明示した試聴／読み上げの表示文のみを`audio_query`、返されたqueryを`synthesis`へ渡す。ログ／本人state／ノートを一括送信せず、生成音声を永続保存しない。しぐさは端末の専用ナレーター・標準pitch/rate・無加工を維持し、会話と別の実声を使う。現在言語の端末声が少なくとも1つ必要。
- 姿に応じたfilter・金属的な振幅変調・有限3tapのecho・低域補強を組合せ、dryの声を残す。「この子らしい響きの強さ」0〜1・.05刻み、初期.65、0は演出なし。会話試聴と実会話へ同じ加工を適用。ピーク抑制と0〜1音量を最後に適用する。別種族一覧／種族数は表示しない。
- `wordAudioSources:v1`は言語ごとのsource、生成元別・外見別のvoice identity、生成元共通・外見別のeffects強度を独立保存。既存`wordVoiceProfiles:v1`の端末声・ナレーター・pitch/rateは維持。①→将来②→①でも選択声を上書きせず、再選択不要で復帰できる設計。再読込後は明示的な接続が必要。声の欠落／言語非対応／失敗では無言で別声や生成元へfallbackしない。文字経路を維持する。
- 接続15秒・生成120秒で通信を打切り、停止・非表示・入力／認識開始・画面／言語／声／方式／演出変更でAbortControllerと世代番号により遅延再生を防ぐ。Web Audioのsource・oscillator・echo接続も停止／切断する。本人の理解・試聴記録にはしない。
- 選択声の`VOICEVOX:話者名`クレジットを声欄と会話の音声設定に表示し、公式利用条件へのリンクを設ける。各音声ライブラリの利用条件も利用者が確認する。エンジン／モデル／音声ライブラリをゲームへ同梱しない。今回の実機確認・未確認範囲は現行handoffで区別する。

### 維持する共通仕様

2026-11-09ユーザー依頼による新方式共通UIへの追加。検証・公開状態は[現行handoff](../../CURRENT_IMPLEMENTATION.md)を参照。独立見本を実本人の証拠と混同しない。

- learning／island／dungeonの3入口で同じ本人のstate・知識・ノート・自由入力を保持。旧AI／通常ゲームの保存形式は変更しない。
- `experimental_word_voice.js`は音声認識と読み上げを独立提供する。文字→文字、音声→文字、文字→音声、音声→音声を選べ、文字の会話は常に表示する。読み上げは初期オフ・音量／停止付き。オン／オフ・音量は今回起動中だけ。声・高さ・速さは同一originの端末内独立localStorage `wordVoiceProfiles:v1`へ言語・外見別に保存し、本人state・知識・ノート・共通自由入力・旧ゲーム保存は変更しない。
- 明示押下でSpeechRecognition／webkitSpeechRecognitionを一度開始し、確定認識文を下書きへ追記する。修正後に共通送信でき、自動送信・常時録音・音声ファイル保存はしない。1000文字を超える追記は下書きを変えず案内する。
- 認識／読み上げは既存7言語設定に従う。認識と本人の理解を分け、拒否・無音・未対応・サービス失敗は本人の未理解として記録しない。送信時のplayer記録に入力手段・認識文／認識言語を添える。本人へ渡す原文は最終送信文。新解釈規則は追加しない。
- 音声がブラウザーの認識サービスへ送信される場合がある旨を画面に示す。未対応環境では機能を個別に無効表示し、文字経路を維持。APIの存在だけで認識サービス成功とはしない。外部有料API・鍵・モデルは追加しない。
- 2026-11-10の読み上げ修正依頼：表示済み返答をそのまま読み、「しぐさの読み上げ」という接頭辞は発声しない。しぐさ・観察・attendは専用ナレーター、本人の会話は出会った種族の選択声で読む。ナレーターに確保した実音声は全11種族の会話候補から除外する。種族間の会話声は共有できる。音程変更だけで別音声と扱わない。
- 最新の画像付き修正依頼：全7設問後の「はじめまして」画面に、回答で決まった子だけを表示し、その右に声選択・高さ・速さ・試聴を組み込む。濃紺／水色の既存文書UIを共用し、下にサイン欄を置く。狭い画面は姿→声設定→サインの縦並び。独立した白い声選択dialog、他種族切替、種族数の案内は出さない。内部の外見別保存は保ち、設問結果の姿／土台／生活／発話様式を変えない。
- 高さpitchは0.50〜1.50、速さrateは0.60〜1.40を0.05刻み、標準は各1.00。「標準に戻す」はこの子の高さ・速さだけを戻す。会話の試聴と実返答へ同じ値を適用し、しぐさナレーターは各1.00を維持する。端末／音声エンジンで調整幅・聞こえ方が異なる旨を示す。旧声設定に調整値がなければ標準、保存／入力値は有限数と範囲を検証し、知識として保存しない。
- 会話3例と折畳み内のしぐさ1例を試聴できる。試聴は学習・本人発話・対話記録・本人保存を作らず、読み上げオンにも変更しない。「書き直す」は従来の設問へ戻る。既存の子は音声設定から同じ姿＋声欄を開き、サイン・設問をやり直さず閉じられる。端末の声で選び直す場合も他の外見の選択／調整値を消さない。
- 端末方式で利用可能な声はブラウザー／端末提供の現在言語の実音声。同言語の声が2つ未満なら別声が必要な案内を表示し、文字だけで先へ進める。同じ声や既定音声への無言fallbackはしない。遅延取得はvoiceschangedで更新。保存声が消えたときは再選択を案内し、端末の声で明示的に選び直せる。保存失敗時は案内し起動中の選択を保つ。VOICEVOX方式の条件は上記追加節を適用。
- 入力開始・停止・pause・非表示・言語変更・タイトル／新規開始・星座開始・声選択開始／変更／終了で停止。声選択中は世界進行と通常返答の読み上げを止める。旧認識の遅延到着は世代番号で破棄する。
- ユーザー確認は読み上げ部分の上記指摘のみ。他の音声入力・星座機能はユーザー未試用であり、Codex検証結果と区別する。
- `experimental_word_constellation_live.js`は現在知識の読取投影。初期生活意味／関係、経験由来の習得、感情教示の限定知識、個体名、説明語、現地教示語を星で示す。最初から知る土台と後の学びを区別し、土台なしの空状態を案内する。
- 線は明示された教示／経験IDから元記録へ、または呼び名から対象への結び付き。初期土台は当時実際に使った意味／関係から入力記録へつなぐ。線から新しい意味関係・原因・感情・真偽を生成しない。初期土台へ架空原文を足さず、異なるscopeの習得を統合しない。
- 元入力は現セッションの既存report timelineと現地inputsの原resultから参照し、本人記録・経験とID対応する。旧記録に原文がない場合は欠落を表示し復元しない。未知／部分理解原文は別欄で参照し、後知識で原当時理解を変更しない。
- 星／記録／接続先選択、検索、拡大縮小、全体復帰、スクロール、キーボード操作、選択周辺強調を持つ。正確な知識数値・確率・数値詳細モードなし。閲覧中は世界進行を止め、学習・経験・本人記録を書換えない。閲覧状態は本人保存対象外。
- 独立見本は保持し、固定見本記録は持ち込まない。日記captureと140/129/138母数へ追加しない。七言語表示を更新し、プレイヤー原文・呼び名・保存IDは非翻訳。
