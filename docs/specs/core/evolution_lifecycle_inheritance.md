# 進化・余生・世代交代・引継ぎ仕様

状態: 実装済み

## 対象範囲

進化判定、進化演出、寿命、免許皆伝後の余生、死亡、思い出生成、魂の引継ぎ、強くてニューゲームを扱う。

## 現在の実装仕様

### 進化

- 11種族に分岐・多段階・クロス進化を含む進化ツリーがある。
- 進化条件は能力、行動、性格、病気・薬の扱い、過去の姿など複数要素を参照する。
- 進化時は対応動画を使い、進化後の姿と履歴を更新する。
- ダンジョンの系譜特性は現在姿だけでなく `pastSkins` を参照する場合がある。
- 病気の放置や薬の乱用から闇落ち系の特殊進化へ到達する場合がある。

### 免許皆伝後と余生

- 1世代で1職業を皆伝すると、称号・能力報酬を受けて余生方針を選ぶ。
- 現在の余生タスクは `life_mentor`、`life_monument`、`life_seeker`、`life_guardian`、`life_author`、`life_slowlife` の6系統。
- 弟子、モニュメント、秘伝書、能力成長、施設保全など、方針ごとに遺産や効果が異なる。
- 余生タスクは年齢を進める。大事業は体力・満腹度20未満で開始せず、スローライフは例外。
- マイホーム内の余生は屋内状態を維持し、自動反復と早送りを利用できる。

### 死亡と思い出

- `age >= lifespan` で死亡処理へ進む。
- 現在の種族・進化形態から世代付きの思い出を生成してから引継ぎ画面を開く。
- 同一世代で同一人物カードを重複取得しないなど、世代単位の獲得ガードがある。

### 魂の引継ぎ

- 選択肢は能力、持ち物、語彙・記憶領域、職業ライセンス、姿と性格、マップ、所持金。
- 基本費用は能力500G、持ち物300G、語彙400G、ライセンス800G、姿と性格200G、マップ300G、Gold500G。
- 能力引継ぎ率は10%刻みで、世代数に応じ上限が上がる。
- 支払いには手持ちGoldと金庫Goldを合算する。
- 選ばなかった要素は最終警告に列挙する。
- 図鑑と音楽館は選択にかかわらず保持する。
- チュートリアル履歴も選択にかかわらず保持する。保存境界と非表示方針は [`tutorial_archive.md`](tutorial_archive.md) が所有する。
- 持ち物を引き継ぎ、マップを引き継がない場合は倉庫・冷凍庫の中身を手持ちへ退避する。冷凍品は鮮度を再開する。
- マップ引継ぎは施設、店舗成長、金庫、カジノコイン、購入済みトランプ、カジノ設備を保持する。
- マップを引き継がない場合、マップ所有のカジノ状態はリセットする。
- 美容師皆伝済みで姿と性格を引き継ぐと、カラーとオーラも引き継ぐ。
- 余生で作った弟子、モニュメント、秘伝書は個別の有料選択肢となり、選ばなければ消滅する。

### 職業と次世代

- 通常は皆伝Rank 10だけが恒久的な職歴として扱われ、中途Rankや破門状態は次世代で未入門へ戻る。
- ライセンス引継ぎは職業Rankと、次世代限定の特別依頼対象を保持する。
- 過去能力が条件を満たすと、次世代の師匠初対面で特待生・即皆伝が発生する場合がある。
