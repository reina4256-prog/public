# 新方式ダンジョン・独立試作

## 現在の実装仕様

2026-11-08、ユーザーは公開URLで今回も「はじめから」育てる同じ子をダンジョンへ連れていき、共通知識と現地で学ぶ知識の働きを比較することを希望。中央旧ダンジョン画面・右解釈／ノート・下状態、共通自由入力、呼び名＋個体への危険教示から回避、指示と違う選択の通知まで採用した。初版の七択／理解チェックだけの画面を共通UIへ改修した。本書はこの仮接続を所有し、既存4d12担当・日記本接続の完了とは別に扱う。

- 入口はexperimental_word_island.html／experimental_word_dungeon.html。いずれも島の「はじめから」で今回の子を育て、「ダンジョンへ行く」で移動する。npm run start:words:dungeonは専用一時profileの非保存入口。旧ダンジョン・5階訓練は置換しない。
- history.pushStateで同一document／同一stateを保ち、島worldを停止、perceptionをdungeon:room:1へ切り替える。帰還時は島へ戻す。pendingQuestion／lastOutputは場所変更時に外し、直前会話を新しい場所の答えへ転用しない。原入力／理解／ノートは削除しない。再入場は初期位置・ターンへ戻るが知識は保持する。
- 固定9×7の一部屋、本人(5,3)・動かない相手(6,3)・階段(7,1)。床・壁・階段は旧スカル画像の原切抜き。本人の現在appearanceのidleと、同じ姿へ旧敵filterを適用した赤い相手を表示し、ぜんまい等へ固定しない。相手マスへは侵入せず、戦闘・攻撃被害・ドロップはない。旧ターン・戦闘・語彙処理は呼ばない。
- 右側は島と共通の自由入力・会話／ノート。下部はターン・理由と既存空腹／体力表示。島の身体値は探索中凍結し、独自HPは新設しない。通常入力は既存core.receiveへ渡す。生活お願いの理解と現地での実行可能性を分け、島の木陰や生活経験からダンジョンの休息場所を補わない。
- 相手／階段を地図で押すか指すボタンで注目指定。呼び名は既存coreの候補・採用・根拠更新を用いる。日本語例「これはアカだよ」、他六言語は同じ個体名更新に渡す限定表記を追加。名前だけで種族全体・出口機能・危険性を習得しない。島の特定対象の名前を見た目が同じ別個体へ転移しない。
- 警告は「これは危ない／この相手は危ない」と七言語の対応表記（単一終端記号を許可）。report関係が当該scene／localeで理解でき、今回の赤い相手を一つ指している場合、その個体についてplayerから聞いた警告として保持する。関係不足／注目なし／階段等scope外は取得しない。警告の真偽・戦闘経験・一般的な危険語義や別個体への知識を生成しない。
- 指して「そこへ行って／そこに行って」（七言語対応）と頼める。walk意味とrequest関係を当該場面で理解できる場合だけ有限経路へ渡す。未理解は非移動・ターン非加算。警告がない相手へは近づける範囲へ進み、警告後はその相手への接近依頼や相手の隣からの自主判断で距離を取る。指示と違う選択は吹出し／会話／状態欄へ理由を表示。gestureでは会話をしぐさに留め、状態欄で理由を示す。
- 指示なしは有限経路で階段を探す。AUTO任意開始／停止、入力中・一時停止・非表示・指示・指す操作・帰還・到着で停止。到着後は進行を止め、会話／ノート閲覧は可能。任意自然文の作戦解釈・人格全体・敵戦闘AIの完成を意味しない。
- state.dungeonLearning.inputsは専用入力の原input／当時understandings／knowledgeBefore／warningsBefore、warningsはscene/target/inputId、actionsは依頼inputId／前後位置／理由／警告出所。既存core原資料と所有を分け、後の知識で原理解を書き換えない。既存ノート投影に警告投影を加え、島へ戻った後と試遊レポートにも残す。閲覧・言語変更・往復は学習／経験を再加算しない。
- 公開Webの今回起動中だけの仮接続。再読込・実ページ離脱後の永続保存は未実装。wordStorageがある開発Electronでは入口非表示、旧保存形式は変更しない。言語設定は既存島の仕組みを継承し、本人知識をWeb Storageへ保存しない。公開URLへ自動個人試遊収集を追加しない。
- 所有はexperimental_word_dungeon_learning.js／experimental_word_dungeon_view.jsと共通experimental_word_learning_ui.js。初版core単独API／testsは保持するが旧チェック式UIは現行入口で使わない。今回APIを旧140/140枠・129子・138登録APIへ加算しない。

## 確定している将来仕様

- 各コンテンツで共通自由入力・会話・見えているものへの教示を使う。限定表記／判断を任意自然文や全領域の完成形へ拡張しない。
- 本編の所有は[dungeon_common.md](dungeon_common.md)。日記本接続4g・星座工程／時期未確定・4d12／4e全体未完・4f非移行・前倒しなしを維持。

## 構想段階の案

- 罠／ギミック追加時は旧素材を使えるとのユーザー意見を受領。戦う敵へ拡張する場合も本人と同じ姿を赤く表示する方針。戦闘・罠／ギミック規則は未実装。
- 探索素材と経営、作戦と闘技場／防衛戦、実体験とカードを結ぶ方法は継続相談。今回実装しない。
