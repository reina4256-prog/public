# 新方式ダンジョン・独立試作

## 現在の実装仕様

- 2026-11-09ユーザー指定：新版の「本人の判断で1ターン」ボタンは撤去する。自由入力の理解済み依頼による実行と、危険と判断したときの理由付き別行動は保持する。AUTO開始／停止は指示なし探索の任意操作であり、理解済み目的地指示の開始に押す必要はない。目的地継続中に押すと停止する。ボタン撤去は方向指示や方向語学習の追加を意味しない。
- 同日の補足：原レポートの方向／一歩の発言は、前回の歩行教示案内を受けて一歩の動かし方を試したもの。方向を教えたいという要望ではない。今回life=trueの子はwalk初期既知で、歩行を教え直す必要はない。対象への位置参照とは別の、方向移動の実行／その教示経路は追加しない。対象参照の誤解析と古い聞返しへの停滞はボタン撤去で修正されたと扱わない。

2026-11-08、ユーザーは公開URLで今回も「はじめから」育てる同じ子をダンジョンへ連れていき、共通知識と現地で学ぶ知識の働きを比較することを希望。中央旧ダンジョン画面・右解釈／ノート・下状態、共通自由入力、呼び名＋個体への危険教示から回避、指示と違う選択の通知まで採用した。追加確認では対象指定ボタンと定型文依存を否定し、「知らない言葉は会話や教示で学び、覚えた知識で指示を理解する」方式2を採用。本書はこの仮接続を所有し、既存4d12担当・日記本接続の完了とは別に扱う。

- 入口はexperimental_word_island.html／experimental_word_dungeon.html。いずれも島の「はじめから」で今回の子を育て、「ダンジョンへ行く」で移動する。npm run start:words:dungeonは専用一時profileの非保存入口。旧ダンジョン・5階訓練は置換しない。
- history.pushStateで同一document／同一stateを保ち、島worldを停止、perceptionをdungeon:room:1へ切り替える。帰還時は島へ戻す。pendingQuestion／lastOutputは場所変更時に外し、直前会話を新しい場所の答えへ転用しない。原入力／理解／ノートは削除しない。再入場は初期位置・ターンへ戻るが知識は保持する。
- 固定9×7の一部屋、本人(5,3)・動かない相手(6,3)・階段(7,1)。床・壁・階段は旧スカル画像の原切抜き。本人の現在appearanceのidleと、同じ姿へ旧敵filterを適用した赤い相手を表示し、ぜんまい等へ固定しない。相手マスへは侵入せず、戦闘・攻撃被害・ドロップはない。旧ターン・戦闘・語彙処理は呼ばない。
- 右側は島と共通の自由入力・会話／ノート。下部はターン・理由と既存空腹／体力表示。島の身体値は探索中凍結し、独自HPは新設しない。初回の島描画前に入場しても、現在値をダンジョンの描画で表示する。通常入力は既存core.receiveへ渡す。生活お願いの理解と現地での実行可能性を分け、島の木陰や生活経験からダンジョンの休息場所を補わない。
- 対象を指す専用ボタンは撤去。呼び名／位置／外見と、説明／お願いの部分を組み合わせて解析する。日本語では「横／隣／そば／近く」「赤い」「右上」等を候補抽出に使うが、解析できるだけでは既知としない。まだ知らない参照は一意の候補を輪郭で示して確認し、候補なし／複数なら見た目・本人からの位置を自由入力で尋ねる。地図クリックの任意補助は残すが、入力の前提にはしない。名前の候補は島の有効な同一個体の連想と現地確認語から照合し、別個体や競合を順番で選ばない。
- 実試遊で止まった存在報告＋理由＋依頼（例「右に敵がいるから避けて」）を位置・個体名・お願いへ分ける。右／左／上／下は本人の現在位置からの半平面、斜めは両軸の共通部分として七言語で候補を絞る。「右」には相手と階段の二候補があり、近い順で決めない。続く「赤い」等の説明を同じ聞返しの条件へ累積し、矛盾時は対象を採用せず、否定回答で条件を外して説明をやり直せる。
- 同じ対象の聞返し中は、省略依頼の反復・同じ語の知識質問・まだ解釈できない説明で確認待ちを破棄しない。明示した別依頼／教示・共有coreが分かる別話題・言語変更・移動・往復で失効する。既知の挨拶は助詞を含んでも名付けへ誤分解しない。一意に示して呼び名を確認中のその呼び名の回答、または呼び名なしの一意候補へ尋ねた短い呼び名の回答も、新しい確認教示として扱う。まだ候補が複数なら呼び名だけで決めず、名付け関係不足も補わない。
- 未知の短い単語や「階段わかる？」等の対象知識質問は、知らない呼び名について位置・外見を尋ねる入口になる。既知なら教わった個体を示して答え、移動／一般性質の取得はしない。未知語から内部の階段／敵IDへ自動対応しない。移動・回避の意味確認中は、肯定だけでなく、歩いてその場所へ行く／距離を取る等の限定した説明も七言語で受けられる。説明は元の確認質問への回答としてのみ扱い、namingと既存request／walkのscopeが必要。任意の定義文・任意自然文全般の完成ではない。
- 確認への「はい／うん／そうだよ」等（七言語対応）を新しい原入力として、今回のplace／locale／player範囲の確認教示lexiconへ結ぶ。語面・意味または個体ID・元入力ID・候補提案ID・確認入力IDを保持する。位置表現の確認は同じ部屋の現在位置からの参照に使い、個体名はその個体だけ。確認した対象を会話の注目先へ渡す。呼び名なしの対象確認は空文字の名前を学習せず、その後「避けて」等の省略依頼で注目先を使える。名前だけで敵一般の性質・出口機能・危険性を習得しない。原当時の未理解は非書戻し、確認だけでは元の依頼を再生せず、覚えた後の新しい依頼だけ実行する。
- 「階段にいって」の階段が未知なら、内部の出口IDから語義を補わず、どれか尋ねる。例えば「右上にあるもの」の候補確認で呼び名を教えられる。「横にいるのは敵だから避けてね」は対象教示と回避依頼へ分け、既存naming／report／reason／requestとwalkの当該scopeが必要。知らないお願いは、近づく／距離を取る意味か確認する。確認後は同じ対象名と「行って／いって／向かって／進んで」「避けて／よけて／から離れて／には近づかないで」等の組合せを使える。二つの例文そのものの完全一致を実行条件にしない。他六言語も対象説明・移動／回避・確認の組立を持つが、自由文全般の完成ではない。
- 横は本人の左右の隣、隣／近くは上下左右の隣。参照候補では対応する説明語の全体を照合し、赤い等の一語だけ拾って未知の否定・選択肢・別指示を削らない。疑問符を含む入力を依頼や確認の肯定へ転用しない。対象知識質問だけを参照質問として別扱いにする。未対応の複数依頼・条件・否定は未理解を保持し、移動しない。確認後の別表記への適用は同じ言語／場面の意味範囲に留める。
- 警告の表記候補を見ただけで危険既知へしない。意味確認で教わった後、report関係と一意の赤い相手が分かる新しい警告だけを、その個体についてplayerから聞いたものとして保持する。関係不足／対象不明／階段等scope外は取得しない。敵という呼び名、回避のお願い、警告の意味と当該個体への報告、真偽・戦闘経験は別。回避依頼は危険知識がなくても距離を取る行動として実行できるが、恒常的警告へ変換しない。
- 移動／回避はwalk意味とrequest関係が当該場面で理解できる場合だけ有限経路へ渡す。未理解は非移動・ターン非加算。警告がない相手へは近づける範囲へ進み、警告後はその相手への接近依頼や相手の隣からの自主判断で距離を取る。指示と違う選択は吹出し／会話／状態欄へ理由を表示。gestureの本人発話はしぐさを保持し、確認内容は会話欄の補助案内として示す。回避／移動の理由は状態欄へ表示する。
- 初期生活語なしの子も、[2b歩行追補](../core/experimental_word_learning.md#walking-experience-learning)の実歩行と声かけからwalkを習得できる。同じworld／stateを往復で共有し、島での教示・現地の直後一歩の原証拠を分離する。walk不足を隠さず、実際に動いている間／一歩の直後に教える案内を出す。教示を受けただけで元依頼を再生しない。
- 「階段まで動いて／階段に移動して」等は、対象・方向助詞・移動動詞・丁寧さを組み合わせる。文全体を新しい名前として扱わない。「それであっているよ」等の肯定も対象／意味確認の新しい入力になる。理解された新しい移動依頼は、一歩後もsession.goalの原依頼ID・対象を保ち、有限経路で対象へ進む。階段到着、相手なら隣、非移動・危険による別判断で止める。入力開始／新入力・指す・一時停止・非表示・AUTO停止・帰還でも継続を取り消す。入力なしのAUTO探索と区別し、継続中の各歩にも原依頼IDと実判断を残す。
- 指示なしは有限経路で階段を探す。AUTO任意開始／停止、入力中・確認待ち・一時停止・非表示・指示・指す操作・帰還・到着で停止。確認待ちはAUTO探索も停止する。手動ターンボタンは設けない。移動／別話題／往復で古い確認を失効させ、無関係な「はい」で復活させない。到着後は進行を止め、会話／ノート閲覧は可能。任意自然文の作戦解釈・人格全体・敵戦闘AIの完成を意味しない。
- state.dungeonLearning.inputsは専用入力の原input／当時understandings／knowledgeBefore／lexiconBefore／warningsBefore／dialogueBefore・After／acquired、warningsはscene/target/inputId、actionsは依頼inputId／subject=self／intent／前後位置／理由／警告出所。依頼入力のspeaker／proposer=playerと実行主体selfを分離する。lexiconは今回追加の確認教示であり、coreの経験学習／初期語彙・関係を変更しない。既存core原資料と所有を分け、後の知識で原理解を書き換えない。既存ノート投影に確認語と警告投影を加え、島へ戻った後と試遊レポートにも残す。閲覧・言語変更・往復・同じ確認の反復は学習／経験を再加算しない。
- 確認教示はclarificationInputIdsで途中の説明入力を、confirmationKindで肯定／呼び名の回答／意味説明を区別して保持する。各入力のdialogueBefore／Afterと当時理解は後から更新しない。実レポートの原資料と、修正コードによる独立再生は別証拠とし、元レポートの未理解・行動0を書き換えない。
- 公開Webの今回起動中だけの仮接続。再読込・実ページ離脱後の永続保存は未実装。wordStorageがある開発Electronでは入口非表示、旧保存形式は変更しない。言語設定は既存島の仕組みを継承し、本人知識をWeb Storageへ保存しない。公開URLへ自動個人試遊収集を追加しない。
- 所有はexperimental_word_dungeon_learning.js／experimental_word_dungeon_view.jsと共通experimental_word_learning_ui.js。初版core単独API／testsは保持するが旧チェック式UIは現行入口で使わない。今回APIを旧140/140枠・129子・138登録APIへ加算しない。
