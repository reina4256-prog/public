# 新方式ダンジョン・独立試作

## 現在の実装仕様

2026-11-08、ユーザーが一部屋で探索・指示・自主判断を比較する案と、星座／日記同様の別URL形式を承認。初版の理解済み／未理解切替を承認し、本人が指示と異なる行動を選ぶ場合はプレイヤーへ伝えることを指定した。本書はその独立試作だけを所有する。本編の新理解規則や4d12担当の追加ではない。

- 入口は `experimental_word_dungeon.html`、ローカル起動は `npm run start:words:dungeon`。既存の独立見本と同じ静的HTML/JS/CSS配信で、本編の入口・旧ダンジョンを置換しない。公開先は同じGitHub Pagesの専用パス。
- 固定9×7マップ一部屋に本人、壁、出口、動かない危険源を置く。探索開始と危険の隣からの開始を選べる。床・壁は旧 `dungeon_render.js` のスカル用切抜きと同じ原画像・範囲、本人は既存robot画像・idle切抜きを使う。旧実行ループ・旧aiPet・旧語彙・旧保存は呼ばない。ターン／経路は試作用の有限処理であり、旧戦闘全体の移行完了を意味しない。
- 指示は上下左右、退避、出口へ、待機の七つの選択肢。自由入力や新しい自然文解釈は追加しない。表示は七言語、内部指示・理解状態・行動・理由は言語非依存ID。
- 理解状態は移動（待機を含む）／退避／出口指示の三つのチェック。設定を外した指示は「その指示はまだ分からない。」と反応し、行動なし・ターン非加算。設定切替は試作用で、教示・学習・忘却ではなく、過去の履歴を理解済みに書換えない。自主移動の能力は指示語の理解と分ける。
- 理解済みの移動・出口指示は、壁と危険源への進入を除き行動へ渡す。壁で実行不能なら待機理由を伝える。移動先が危険源とのマンハッタン距離1以下になる場合、または距離1以内で待機する指示の場合は、本人が隣接可能マスのうち距離を広げる方向を選ぶ。指示と異なる選択であることと「そちらは危ないから、別の方向へ離れるね。」を通知枠・履歴へ表示する。
- 指示なしの1ターンでは、危険との距離1以内なら離れ、それ以外は危険に隣接しない経路で出口を探す。指示由来／自主判断／指示と異なる選択、元指示、当時の理解、選んだ行動、理由、前後位置を別保持する。これは用意した試作判断で、本編本人の正式な判断・am/cp/cq資料へ読替えない。
- 自動進行は任意の開始／停止式。指示・理解状態切替・場面変更・リセット・画面非表示・到着で停止する。出口到着後は進行操作を無効化する。履歴は最大60件、連番を持ち、表示言語切替では行動しない。
- データはページのメモリだけ。再読込で初期化し、localStorage/sessionStorage・本編bridge・日記・知識・経験・所持品・報酬へ書込まない。Electronは専用一時profile、開発serverは自動試遊収集を有効化せず起動する。個人ログや試作履歴を歴史Bの供給へ数えない。
- 試作用の危険源は動かず、攻撃／被害・戦闘・ドロップ・教示学習・日記出力・カード化はない。既存の冒険家同行5階訓練は置換しない。
