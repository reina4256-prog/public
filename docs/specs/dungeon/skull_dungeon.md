# スカルダンジョン仕様

状態: 実装済み / 内部種別: `skull`

## 現在の実装仕様

- 育成中AIの活力、世代、年齢から最大HPを算出し、現在体力割合と満腹度を持ち込む。
- 育成画面の所持品をすべてIDとして持ち込め、所持上限は実質無制限。
- 道中に通常アイテムを生成せず、敵・罠・持込品を中心とする構成が現行生成ルール。
- 敵基礎HP・攻撃はクリスタルより高い。
- 生還または救助時は、残存した所持品と装備を育成所持品として置き換えて戻す。元からあった個体は鮮度等のメタデータを再利用する。
- 通常死亡では持込品を含めて所持品をロストする。
- 到達階×50Gを基礎報酬とし、通常死亡はGoldと追加報酬を半減する。
- 5階、10階、20階到達報酬として城建築用の呪われた礎石、漆黒の柱、覇者の紋章を得る。
- 正式入場時にスカルダンジョンの場所思い出を世代1回記録する。

## 城との依存関係

- 城建築素材の獲得元であり、闘技場・防衛戦解放へつながる。
- 素材を失った場合の再取得可否は、建築・報酬コード変更時に重複ガードを確認する。

## 確定している将来仕様

- 冒険家同行の共通固定マップ完了後、手持ち持込可、育成画面の能力・体力・満腹度反映、死亡時ロストというスカル固有規則を、専用のチュートリアル図鑑項目と実入場準備の確認情報へ接続する。共通訓練自体には実際の持込品を使わない。
- 到達可能最深階は初期5階とし、入居住人が現在の最深階から1階まで登って正式生還した実績3回ごとに5階ずつ伸ばす。下降中は最深階まで下り階段だけ、最深階以後は上り階段だけを生成して逆戻りできないようにする。上昇時は下降時の各階を保存・再利用せず、階ごとの地形、敵、罠、アイテムを新しく生成し直す。1階の上り階段から地上へ出た時点で通常生還とする。必要回数と解放幅は後から調整可能にする。
- 冒険家皆伝済み住人は本人の能力・装備・所持品で自律探索でき、画面外・オフライン時は同じ探索規則を決定的に省略計算する。住人が先に5・10・20階へ到達した場合も城素材を取得できる。
