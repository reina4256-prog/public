# スカルダンジョン仕様

状態: 実装済み / 内部種別: `skull`

## 現在の実装仕様

- 育成中AIの活力、世代、年齢から最大HPを算出し、現在体力割合と満腹度を持ち込む。
- 育成画面の所持品をすべてIDとして持ち込め、所持上限は実質無制限。
- 道中に通常アイテムを生成せず、敵・罠・持込品を中心とする構成が現行生成ルール。
- 敵基礎HP・攻撃はクリスタルより高い。
- 生還または救助時は、残存した所持品と装備を育成所持品として置き換えて戻す。元からあった個体は鮮度等のメタデータを再利用する。
- 通常死亡では持込品を含めて所持品をロストする。
- 到達階×50Gを基礎報酬とし、通常死亡はGoldと追加報酬を半減する。
- 5階、10階、20階到達報酬として城建築用の呪われた礎石、漆黒の柱、覇者の紋章を得る。
- 正式入場時にスカルダンジョンの場所思い出を世代1回記録する。

## 城との依存関係

- 城建築素材の獲得元であり、闘技場・防衛戦解放へつながる。
- 素材を失った場合の再取得可否は、建築・報酬コード変更時に重複ガードを確認する。
