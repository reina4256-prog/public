# クリスタル迷宮仕様

状態: 実装済み / 内部種別: `crystal`

## 現在の実装仕様

- 入場時最大HPは100、現在体力割合と満腹度を引き継ぎ、レベル1・経験0・基礎力10から開始する。
- 育成画面の所持品は持ち込まず、空のバッグで開始する。最大所持数は20。
- フロアで敵、罠、通常アイテムを生成し、現地調達で進む。
- 生還または救助時は、道中品と装備を新規個体として育成所持品へ追加する。
- 通常死亡でも入場前から持っていた育成所持品は失わないが、道中品は持ち帰らない。
- 到達階×100Gを基礎報酬とし、通常死亡はGoldと追加報酬を半減する。
- 冒険家からカジノ素材の噂を聞いた後、5階、10階、20階で幻惑のグラス、輝くカジノチップ、真理のダイスを得る。
- 同じカジノ素材が手持ち・施設・収納・マップ所有状態にある間は重複取得しない。消費・紛失後は再取得可能。
- 25階でカードショップ用素材を得る。
- 正式入場時にクリスタル迷宮の場所思い出を世代1回記録する。

## カジノ・カードショップとの依存関係

- カジノ素材は冒険家の噂、実接続された2連橋、建築士のレシピ解放と連動する。
- カードショップの建築はカジノ来店と深層素材に関係する。

## 確定している将来仕様

- 冒険家同行の共通固定マップ完了後、持込不可、Lv1開始、現地調達・成長というクリスタル固有規則を、専用のチュートリアル図鑑項目と実入場準備の確認情報へ接続する。共通訓練自体の能力・所持品をクリスタル本編へ持ち越さない。
- 到達可能最深階は初期5階とし、入居住人が現在の最深階から1階まで登って正式生還した実績3回ごとに5階ずつ伸ばす。下降中は最深階まで下り階段だけ、最深階以後は上り階段だけを生成して逆戻りできないようにする。上昇時は下降時の各階を保存・再利用せず、階ごとの地形、敵、罠、アイテムを新しく生成し直す。1階の上り階段から地上へ出た時点で通常生還とする。必要回数と解放幅は後から調整可能にする。
- 冒険家皆伝済み住人も持込不可・Lv1・現地調達で自律探索でき、画面外・オフライン時は同じ探索規則を決定的に省略計算する。住人が先に5・10・20・25階へ到達した場合もカジノ・カードショップ用素材を取得できる。
