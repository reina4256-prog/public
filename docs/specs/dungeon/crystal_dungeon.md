# クリスタル迷宮仕様

状態: 実装済み / 内部種別: `crystal`

## 現在の実装仕様

- 入場時最大HPは100、現在体力割合と満腹度を引き継ぎ、レベル1・経験0・基礎力10から開始する。
- 育成画面の所持品は持ち込まず、空のバッグで開始する。最大所持数は20。
- フロアで敵、罠、通常アイテムを生成し、現地調達で進む。
- 生還または救助時は、道中品と装備を新規個体として育成所持品へ追加する。
- 通常死亡でも入場前から持っていた育成所持品は失わないが、道中品は持ち帰らない。
- 到達階×100Gを基礎報酬とし、通常死亡はGoldと追加報酬を半減する。
- 冒険家からカジノ素材の噂を聞いた後、5階、10階、20階で幻惑のグラス、輝くカジノチップ、真理のダイスを得る。
- 同じカジノ素材が手持ち・施設・収納・マップ所有状態にある間は重複取得しない。消費・紛失後は再取得可能。
- 25階でカードショップ用素材を得る。
- 正式入場時にクリスタル迷宮の場所思い出を世代1回記録する。

## カジノ・カードショップとの依存関係

- カジノ素材は冒険家の噂、実接続された2連橋、建築士のレシピ解放と連動する。
- カードショップの建築はカジノ来店と深層素材に関係する。
