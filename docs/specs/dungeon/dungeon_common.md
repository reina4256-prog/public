# ダンジョン共通仕様

状態: 実装済み

## 対象範囲

スカルダンジョンとクリスタル迷宮が共有するローグライク基盤を扱う。持込・ロスト・固有報酬は各ダンジョン仕様を優先する。

## 進行

- 30×30を基本とする部屋・通路型フロアを自動生成し、階段で次階へ進む。
- フロアごとに地形、部屋、通路、敵、罠、アイテム、階段、モンスターハウスを再生成する。
- ダンジョン中は拠点時間と防衛襲撃等を止める。
- プレイヤーの現在種族・進化、体力割合、満腹度を入口で反映する。
- 入口では育成側の現在満腹度を引き継ぐ一方、ダンジョン側の基礎最大満腹度は探索ごとに100へ初期化される。パンや一部特性で探索中だけ100を超えられるが、現在の帰還処理は現在満腹度・最大満腹度のどちらも育成側へ戻していない。
- ターン制でAIと敵が行動し、AUTOは一定間隔でターンを進める。
- 視界、ミニマップ、ログ、状態、装備、所持品、現在作戦を表示する。ログは最新100行に制限する。

## 言葉と作戦

- 基礎語は上下左右移動、向き変更、戦う、回復、食べる、装備、外す、逃げる、使う、合成、調べる、名前、投げる、置く。
- 行動経験で語彙を閃き、各語は記憶容量を永続拡張する。
- 全基礎語を習得すると `作戦` を閃き、小屋の作戦会議とダンジョン指示UIを解放する。
- HP30%以下で `にげる` と `かいふく` を閃く。入場時・ターン中のあらゆる被害経路で共通判定する。
- `dungeonTactics` は複数のカスタム作戦、条件、最大2行動、コピー、挿入、並べ替え、自動構築を持つ。
- 作戦ごとに武器・盾/鎧の印優先度を保存し、合成判断へ反映する。

## 戦闘・状態・種族特性

- 攻撃、防御、経験値、レベル、敵特殊能力、状態異常をターン単位で処理する。
- 主な状態異常は毒、麻痺、暗闇、混乱、濡れ、睡眠、石化、恐怖、火傷、凍結等。
- 専用回復草や巻物を状態に応じてAIが選ぶ。
- 全11種族・119形態の特性を現在姿と系譜から決定し、攻撃、防御、移動、地形、アイテム、死亡等へ介入する。
- 敵も種族別特殊能力を持つ。

## アイテム・識別・装備

- 武器、盾、鎧、アクセサリー、草、巻物、杖、指輪等を扱う。
- セッションごとに未識別名を割り当てる。草・巻物は使用で識別し、杖は効果から仮名を付けても残回数は不明。
- 装備品は装備または調査まで+値、呪い、印を隠す。
- 呪い装備は通常の取り外しを妨げる。回数0の杖も投擲命中で最後の効果を発動できる。
- 同種合成は強い器・印枠を評価し、異種合成はベース種別を保持して印を移す。
- 印枠超過時は作戦の優先度と基礎スコアから残す印を選ぶ。呪縛印は除去不能。
- 合成結果の印から未識別素材を推測する場合がある。

## 地形・罠・イベント

- 氷、水脈、魔法陣等の地形効果がある。AI経路探索は滑走先と罠危険度を見積もる。
- 罠は通路入口を避け、素振り等で発見できる。
- モンスターハウスは小型・大部屋があり、侵入時に敵を覚醒し専用演出・BGMを使う。
- 長居すると風の警告が進み、作戦の `風が吹いている時` と `にげる` が未探索部への急行として解釈される。
- 風の進行は各階の経過ターンで管理し、新しい探索を開始したときは前回の全滅・帰還時点の値を持ち越さず0から始める。
- 謎の種は土へ置くと時間経過で食べ物へ成長する。

## 帰還・死亡・オンライン

- 帰還時は到達階、レベルをオンラインランキングへ送る。
- 生還・死亡・救助でGold、道中品、追加報酬の扱いが変わる。各ダンジョン仕様を参照する。
- 倒れたとき救助要請を出せる。救助待ちはゲーム進行をロックし、救助後はHP半分・満腹50で帰還扱いとなる。
- 詳細は `online/dungeon_rescue.md`。

## BGM

- 種類別の浅・中・深、モンスターハウス、風、死亡、生還を切り替える。
- 退出後は通常育成BGMへ戻す。

## 主な実装

- `dungeon_core.js`: 入退場、状態、UI、作戦、結果、救助。
- `dungeon_generator.js`: フロア、敵、罠、アイテム。
- `dungeon_turn.js`: ターン、AI、視界、経路。
- `dungeon_combat.js`: 戦闘と状態。
- `dungeon_item.js`: アイテム、識別、装備、合成。
- `dungeon_traits.js`: 種族特性。
- `dungeon_render.js`: 描画とVFX。

## 確定している将来仕様

- ダンジョンから生還・救助帰還して恒常所持品へ移った装備と杖は、種類、+値、呪い、印、杖の残使用回数をすべて識別済みとして保持する。未識別状態はダンジョンセッション内だけに限定する。移行漏れ等で恒常所持品に未識別品が存在した場合、将来の鍛冶屋加工では対象にしない。
- ダンジョン内の即時 `ごうせい` は維持する。持ち帰った品を自分の鍛冶屋で時間をかけて加工する将来仕様は [`../business/blacksmith_business.md`](../business/blacksmith_business.md) が所有し、+値・印・杖回数の結果計算と中立なアイテム表現はダンジョン合成と共有する。
- 探索中に100を超えて成長した最大満腹度を、通常帰還または救助成功時に育成側の恒常的な最大満腹度へ反映する。持ち帰るのはパンや個体特性等で成長したダンジョン側の基礎最大値だけとし、装備の `膨` 印による一時ボーナスは含めない。育成側の既存値と帰還値の高いほうを保存して一度得た最大値を下げず、次回探索も育成側の最大値をダンジョン側の基礎最大値として開始する。全滅して救助せず帰還した場合と救助を断念した場合は、探索中に得た最大満腹度を失い、育成側へ反映しない。
- 通常帰還または救助成功時には最大満腹度だけでなく、ダンジョン終了時の現在満腹度も育成側へ反映し、探索中の空腹をなかったことにしない。装備の `膨` 印等による一時上限が外れ、現在満腹度が恒常最大値を超える場合は、恒常最大値まで切り下げる。
- ダンジョン終了時の `現在HP ÷ 最大HP` を育成側の体力割合へ変換し、HP総量の異なる両モードを割合で接続する。全滅して救助せず帰還した場合または救助を断念した場合は、最大満腹度の成長を失う一方、育成側の体力を1、現在満腹度をダンジョン終了時の値として消耗を反映する。救助成功時は、救助処理後のHP割合と現在満腹度を反映する。
- 帰還時点で残っているダンジョン状態異常は単純消去せず、育成側で持続する病気・症状へ必ず変換する。探索中にすでに治った状態異常は病気化せず、後遺症も残さない。抽選による発症判定は行わず、帰還時の残りターン数1～2を軽症、3～5を中症、6以上を重症とする。境界値は後から調整可能にする。
- 初期の変換分類は、毒→中毒、濡れ→風邪、凍結→低体温症・凍傷、火傷→火傷、暗闇→眼病、麻痺・石化→身体硬直、混乱・恐怖→心労、睡眠→強い倦怠とする。
- 異なる病気は同時に複数発症できる。すでに同じ病気を発症中なら重症度を一段階上げ、重症を上限としてそれ以上の重複項目を作らない。
- 軽症は睡眠・休養による時間経過でも回復可能とし、中症・重症は対応薬または軽症より長い休養を必要とする。新しい病気には薬剤師皆伝後の追加レシピを用意し、既存の特効薬と万能の霊薬は新しい病気を含む全病気を治療できる。
- 全滅して救助せず帰還した場合または救助を断念した場合も、帰還時点で残っていた状態異常を通常帰還と同じ規則で病気化する。全滅を理由とした追加の重症度上昇は行わない。
- 状態異常が帰還後の病気になることは、常時読み返せるチュートリアル図鑑へ登録する。項目解放時に本文を強制表示せず、将来の冒険家同行による初回固定マップチュートリアルの会話・実地説明でも同じ内容に触れる。チュートリアルの表示・保存共通規則は [`../core/tutorial_archive.md`](../core/tutorial_archive.md) が所有する。
- 帰還で状態異常が病気へ変換された場合、帰還結果画面に `帰還後の体調` を追加し、発症・悪化した全病名と重症度を表示する。病気化が一件もなければこの欄は表示しない。
- 現在の偶発的なダンジョン用語の閃き方式は見直し、冒険家皆伝後の初回ダンジョン入場時に専用の固定マップを使い、冒険家本人が同行して移動、戦闘、生存、道具、状態異常と帰還後の病気等を実地で教える導入へ変更する。冒険家皆伝という通常ダンジョン入場条件は維持する。
- 固定マップは説明上の章選択ではなく実際の複数階層として構成し、1階は移動、2階は戦闘というように、階段を下りながら学ぶ内容を増やす。現在のダンジョン用語20個は集約せず、`うえむき`、`したむき`、`ひだりむき`、`みぎむき` も独立した4語のまま維持する。
- 固定した敵、罠、アイテム、未識別品、呪い等を適切な位置へ置き、現在の被弾、低HP、アイテム接触、所持上限、鑑定、装備等の出来事を利用して、冒険家の説明後に実際の体験から対応語を習得させる。説明を聞いただけで一括付与しない。すでに習得済みの言葉があっても対応する階・実地体験を省略せず、言葉と記憶容量は重複加算しない。
- 共通固定マップはスカル・クリスタルのどちらにも属さない隔離された訓練用ダンジョンとし、訓練専用の能力、所持品、敵、罠、状態を使用する。最終階で冒険家が、スカルは手持ちを持ち込み育成能力を反映すること、クリスタルは持込不可でLv1から現地成長することを対比して説明する。5階修了後は通常の生還と同じ帰還経路で育成画面へ戻し、訓練状態のまま通常ダンジョンへ連続突入させない。
- 共通訓練の完了時に、スカルとクリスタルそれぞれの持込、能力・Lv、ロスト、持帰り規則を別々のチュートリアル図鑑項目として解放する。本文は自動表示せず、実際の各ダンジョン入場準備では選択中のダンジョンに対応する規則と持込結果を確認できるようにする。
- 共通訓練は5階構成とする。1階で上下左右の移動4語と上下左右の向き変更4語、2階で戦う・逃げる・回復・食べる、3階で装備・外す・使う、4階で投げる・置く・調べる・名前、5階で合成、安全な状態異常と治療、スカルとクリスタルの差、帰還を扱う。初回は5階すべての修了を通常ダンジョン解禁条件とし、途中階だけの省略はできない。
- チュートリアルは通常ダンジョンのランダム生成、持込・ロスト、ランキング、通常報酬等とは別の状態として管理し、通常操作で失敗しないよう敵、罠、資源、冒険家の介助を調整する。アプリ終了等で中断された場合は、進行中だった階の開始地点から安全に再開する。
- 状態異常の階では、冒険家が安全な弱い状態異常と治療を実演し、治さずに通常ダンジョンから帰還すると病気になることを説明する。固定チュートリアル自体から育成側の病気を強制発症させない。
- 新しいチュートリアル修了フラグを持たない旧セーブは、既存のダンジョン経験や習得済み語彙があっても、次の入場要求時に1階から5階まで初回訓練を履修する。習得済みの課題も体験するが、習得語と記憶容量は二重に付与しない。未習得語は対応する実地課題の成立時に確実に付与し、全20語を初めて揃えた時点でだけ、現在と同じ `作戦` と記憶容量ボーナスを付与する。
- 初回の物語付き訓練を完了した後も、プレイヤーは普段の師匠会話イベントウィンドウで冒険家と話し、`最初から全階を履修` または `任意の階だけ履修` を選べる。後世代でダンジョン語彙を引き継がなかった場合も同じ訓練を利用して再習得できるようにし、初回用の物語説明を毎回強制しない。再履修では通常報酬、習得済み語彙、記憶容量を重複付与しない。
- 住人が将来自律的にダンジョンを探索した場合も同じ規則を使い、その住人本人の恒常的な最大満腹度と帰還時の現在満腹度を更新する。
- スカルとクリスタルはダンジョン種別ごとに島全体の到達可能最深階を持ち、初期値はチュートリアルと同じ5階とする。探索は `下降中` と `上昇中` の片方向フェーズを持つ。下降中は現在の最深階へ着くまで下り階段だけを生成し、上り階段を生成しない。最深階では下り階段を生成せず上り階段だけを生成し、使用した時点で上昇中へ切り替える。上昇中の各階も上り階段だけを生成し、下り階段を生成しないため、直前の深い階へ戻ることはできない。1階の上り階段から地上へ出た時点を正式生還とする。特殊能力による階層移動も現在のフェーズと到達上限を破らないようにする。
- 各階の地形、敵、罠、アイテム等は従来どおり、その階を離れた時点で破棄する。上昇中は下降時のマップや敵・取得状態を保存せず、到達した階番号に応じたフロアを新しく丸ごと生成する。不思議のダンジョン型の再生成方式とし、往復用の全階スナップショットやフロア履歴は保持しない。
- 最深階で下降から上昇へ切り替わっても、同じ探索セッションを継続する。現在HP、現在・最大満腹度、状態異常、所持品、装備と耐久値、クリスタル側のLv等は切り替え前の値をそのまま保持し、フロア情報だけを破棄する。
- 上昇中に新しく生成する階にも、その階番号に対応する通常の難易度、敵、罠、アイテムとドロップ規則を適用する。帰路で新しいアイテムを取得できる一方、新しい戦闘・罠・消耗も発生する。
- 冒険家を皆伝した入居住人が現在の最深階へ到達し、1階まで登り直して正式生還した場合だけ、そのダンジョン種別の島全体探索実績を1増やす。実績3ごとに次の5階分を解放し、解放後は主人公と他の住人も新しい階層へ進める。救助帰還、任意帰還、途中帰還、敗北、主人公本人の生還は住人開拓実績へ数えない。必要実績3と解放幅5階は設定値として後から調整可能にする。
- 画面外・ゲーム終了中の住人探索は、通常ダンジョンと同じ敵、罠、アイテム、作戦、装備効果と帰還境界を使い、描画を省いた決定的シミュレーションで解決する。攻撃、被弾、効果発動等の実イベント回数も集計して装備耐久値へ反映し、開始時に保存した乱数状態から同じ入力には同じ結果を返す。
- 武器、盾、鎧、アクセサリーは、従来のアイテムID、+値、印、呪い等に加え、安定した個体ID、現在耐久値、最大耐久値を持つ。武器は攻撃時、盾・鎧は攻撃を受けた時、アクセサリーは効果発動時または一定ターンごとに消耗する。0になった装備は破損して性能と印が無効になるが消滅せず、鍛冶屋で最大値まで修理できる。初期仕様では修理による最大耐久値低下を行わない。
- 住人が倒れた場合は再死亡させず救助待ちとして島の予定から外す。主人公または別の冒険家皆伝済み住人が救助できる。救助成功時は装備と所持品を保持して帰還し、断念時はスカルなら持込品、クリスタルなら現地取得品を失い、体力1と帰還時点の病気を反映して帰宅する。
- 住人も各階の通常報酬と重要建築素材を取得できる。スカルの城素材、クリスタルのカジノ・カードショップ素材等を主人公専用到達報酬にせず、住人が先に持ち帰ることを作戦構築が難しい場合の救済経路として認める。重複取得防止は主人公・住人・収納・施設・マップ所有状態を含む島全体の所有検索へ拡張する。
- 主人公の現在の任意帰還操作は全階で維持するが、任意帰還は住人開拓の正式生還には扱わない。住人の探索予定も、最深階から新しく再生成される各階を1階まで登り直す工程を終えるまで帰還成功とせず、上り中の戦闘、空腹、状態異常、装備消耗を省略シミュレーションへ含める。
- 共通余生方針 `冒険の語り部` で完成した歴代の冒険記は、本人が実際に経験した階層、敵、罠、アイテム、被害、装備消耗、所要時間、救助・帰還結果の実測資料として、主人公・住人の探索前試算へ統合する。対象記録が多いほど想定戦闘回数、被ダメージ、必要食料、耐久消耗等の予測幅だけを狭め、未遭遇情報を表示せず、敵能力、抽選、ドロップ、マップ、識別、階層実績、実際の探索結果を変更しない。同じ探索イベントIDを複数の冒険記や再読込から重複集計しない。余生工程と永久記録は [`../core/evolution_lifecycle_inheritance.md`](../core/evolution_lifecycle_inheritance.md) が所有する。
- プレイヤーが画面上で操作・観戦するダンジョンの初期戦闘ボイスは主人公・住人の攻撃時とダメージ時の短い掛け声だけを対象とし、通常モンスターは従来の効果音だけを使う。探索中の通常会話や勝敗・帰還へは広げない。音声は入場前までに生成済みのキャッシュだけを再生し、不足していても探索を待たせない。画面外・オフライン住人探索では音声再生や不足音声の生成を行わない。候補、優先順位、字幕、早送り、設定解放等の共通規則は [`../collections/music_creation_studio.md`](../collections/music_creation_studio.md) が所有する。

## 構想段階の案

- 新ダンジョン、新地形、新状態、新装備カテゴリを追加する可能性がある。
- アイテムを内部へ保存できる `ツボ` を将来追加し、内容物をツボへ収める操作にはコンシェルジュから習得する共通正式語 `いれる`、ツボから外へ出す操作には同じく共通正式語 `だす` を使用する。ツボの容量、種類、識別、破損、投擲、持込・ロスト、ツボの中のツボ、AUTO作戦等の詳細は未決定とする。
