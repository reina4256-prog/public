# 思い出・アルバム仕様

状態: 実装済み

## 用語と解放

- AIの生涯、人物、場所、行動、アイテム等の記録を、TCG正式解放前は `思い出` と呼ぶ。
- 思い出を60枚以上所有し、建設済みカジノへ入場済みで、ディーラーRank 6へ到達するとTCG用のカードとして正式に扱う。
- カジノ入場自体には60枚条件を設けない。

## 現在の実装仕様

- アルバムは人物、場所、行動、アイテム、種族・進化など複数タイプを同じ一覧で扱う。
- 同一 `masterId` の複数世代・複数枚は1つのアルバム枠へまとめ、詳細で所有世代を確認する。表示名が同じでも `masterId` が異なれば別枠。
- 一覧は1ページ12種類、固定4列のアイコン中心表示。名前、世代、説明は詳細モーダルへ置く。
- 検索は表示名と所有世代に対応し、検索変更時は有効ページへ戻る。
- ヘッダーは総所有枚数と種類数を分けて表示する。
- 旧データの末尾 `+数値` は表示時に隠すが、内部名・強化値・元コレクションを変更しない。`C++` 等の非数値文字列は保持する。
- 獲得処理は同一世代の重複を、履歴と `acquiredGeneration` の両方で防ぐ。
- 職業皆伝時は対応人物思い出を獲得する。城入場では兵士・隊長・王様を同時に記録する。
- 場所思い出はスカル、クリスタル、森の小屋、城などの正式な入場地点で獲得する。
- 行動思い出は睡眠、農業、鍛冶など、実際に対象行動が成功開始した時点で獲得する。
- 生涯終了時は死亡したAIの現在種族・進化から世代付き思い出を生成する。
- 最初の1枚を取得した時点では `思い出について` だけを案内し、カード、デッキ、バトルという名称・機能は出さない。
- TCG正式解放条件を満たした時点で、別項目の `カードについて` を案内する。

## TCGとの境界

- アルバムは収集・閲覧を所有する。
- デッキ構築、コスト、HP、効果、バトルは `casino/tcg.md` が所有する。
- カードショップ・競売でインスタンスが増減しても、アルバムは元のコレクションを破壊せず再集計する。

## 主な状態と実装

- `TCG.myCollection`, 各カードの `masterId`, `generation`, `acquiredGeneration`
- `tcg_core.js`: カード定義、アルバム、アート、獲得。
- `ui_controller.js`: 生涯・師匠・場所・行動の獲得フック。
