# 思い出・アルバム仕様

状態: 実装済み

## 用語と解放

- AIの生涯、人物、場所、行動、アイテム等の記録を、TCG正式解放前は `思い出` と呼ぶ。
- 思い出を60枚以上所有し、建設済みカジノへ入場済みで、ディーラーRank 6へ到達するとTCG用のカードとして正式に扱う。
- カジノ入場自体には60枚条件を設けない。

## 現在の実装仕様

- アルバムは人物、場所、行動、アイテム、種族・進化など複数タイプを同じ一覧で扱う。
- 同一 `masterId` の複数世代・複数枚は1つのアルバム枠へまとめ、詳細で所有世代を確認する。表示名が同じでも `masterId` が異なれば別枠。
- 一覧は1ページ12種類、固定4列のアイコン中心表示。名前、世代、説明は詳細モーダルへ置く。
- 検索は表示名と所有世代に対応し、検索変更時は有効ページへ戻る。
- ヘッダーは総所有枚数と種類数を分けて表示する。
- 旧データの末尾 `+数値` は表示時に隠すが、内部名・強化値・元コレクションを変更しない。`C++` 等の非数値文字列は保持する。
- 獲得処理は同一世代の重複を、履歴と `acquiredGeneration` の両方で防ぐ。
- 職業皆伝時は対応人物思い出を獲得する。城入場では兵士・隊長・王様を同時に記録する。
- 場所思い出はスカル、クリスタル、森の小屋、城などの正式な入場地点で獲得する。
- 行動思い出は睡眠、農業、鍛冶など、実際に対象行動が成功開始した時点で獲得する。
- 生涯終了時は死亡したAIの現在種族・進化から世代付き思い出を生成する。
- 最初の1枚を取得した時点では `思い出について` だけを案内し、カード、デッキ、バトルという名称・機能は出さない。
- TCG正式解放条件を満たした時点で、別項目の `カードについて` を案内する。

## TCGとの境界

- アルバムは収集・閲覧を所有する。
- デッキ構築、コスト、HP、効果、バトルは `casino/tcg.md` が所有する。
- カードショップ・競売でインスタンスが増減しても、アルバムは元のコレクションを破壊せず再集計する。

## 主な状態と実装

- `TCG.myCollection`, 各カードの `masterId`, `generation`, `acquiredGeneration`
- `tcg_core.js`: カード定義、アルバム、アート、獲得。
- `ui_controller.js`: 生涯・師匠・場所・行動の獲得フック。

## 確定している将来仕様

- 新職業は人物思い出を定義する。占い師、科学者、販売員はTCG人物カードが先行しているが、職業獲得経路は未実装。
- 販売員は、その世代で新規皆伝した場合に皆伝時の人物思い出を1枚取得する。販売員ライセンスを引き継いだ次世代以降は、既存師匠と同じ1世代1回の思い出クエストを達成することで、その世代の販売員人物思い出を1枚取得できる。同じ師匠の人物思い出は同一世代で重複取得しないが、異なる世代の取得は別カードとして認め、アルバムでは同一 `masterId` の所有世代へ集約表示する。住人本人の皆伝では主人公向け人物思い出を増やさない。
- 販売員の思い出クエストは `時代を読む商い` とし、現世代で販売員と再会済みの、販売員ライセンスを引き継いだ主人公だけが対象となる。固定5件の仮想市場判断に4件以上正解すると、その世代の販売員人物思い出を1枚取得する。出題は既存の入門試験用一問一答UIを5問へ対応させて再利用し、通常の師匠会話イベントウィンドウは使わない。実際のGold・商品・能力値は報酬として増減させず、同世代で取得済みならクエストを提示しない。問題、必要語、ヒント、挑戦消費の詳細は [`../careers/advanced/salesperson.md`](../careers/advanced/salesperson.md) が所有する。
- 余生方針 `悠々自適なスローライフ` の4工程では、選んだ趣味、場所、振り返った出来事、最後の言葉を人物ID・世代・工程順とともに `余生アルバム` へ永久記録する。余生アルバムはTCG用カードと別の人物史記録とし、思い出60枚条件、カード所有枚数、デッキ、売買、強化へ加算しない。余生工程を再読込・不在精算しても同じ記録を重複作成せず、生涯終了時の人物思い出カードは従来どおり別に1回生成する。
- 余生方針 `冒険の語り部` の冒険記と `島の架け橋` の交流記録も、人物ID、世代、4工程、参照した実出来事IDを持つ永久人物史として閲覧できるようにする。これらはTCG用カードとせず、思い出枚数、デッキ、売買、強化へ加算しない。冒険記の探索前試算利用、交流記録の次世代紹介状は各所有仕様から導出し、アルバム閲覧によって効果を再適用しない。
- 余生方針 `歴戦の指揮者` の戦術書も、著者人物ID、世代、4工程、参照した実戦イベントID、代表戦、対応モードを持つ永久人物史として閲覧できるようにする。TCG用カード、思い出枚数、デッキ、売買、強化へ加算せず、アルバム閲覧によって作戦テンプレートを再生成・重複取得しない。実戦利用は戦術書原本から導出し、廃止された語や条件があっても人物史本文は残す。

## 構想段階の案

- 将来の新コンテンツも人物・場所・行動・アイテムの既存分類へ追加できる。

## 未決定事項

- 占い師・科学者の人物思い出を職業実装前に別経路で獲得可能にするかは未決定。販売員は職業実装後の皆伝と次世代思い出クエストを正式な取得経路とし、職業実装前の先行取得経路は設けない。
