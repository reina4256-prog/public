# 知識の手帳仕様

状態: 実装済み

## 現在の実装仕様

- 知識の手帳は、AIが解放・発見した制作知識を一つのUIで確認する。
- 主なカテゴリは建築設計図、料理レシピ、鍛冶レシピ、薬剤師の処方箋、仕立屋の型紙。
- 建築設計図は建築士皆伝後に全施設の必要能力・素材・前提フラグを確認できる。
- レストランレシピは最初から全表示せず、チュートリアルと研究開発で閃いたものを表示する。
- 薬剤師課題は手帳で処方を確認してから調合する導線を持つ。
- 仕立屋の型紙は素材、制作物、お守りの関係を表示する。
- 未解放カテゴリは解放方法を示すロック表示にする。

## 関連実装

- `ui_controller.js`: 手帳UI、建築・制作一覧。
- `data.js`: アイテム、施設、制作定義。
- `shop_map_core.js`: レストランの研究進捗・固定レシピ。
- `ai_core.js`: 調合、鍛冶、裁縫、解放フラグ。
