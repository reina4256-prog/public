# マイホーム・コンシェルジュ屋内仕様

状態: 実装済み

## 解放

- 倉庫、冷凍庫、金庫、ドレッサーを備える。
- 冒険家皆伝から巡回記録、建築士皆伝から家の鍵を受け取る。
- 美容師皆伝後の紹介を経て、初回の実際のマイホーム入場でコンシェルジュ遭遇を行う。
- 次世代では、その世代で最初のマイホーム屋内入場だけ再会動画・挨拶を行う。通常の小屋入場では再生しない。

## 屋内マップ

- `myhome_map_core.js` が所有し、`MYHOME_SPRITES` を `SHOP_SPRITES` と分離する。
- 長方形グリッドに倉庫、冷凍庫、金庫、ドレッサー、作戦ボード、テーブル、椅子、ベッド、装飾を配置する。
- 屋内マップを開くには、マップ上に実在するマイホームと、現在世代のコンシェルジュ遭遇済み／解放済み状態の両方が必要。コンシェルジュ不在時は屋内マップへ入れない。
- 現在の種族・進化の4方向ダンジョン歩行スプライトを使い、家具・装飾・来客を避けて移動する。
- 外部からの入場は入口へ戻し、試験完了など明示的な `preservePosition` のときだけ位置を保持する。
- 床・壁・家具・落とし物・NPC・プレイヤーを安定キー付きDOMで更新し、移動ごとの全再構築を避ける。

## チャットと行動

- 育成画面のコマンドは小屋へ移動後、指定対象へルーティングする。屋内コマンドは入口から対応家具へ歩く。
- 対応行動はコンシェルジュ訪問、掃除、倉庫、冷凍庫、金庫、作戦会議、睡眠、食事、勉強、筋トレ、ランニング、ドレッサー、家具強化、接客、装飾配置。
- 学習語パネルは屋内で有効な語だけを表示し、クリック時も通常チャットと同じ経路を使う。
- 屋内行動は `myHomeIndoor: true`, `myHomeAction`, `_started: true` の共有タスクとして進め、完了後も屋内に残る。
- 体力または満腹度が0でも、睡眠・食事のためにマイホームへ向かう中継移動は回復行動として許可し、到着後の睡眠・食事まで強制中断しない。
- ベッドは実際の位置へ移動し、横向きで通常睡眠タスクを開始する。
- 停止ボタンは通常屋内行動を中断するが、余生タスクには表示しない。

## 家具・収納・装飾

- 倉庫、冷凍庫、金庫は個別コマンドで入出庫・拡張する。
- `アイテム`、`食べ物`、`お金` は各収納への投入、`入れる/しまう` と `出す/取り出す` は候補から選ぶ。
- 知性が高いほど高価な通常品、古い食品、適切な財布残高を優先する。
- `アップグレード` は材料がそろう強化可能家具から選び、移動・作業・材料消費・レベル同期後に完了する。
- ドレッサーはカラーかオーラを選ぶ二段階会話。屋内で編集を閉じてもマイホームを退出しない。
- 観葉植物とキャンドルは到達可能な隣接セルから配置し、配置セルを永久障害物にする。
- 掃除対象の落とし物は12実時間ごとに最大3個追加する。累積の固定上限はなく、空きマスがなくなると追加を停止する。

## 来客・接客

- 来客は入口から応接席へ歩き、接客後に料理を食べ、入口から退出して初めて完了となる。
- 腐敗、焦げ、失敗、残骸、原材料、生魚等は提供しない。完成料理を優先し、その中で価値の高い料理を選ぶ。
- 来客とAIは同じセルへ入らず、進路が塞がれた場合は再経路探索する。

## 余生と世代交代

- 皆伝後は称号、余生方針、現在タスク、進捗、早送りを屋内表示する。
- 手動行動中は余生サイクルを一時停止し、完了後に再開する。
- 寿命到達時は屋内UI、移動、来客、行動タイマーを破棄してから思い出生成と引継ぎへ進む。
- 退出時も屋内タスク、オーバーレイ、タイマー、経路を残さない。
- 世代交代では、マップ引継ぎとライセンス引継ぎの両方を選び、前世でコンシェルジュと遭遇済みの場合だけ、コンシェルジュと屋内状態を次世代へ保持する。片方でも欠けた場合はコンシェルジュ不在となり、屋内状態も初期化する。

## コンシェルジュ職業

- Rank表、試験、称号は `careers/advanced/concierge.md` を正本とする。

## 主な状態と実装

- `aiPet.myHomeIndoor`, `conciergeUnlocked`, `conciergeEncounterGeneration`
- `myhome_map_core.js`: マップ、経路、チャット、家具、来客、余生。
- `ai_core.js`: 共通タスク、解放、遭遇、死亡。
- `ui_controller.js`: 育成画面ルーティング、試験、収納・美容UI。
- `view_renderer.js`: 共通アクション描画。

## 確定している将来仕様

- マイホームに最初の収納設備が完成した際、コンシェルジュが収納から物を外へ出す正式語 `だす` と、収納へ物を収める正式語 `いれる` を同じ会話で教える。日本語入力では `だす` に `出す`、`取り出す`、`取出す`、`とりだす` 等、`いれる` に `入れる`、`しまう` 等の入力別名を認める。各語の習得時に記憶容量を恒久的に1増やし、容量不足では習得失敗させない。既存セーブで旧別名を学習済みなら重複付与せず正式語へ移行し、収納設備があるのに不足語が残る場合は次のコンシェルジュ会話で不足分だけを教える。住人は自動共有されず、本人が現在の島のコンシェルジュから個別に学ぶが、過去に主人公だった時代の習得語は保持する。語彙定義と他コンテンツでの再利用は [`../core/ai_words_and_tasks.md`](../core/ai_words_and_tasks.md) を正本とする。
- コンシェルジュ皆伝後、マップ引継ぎとライセンス引継ぎの両方を選んだ次世代のコンシェルジュ会話で、マイホーム自由エディットを永久解放する。日替わり依頼で増減するコンシェルジュポイント、増築、再ロックを含む詳細は [`myhome_editor_and_concierge_points.md`](myhome_editor_and_concierge_points.md) が所有する。
- 現在の12実時間ごとの出所不明な掃除対象生成は完全に廃止し、島の入居住人が森・山・ダンジョン等で得た本人所有品を、主人公のマイホーム訪問時に贈る仕組みへ置き換える。主人公はマイホーム室内で `倉庫優先` と `落とし物優先` を切り替えられる。倉庫優先では空きがある限り直接収納し、超過分を掃除対象として床へ置く。落とし物優先では床の配置可能枠を先に使い、超過分を倉庫へ収納する。どちらにも空きがなければ住人が保持して再訪する。所有権は倉庫への収納成立時、または主人公が床の品を掃除して拾った時点で移る。重要建築素材の取り置きと訪問優先度を含む住人側の規則は [`../core/island_residents.md`](../core/island_residents.md) が所有する。
- 1回の訪問で渡せる重要建築素材には個数上限を設けず、収納・床の空きが許す限りすべてを優先して渡す。通常品は初期値を1回3個までとし、後から設定値で調整可能にする。倉庫へ直接収納する通常品もこの3個へ含める。

## 構想段階の案

- 部屋拡張、家具追加、来客追加の可能性がある。
- 将来家具とコンシェルジュサービスは、自由エディットの登録基盤へ継続追加する。
