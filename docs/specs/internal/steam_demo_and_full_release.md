# Steam体験版・製品版の分離

状態: 実装済み（Steam実配信設定・実機音声認識は未検証）

更新日: 2026-09-22

## 対象範囲

体験版の制限、製品版とのビルド・保存分離、製品版への任意引継ぎを所有する。工程6・工程7・城移行は保留を維持する。

## 現在の実装仕様

### 起動・ビルド・保存

- 製品版は `npm run start`、体験版は `npm run start:demo`。オンライン無効の製品版は `npm run start:full:offline`。
- Windowsビルドは `npm run build:demo` / `build:full` / `build:full:offline`。`build` は `build:full` の別名。出力先はそれぞれ `dist/demo/win-unpacked`、`dist/full/win-unpacked`、`dist/full-offline/win-unpacked`。配布時はフォルダー全体を使う。
- `release_profiles.js` はeditionとonlineを独立に持つ。配布物ではpackage.jsonのgameReleaseProfileを正本とし、開発用引数・URL・セーブで変更しない。
- Electronの体験版保存先は従来保存先と同じ親ディレクトリの `AIPetGame-Demo`。製品版は従来領域を維持する。自動取込みはしない。
- Web検証は `start:web:demo`（標準4174）と `start:web:full:offline`（標準4173）。保存分離はorigin単位のため別originを使う。

### プレイ制限

- 1世代だけ遊べる。次世代への引継ぎ画面は体験版では開かない。
- 四つの保存基礎能力（intel/power/beauty/speed）は各150上限。既存の装備・一時補正による計算後の値は150を超えてよい。
- 進化候補・進化ボタンを隠し、直接呼出しでも進化しない。
- 基本職6種はRank 8課題の受注・達成・納品・報告まで可能。報告後は内部Rank 9・課題未受注、表示はRank 8の境界とする。Rank 9課題の受注・進行・皆伝・余生へ進ませない。
- 上限のため受注中の能力上昇課題が達成不能になることを許容する。目標の引下げや救済は加えず、Rank 8到達を保証しない。
- 日課、デイリークエスト、ログインボーナス、音楽館、救済、薬局を無効にする。既存体験版の薬局もプレイマップから除き、製品版取込み時に戻すため別保存する。日課とは別の手動「予定」キューは使える。
- 体験版では重病・風邪・腹痛・中毒にかからず、既存の病気状態も無効化する。
- 製品版の音楽館は現状維持。将来のCDプレイヤー統合に伴う廃止は今回の実装対象ではない。

### 時間と終了

- 表示中の通常プレイでは年齢・寿命・鮮度を進める。
- 閉じている間・最小化・別タブ等の非表示中はゲーム進行を停止する。再開時に年齢・寿命・日課・鮮度を不在精算せず、鮮度等の絶対時刻を停止時間分ずらす。以前の「不在中も寿命到達」案を置き換える。
- 寿命到達で進行を止めて保存し、死亡演出なしで体験終了画面へ進む。書出しとタイトルへ戻る操作を置く。
- 終了マーカーと生成済み思い出カードを保存し、再表示・再読込みでカードを重複生成しない。

### 任意引継ぎ

- 体験版から専用拡張子 `.aipetdemo` で書き出し、製品版タイトルから選んで読み込む。同一PC・別PCの双方で使える。
- 暗号化、保存対象、検証、競合・失敗時の復旧の正本は [セーブ互換・移行](save_data_and_migration.md)。
- 既存製品版セーブがないときだけ読み込める。既存セーブの上書き・再取込みはしない。読み込まず新規開始してよい。
- 生存中のデータは続きから、寿命到達済みは直接世代引継ぎ画面から開始し、育成画面・死亡演出を先に出さない。取込みまでの不在時間は加算しない。

### オンライン

- 体験版はゲームのオンライン機能を無効にする。ログイン・フレンド・酒場・ランキング・カード市場・オンライン対戦・救助の導線を隠す。
- Firebase依存モジュール・P2Pの初期化、認証復元・クラウド定期公開を開始しない。過去の認証情報で有効化しない。
- 新規・続きからとも認証選択とオンライン表示名登録を省く。主人公のゲーム内命名とは別。
- オンラインチュートリアルは既存履歴があっても一覧・未読数・解放から除く。
- 製品版のオンライン有無は独立に選んでビルドできる。Steamworksの起動処理はゲーム内オンライン設定とは別で、既存テストApp IDを維持する。

## 確定している将来仕様

- Steamで無料体験版と有料製品版を配信する。ローカルの版別ビルドとは別に配信設定を行う。
- オンライン有効製品版の任意ログアウト方針は [オンライン基盤](../online/online_foundation.md) を参照する。

## 構想段階の案

- 現在の寿命・世代・職業制限に加えるプレイ時間制限や別の終了条件。導入承認はない。
