# Steam体験版・製品版の分離

状態: 未実装・構想段階（導入方針・一部制限は確定）

更新日: 2026-09-20

## 対象範囲

Steamで無料配信する体験版のプレイ範囲・機能制限、体験版と有料製品版のビルド分離、製品版へのデータ引継ぎを所有する。
壁打ちで仕様を整理し、整理完了後に実装へ進む。現段階ではゲームコード・ビルド設定を変更しない。

- 2026-09-20: ユーザーはここまでの仕様整理をコミット・リモートへ保存し、次チャットから体験版のコーディングに進むことを希望。確定部分の実装に着手できる段階であり、今回のチャットでは実装しない。

- 次に能力加算・進化・職業課題・寿命終了の通常／自律／不在精算経路を確認し、確定した制限を共通に適用する。Rank 8報告を止めたり、能力上限で詰む課題へ救済を追加したりしない。

## 現在の実装仕様

- `package.json` の配布ビルドは `npm run build`（`electron-builder --windows`）の1種類。体験版用・製品版用コマンドはまだ分かれていない。
- 既存セーブの保存・互換仕様は [save_data_and_migration.md](save_data_and_migration.md) が所有する。体験版からの引継ぎ方式は未確定。

## 確定している将来仕様

- Steamで無料の体験版を配信する。
- 体験版はプレイ可能な範囲と機能を制限する。
- 体験版と有料製品版のビルド方法を分ける。
- 体験版で遊んだデータを有料製品版へ引き継げるようにする。
- 詳細をMarkdownにまとめ、相談を完了してから実装する。

### プレイ範囲

- 遊べるのは1世代だけとし、体験版では次世代へ進めない。
- ゲーム内の世代交代用引継ぎ画面は隠す。体験版から製品版へのセーブ移行とは別の制限であり、製品版へのデータ引継ぎ方針は維持する。
- 賢さ・活力・美しさ・素早さの基本育成は可能とし、各能力の体験版上限は当面150とする（ユーザー指定は「150程度」。調整可能な暫定値）。以前の99案は置き換える。
- 条件を満たしても進化できず、進化ボタンも表示しない。能力上限だけで進化を抑える方式にはしない。
- 基本職6種（冒険家、漁師、建築士、料理人、鍛冶師、農家）に弟子入りできる。
- Rank 8の課題は達成・報告まで可能とする。その先のRank 9（最後の免許皆伝クエスト）は受注・進行不可とし、免許皆伝には到達させない。「Rank 8まで」は課題のプレイ可能範囲を指す。
- 基本職6種の既存仕様ではRank 9は全て能力上昇課題（冒険家・漁師・鍛冶師・農家は活力+50、建築士・料理人は賢さ+50）。体験版では能力の余裕にかかわらず、この最終課題をプレイさせない。課題の正本は各職業仕様とする。
- 能力上限に達して、受注中の能力上昇課題が達成不能になることを許容する。Rank 8到達を全プレイで保証せず、救済のための目標引下げや上限突破は設けない。
- 皆伝を禁止する主目的は、余生の仕組みを体験版で表示させないこと。体験版では余生の選択・開始へ進めない。

### 寿命到達と製品版での開始

- 体験版で寿命に到達したら体験終了とし、製品版へ移行できるデータを保存する。体験版内では世代引継ぎ画面を表示せず、次世代を開始しない。
- 製品版のタイトル画面に `体験版データの読み込み` の導線を設け、プレイヤーの選択で体験版データから開始できるようにする。自動取込みや強制的な世代引継ぎは行わない。項目の最終文言は実装時に整理する。
- 製品版で新規に開始する際、体験版データが存在していても、読み込まず `はじめから` 遊ぶことを選べる。体験版データの存在だけを理由に新規開始を隠さない。
- 寿命到達済みの体験版データを読み込んだ場合、開始画面は世代引継ぎ画面とする。育成画面や死亡演出を先に表示する流れにはしない。
- 寿命到達前の体験版データは、保存したプレイの続きから開始する。読込み時の不在時間の扱いは別途決める。
- 製品版で既に遊んでいるセーブを上書きする条件は未決定。今回の新規開始選択を、既存製品版セーブの無確認削除の許可とは扱わない。

### オンライン要素

- 体験版ではゲームのオンライン機能を無効にし、オンラインメニュー、ログインボタン、登録・ログイン案内、オンライン用チュートリアルを表示しない。
- 新規開始時の「ログインして進める／ログインせずに進める」の選択と、オンライン用プレイヤー名の登録を省き、そのままオフラインの開始フローへ進む。続きからでもログイン選択を要求しない。
- 非表示だけでなく、ゲームのオンライン認証、クラウド同期、定期公開等も動かさない。過去の認証状態が残っていても体験版のオンライン機能を有効化しない。
- 製品版でもオンライン機能を含めず配布できる構成を用意する。採用する販売構成と、ログアウトを含む共通認証方針は [オンライン・販売方針](online_release_and_localization_strategy.md) と [オンライン基盤](../online/online_foundation.md) が所有する。
- ここで省く名前入力はオンライン用プレイヤー名であり、主人公等のゲーム内命名を一律廃止する決定ではない。

## 構想段階の案

以下は比較用の候補であり、採用決定ではない。


| 論点 | 候補 |
|---|---|
| 1世代制限に加える区切り | プレイ時間、職業Rank・到達イベント、利用可能コンテンツ |
| 能力・職業上限到達後の案内 | 解放済み範囲の継続案内、製品版案内 |
| コード管理 | 共通コードから体験版・製品版の設定を切り替えて生成 |
| セーブ分離 | 版ごとに保存先を分け、製品版側から体験版セーブを取り込む |
| タイトルの読込み導線が使う取得方法 | 同一PC内で検出、ファイル書出し・読込み（体験版はゲームのクラウド機能を使用しない） |

## 未決定事項

1. 暫定上限150の最終調整、一時補正と恒常能力の扱い、進化禁止を全経路へ適用する具体方式。
2. Rank 8報告済み・Rank 9未受注を表す内部保存と表示方法は実装設計で整理する（プレイ範囲は上記で確定）。上級職、探検、住人、施設、収集、オンライン等の許可範囲も未決定。基本職の弟子入り許可だけでは、関連施設の全機能を許可したことにはしない。
3. 時間制限の有無。導入する場合はプレイ時間・ゲーム内時間・不在時間の扱い。
4. 能力・職業上限の案内、体験終了画面の操作・製品版案内、体験版の再プレイ。不在中の寿命到達と移行時の経過時間、死亡演出を体験版で見せるか、思い出生成等の確定時点・重複防止も決める。製品版での開始地点は上記で確定。
5. 引継ぎ対象（主人公・島・所持品・住人・図鑑等）と対象外、ゲーム設定の扱い。
6. 同一PC・別PCでのデータ取得方法、データ不在時の読込み項目の表示・無効化、既存製品版セーブとの競合、再取込み、製品版から体験版へ戻す可否。
7. 製品版をオンライン有効・無効のどちらで発売するか。体験版のオンライン無効は確定済み。Steam配信・購入管理とゲーム内オンライン機能の境界はビルド設計時に整理する。
8. ビルドコマンド名、出力先、配布対象OS、体験版に含める素材、開発機能の扱い。
9. Steam側の体験版設定・App ID・配信構成。具体化時にSteamworks公式資料で確認する。
10. バージョン差のある引継ぎ、制限が通常操作・自律行動・不在精算・オンライン経由でも守られることの検証条件。
