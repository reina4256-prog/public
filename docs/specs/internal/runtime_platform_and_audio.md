# 実行環境・配布・共通音声仕様

状態: 実装済み・配布最適化未完了

## 実行環境

- `npm start` はElectron/Steam向けの標準起動。
- `npm run start:web` は `127.0.0.1:4173` で同じゲームを配信する。
- `npm run start:web:lan` はLAN検証用に `0.0.0.0` へバインドする。
- `browser_server.js` は依存なしの静的サーバーで、MIME、Range、パス包含、no-storeへ対応する。
- ブラウザ・Android候補環境では `require` がないため、Electron/Steam呼出しをガードして通常Webとして動かす。
- 現在は `main.js` の `visibilitychange` が非表示時間を記録し、復帰時に最大1時間分を60fps換算した `aiPet.update()` の大量反復で補完する。通常ループは50ms間隔の約20fpsであり、ブラウザが非表示中にも実行した更新を差し引かないため、通常表示時との速度差と二重計算の可能性がある。

## タイトル画面のゲーム設定

- タイトル画面は `はじめから`、`つづきから` の下に `ゲーム設定` を表示し、セーブ開始前でも設定を変更できる。
- `game_settings_core.js` が端末単位の設定画面を所有し、現在は表示言語、BGM音量、フルスクリーンを設定できる。設定画面は狭い画面では1列表示になる。
- 表示言語は初回のみOS言語から選択し、ゲーム設定で選んだ後は保存済み言語を優先する。変更はDOM、Canvas、ダイアログ、音声入力へ即時反映する。
- BGM音量はタイトルとゲーム中の共通音楽へ即時反映し、既存の音楽館スライダーとも同じ保存値を使う。
- フルスクリーンは画面内ボタンで切り替える。環境がFullscreen APIに対応しない場合、PC版では従来どおりF11も利用できる。

## Electron・Steam

- 通常のゲーム内終了はゲーム内確認画面から保存後に実行する。初期値有効の端末設定 `終了時にオフライン進行の説明を表示` で説明を省略できる。Electronの通常クローズは、rendererの終了ハンドラー登録後に `request-game-quit` を送り、保存後の `quit-app` だけが終了を確定する。renderer未準備・クラッシュ時は通常クローズを妨げない。OS強制終了やブラウザによる破棄で専用画面を保証しない。

- `electron_main.js` がウィンドウ、フルスクリーン、Steamworksブリッジ、終了処理を所有する。
- 開発ビルドだけDevToolsを開き、パッケージ版では自動表示しない。
- Windows `dir` ビルドは `signAndEditExecutable: false`。現在の友人配布ビルドは未署名で、カスタムEXEメタデータを埋め込まない。
- 配布単位は `dist/win-unpacked` フォルダ全体で、EXE単体ではない。
- 現状は画像・動画・音声を広く同梱するため約5.7GiBで、サイズ最適化は未完了。

## Electronローカライズ監査

- `Ctrl+Shift+L` で、通常は無効なローカライズ監査パネルを表示・非表示にする。監査は開発者向けなので、ゲームの表示言語にかかわらずパネル自体は日本語へ固定する。見たい箇所を隠している場合は、パネルの見出しをマウスまたはポインターでドラッグして画面内を移動できる。監査は現在表示中の画面だけを対象とし、全画面巡回、ゲーム進行、自動言語切替は行わない。
- 有効中は、現在言語が日本語以外の場合の可視DOM上の日本語残り、Canvasへ渡された未翻訳文字、意図しない内容のはみ出し候補を検出する。上部ステータスUIについては、値の上下ずれと各列からの文字はみ出しも個別に検出する。
- 簡体字中国語では漢字自体を日本語残りとみなさず、ひらがな・カタカナを残留判定に使う。他の非日本語言語では、かな・漢字を候補にする。赤は日本語残り、黄ははみ出し、水色は配置ずれの候補表示であり、人による確認を省略できる確定判定ではない。
- `現在の画面を保存` は、監査パネルを写さず、候補枠を付けた現在のElectron表示をPNG、検出結果をJSONとして端末内だけへ保存する。開発版は `.localization-audit/`、パッケージ版はドキュメント内のアプリ名フォルダ配下 `localization-audit/` を使い、ネットワーク送信やセーブデータ変更を行わない。
- 入力欄、編集可能領域、ログイン画面はJSONの文字列監査対象から除外する。監査は通常の開発を止める一括作業ではなく、テストプレイ中に気づいた画面を逐次記録する補助機能として使う。

## 共通音声

- `audioManager` がBGM停止、再生、通常曲復元、再生済み解放を扱う。
- 各コンテンツは入場・状態・結果・退出で所有BGMを要求し、退出時に通常曲へ戻す。
- 音楽館のプレイヤー向け仕様は `collections/music_hall.md`。

## 検証

- JavaScript変更は対象ファイルごとに `node --check`。
- ローカライズ監査は残留判定、Canvas監視、読込順、Electron保存IPCの焦点テストを行い、実際の画面で保存されたPNGとJSONは報告された画面ごとに確認する。
- Web版は `/` とスクリプト、Rangeレスポンス、`node_modules` 遮断を確認する。
- Windowsビルドは `npm run build` 後、環境由来の `ELECTRON_RUN_AS_NODE` を除いて起動確認する。
- Android/Google Playは別ラッパー、AAB、署名、ストア要件が必要で、まだ実装していない。

## 確定している将来仕様

- ゲーム側が表示する警告、確認、エラー、入力ではブラウザ標準の `alert()`、`confirm()`、`prompt()` を使用せず、ゲーム内デザインの共通UIを使う。OSのマイク許可、ファイル選択、ブラウザ終了制約等、実行環境が所有して置換できない画面だけを例外とする。共通方針は [`../core/ui_dialogs_and_notifications.md`](../core/ui_dialogs_and_notifications.md) が所有する。
- セーブデータがない初回起動または完全初期化直後だけ、通常タイトルに `はじめから` を表示する。セーブデータがある場合は通常タイトルから隠し、ゲーム設定の `データ管理` に多段階確認付きの完全初期化を置く。完全初期化手段は端末譲渡・破損復旧・検証のため削除しない。
- ゲーム設定へ `ボイス音量` と `ボイス再生中のBGM低減量` を追加し、既存の `BGM音量` とは別の端末設定として保存する。ボイス音量0は字幕・会話進行を止めず、BGM低減量を変えても通常時のBGM音量を書き換えない。音楽・ボイス制作と再生時の詳細は [`../collections/music_creation_studio.md`](../collections/music_creation_studio.md) が所有する。
- ゲーム設定へ初期値有効の `戦闘ボイスを再生` を追加する。ただし、音楽制作が解放済みで、かつ闘技場、ダンジョン、防衛戦のいずれかが解放されるまでは項目自体を表示しない。設定を無効にしても字幕、効果音、戦闘処理は変更せず、完成済み戦闘ボイスの再生だけを止める。
- 現在のチャット音声認識と将来の生声収録は別経路にし、同じマイクを同時利用しない。収録開始時は音声認識を停止し、収録終了後もプレイヤー操作なしに勝手に認識を再開しない。収録画面には入力機器選択、入力メーター、短いテスト録音・再生を用意し、保存済み機器が利用不能なら再選択を案内する。
- OS・ブラウザのマイク許可画面を開く前にゲーム内UIで用途と保存を説明し、拒否・機器消失・開始失敗後もゲーム内UIへ戻す。OS所有の権限画面自体は共通ゲームUIへ置換できない例外だが、現行 `startVoiceRecognition()` に残る非対応・拒否時の `alert()` は将来の共通ダイアログ移行対象とする。
- Electron版の制作・録音・生成バイナリはインストール先へ書き込まず、端末ユーザーごとのアプリ専用領域へ保存する。Web検証版では大きなバイナリを `localStorage` へ格納せずIndexedDBだけを使い、利用不能な環境では制作データを不完全保存せず録音・生成を無効化して字幕経路を維持する。
- ローカルAI音声の一括生成はゲーム起動中だけバックグラウンド継続し、終了時はキューを保存して安全に中断する。常駐プロセスやゲーム終了中の生成は初期版に導入せず、次回起動後に未処理分を再開する。
- 音声の解決順は、台詞単位の生声、ローカルAI音声、プレイヤーが明示的に許可したクラウドAI音声、ゲーム設定で任意に有効化した端末標準読み上げ、字幕のみとする。端末標準読み上げは初期状態で無効にし、利用不能な言語を別言語として誤って読ませない。
- ローカルAI音声モデルはゲーム本体へ一括同梱せず、音楽制作解放後に表示する管理画面から必要な言語別パックだけを任意取得する。容量、声質、互換性、端末適性、空き容量を開始前に表示し、取得後に最低1GB程度の調整可能な余裕を残せない場合は警告する。自動ダウンロードは行わない。
- モデル取得は一時停止、再開、取消、完了後の整合性確認に対応し、不完全データを生成へ使用しない。モデルはゲーム本体と別のアプリ専用領域へ保存し、互換性がある限りゲーム更新後も保持する。モデルを削除しても生成済み音声は保持し、モデル更新後も既存音声を自動再生成せず、新旧比較後にプレイヤーが再生成を選べるようにする。
- 完全初期化ではセーブ系譜に属する作品、録音、生成音声、プロフィール、本人学習データを削除するが、任意取得した言語別モデルは端末共通資源として保持する。モデル本体はモデル管理画面の独立削除だけで消す。
- 生成品質は高速、初期値の標準、高品質を共通候補とし、モデルが対応する品質だけを表示する。端末性能不足の警告後もプレイヤーが承認して実行でき、長時間生成はゲームを止めずキューで処理する。
- AI音声キャッシュの自動整理設定は初期値を無効とし、プレイヤーが有効化した場合だけ、現在どこからも参照されていない再生成可能なAI生成音声を対象にする。生声、本人学習用録音、本人学習モデル、制作中プロジェクト、CD、音声プロフィール、現在の割当データは自動削除しない。手動整理では対象件数、容量、再生成に必要なモデルを確定前に表示する。
- 音声生成キューは並べ替え、一時停止、再開、取消を可能にし、初期優先順は現在話している人物、固定会話、チュートリアル、動的会話とする。闘技場、ダンジョン、防衛戦等のリアルタイム戦闘中は生成処理だけを安全に一時停止し、戦闘終了後に自動再開する。完成済み音声の戦闘中再生は継続する。
- Electron/Steam版を維持しながら、通常ブラウザ検証経路も維持する。
- オフライン進行が有効なセーブでは、通常のゲーム終了操作とElectronウィンドウの通常クローズ時に、ゲーム終了中も年齢・寿命、鮮度、生態系、設定済み日課、住人店舗等が進み得ることを終了前に毎回説明する。端末単位のゲーム設定へ `終了時にオフライン進行の説明を表示` を追加し、初期値は表示、プレイヤーが非表示へ変更した場合だけ省略する。説明を非表示にしてもオフライン進行自体は止めない。
- OSによる強制終了、プロセス強制終了、停電、ブラウザによるページ破棄等では専用の終了前画面を保証できないため、スケジュール保存時とスケジュール画面にも常設説明を置く。通常終了ではゲーム状態と終了時刻を保存してから終了する。
- 起動中でもゲーム画面が非アクティブな時間はゲーム終了中と同じ不在区間として扱う。開始時に状態と時刻を保存して通常更新を止め、復帰時は共通の不在精算器を一度だけ実行する。これにより、最小化したまま終了した場合も、非アクティブ開始から次回起動までを重複なく一つの区間として扱う。
- 不在判定は、ブラウザタブ切替、Electron最小化、PCスリープ等によってゲーム画面が非表示・停止した場合に行う。ゲーム画面が表示されたまま別アプリへフォーカスを移しただけなら通常進行を維持する。復帰時の詳細な不在報告は初期実装では経過時間にかかわらず毎回表示し、将来の簡略表示閾値を変更可能な設定として追加できる構造にする。
- スケジュール編集画面とゲーム設定画面を開いている間はゲーム全体を停止する。ただし、その状態から非表示、最小化、終了へ移った時点で不在区間を開始する。
- 第一販売先はSteamのPC買い切り版とし、オンライン利用を本体価格に含める。発売時サブスクリプションは採用しない。
- 第二販売先が必要な場合は、同じPC/Electron版を大きく作り替えず配布できるダウンロード販売先を先に比較する。
- 有料ブラウザ版とGoogle Play版は現時点の販売対象外とする。ブラウザ版は開発検証と、必要なら軽量な無料デモに使う。
- 現在の画像・音楽・動画の原本を再生成せず保全する。将来の容量最適化は、原本から配布用コピーを機械変換する方式で行う。
- 詳細な判断根拠は [`online_release_and_localization_strategy.md`](online_release_and_localization_strategy.md) が所有する。
