# カジノ・トランプゲーム仕様

状態: 実装済み

## 共通仕様

- 購入済みトランプが必要。図鑑解放済み種族柄から使用する。
- ディーラー会話の `トランプゲームで遊ぶ` から第2段階のゲーム一覧を開く。
- ポーカーはRank 3、大富豪はRank 5で解放する。
- インディアンポーカーとテキサスホールデムは、ディーラー免許皆伝後にディーラーのトランプゲーム売場で各100コインを支払って購入すると解放する。旧セーブも自動解放せず、購入が必要。
- 購入制のインディアンポーカーとテキサスホールデムは、未購入時にはゲーム一覧へ無効状態で表示せず、購入後に初めて表示する。Rank解放型のポーカーと大富豪は従来どおり進行条件を一覧で示せる。
- 一覧の案内文は遊ぶゲームの選択だけを伝え、将来のゲーム追加予定はゲーム画面内へ表示しない。
- 各ゲームはカジノ内モーダルで、Gold/深赤フレーム、フェルト、カード演出、ゲームログ、UI内エラーを使う。
- 結果はゲーム別・対戦相手別の生涯戦績とコイン収支へ記録する。
- ポーカー、インディアンポーカー、テキサスホールデムは勝敗曲へ切り替え、引分は本編曲を継続する。再戦は本編曲、退出はカジノロビー曲へ戻る。

## ポーカー

- Rank 3で解放し、1コイン以上を賭ける。
- `dealing`、`exchange`、`discarding`、`drawing`、`reveal`、`result` の明示フェーズで進む。
- 最初の10枚を順に配り、プレイヤー選択カードとディーラー捨て札を退場させ、補充後にディーラー札を公開する。
- 1ハンドに2回の交換機会がある。
- 結果後は同じ相手・同じ賭けで即再戦、または設定へ戻る。再戦資金不足は結果UIで報告する。
- Rank 3はディーラー勝利、Rank 4は受注後純利益100、Rank 9は受注後3勝へ使う。

## 大富豪

- Rank 5で解放し、4～6人、試合数、ローカルルールを設定する。
- 初戦は全員平民。`大富豪 ON` と `富豪 ON` により次戦以降の上下階級とカード交換を行う。
- 人間が交換対象階級なら、自分の出すカードを手札から選ぶ。CPU上位は弱い札、下位は強い札を出す。
- 1位/2位/3位の既存配当は40/15/5、4位以下は0。
- 勝利BGM判定は `ceil(参加人数/2)` 位以内。5人戦3位も勝利扱い。
- 革命、11バック、縛り、数縛り、順方向、A/5スキップ等を状態チップとログで表示する。
- 最終出し手まで手番が一周したら、スキップされた席を待たず場を流す。
- Jokerは単独、組、階段のワイルドカードとして扱う。階段の非Jokerは同一スートで、合法候補のうち場を越える最弱解釈を選ぶ。
- スペード3返しは単独Jokerへ即座に場を流す。
- 7渡し、9救急、10捨て、Qボンバー等で人間の選択が必要な場合、選択完了まで手番を止める。
- Rank 5は1位、Rank 9は受注後3勝へ使う。

## インディアンポーカー

- 免許皆伝後にゲームを購入すると解放し、2～4人、1～100コインのアンティを設定する。
- 各自1枚で、プレイヤーは自分の札を見ず相手札だけを見る。stay/foldを選ぶ。
- CPUは見えている札だけで判断する。
- Aを最強として公開し、同値はポットを分配する。同条件再戦に対応する。
- 生涯戦績へ記録するが、ディーラーRank 9には数えない。

## テキサスホールデム

- 免許皆伝後にゲームを購入すると解放し、5～8人で行う。
- 各席2枚、flop/turn/river前にburn、共有札5枚、各ストリート固定call、foldを使う。
- 7枚から最良5枚役を評価し、同値はポットを分配する。同条件再戦に対応する。
- CPUと人間のfoldを扱う。
- 生涯戦績へ記録するが、ディーラーRank 9には数えない。

## 主な実装

- `casino_map_core.js`: ゲームUI、ルール、結果、戦績、BGM。
- `ui_controller.js`: ディーラー会話とメニュー入口。
- トランプ画像: 種族別5スートシートとJoker/裏面。
