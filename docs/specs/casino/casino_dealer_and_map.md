# カジノ・ディーラー・屋内マップ仕様

状態: 実装済み

## 建設までの解放ルート

1. 冒険家と建築士を皆伝する。
2. 生成された2マス幅の川の両岸を、同一連結成分の橋2本以上で実際に接続する。
3. 冒険家へ再訪し、クリスタル迷宮5/10/20階のカジノ素材の噂を聞く。
4. 幻惑のグラス、輝くカジノチップ、真理のダイスを集める。
5. 建築士へ見せ、`casinoRecipeUnlocked` と `カジノ` の言葉を解放する。
6. 材料と建築条件を満たしてカジノを建設する。

- 旧セーブでカジノが建設済みなら噂・レシピを補完する。素材だけ持つ旧セーブも噂段階として認識する。
- 橋は川向きと現在いる岸を判定して延長し、壊れた旧橋は現在岸側の欠損から修復する。すでに両岸接続済みなら追加建築を拒否する。

## 入場とディーラー

- 建設済みカジノは思い出枚数に関係なく入場できる。
- 初回入場でカジノ訪問を記録し、未遭遇ならディーラー遭遇を開始する。
- 未建設時は育成画面内で `カジノが建っていません。` と報告し、屋内状態を残さない。
- ディーラーRankの詳細は `careers/advanced/dealer.md`。
- 思い出60枚条件はRank 6のTCGデッキ課題だけに適用する。

## 屋内マップとチャット

- カメラは移動AIを中央追従し、マイホーム型のオーバーレイチャットを表示する。
- マップオブジェクト、ディーラー、来客、テーブルへの直接操作ボタンは置かず、学習済みの言葉で移動・会話・ゲームを開始する。
- チャットはディーラー、各ゲーム、設置設備、来客名、来客ゲーム設定へルーティングする。カジノ外から入場するための `遊ぶ` と施設名の `カジノ` は、店内の有効語一覧へ表示せず店内コマンドとして扱わない。
- 言葉パネルは学習順を保持し、現在Rank・正式解放・購入状態を満たして店内で実行できる語だけを表示する。Dealer Rank 6以降に正式TCG解放条件を満たした場合、学習済みの `カード` / `カードゲーム` / `TCG` / `デッキ` は、店内用の正規表示 `TCG` にまとめる。
- ディーラー・コインはRank 1、トランプはRank 2課題受注後、ポーカーはRank 3、大富豪はRank 5、TCGは正式解放済みのRank 6、スロット・設備・`おく`・来客設定はRank 10が基準。購入制の追加トランプゲーム名は、皆伝後にそのゲームを購入した場合だけ表示する。
- 師匠名は本人が当日の来客として存在するときだけ有効。常駐ディーラーはRank 1から対象。

## ディーラー会話メニュー

- 課題進行中または免許皆伝後にディーラーへ話しかけた1段目では、既存の報告・バイト・退出操作と、`購入する`、解放済みなら `トランプゲームで遊ぶ` を表示する。
- `購入する` の2段目は、Rank 1からコイン、Rank 2課題受注後からトランプ、免許皆伝後から設備と追加トランプゲームを表示する。1段目へ戻る操作を持ち、会話枠内へ収まる折り返し配置にする。
- 購入・ゲームの直接ボタンを1段目へ縦積みしない。各売場の内容と購入処理は従来どおり専用モーダルで開く。

## カジノ経済

- カジノコインはGoldで購入する。任意の正整数入力と+1/+10/+20/+50ボタンがあり、確定ボタンまで消費しない。
- 購入前に総Gold費用を表示し、不正入力・Gold不足はUI内で報告する。
- トランプは図鑑解放済みの種族柄から購入する。
- カジノコイン、購入済みトランプ、購入設備はマップ所有状態として扱い、マップ引継ぎ時だけ保持する。
- インディアンポーカーとテキサスホールデムは、ディーラー免許皆伝後に各100コインでゲームを購入すると解放する。購入状態もマップ所有状態として扱う。
- 購入制の2ゲームは未購入時にトランプゲーム一覧へ無効カードを出さず、購入後に初めて一覧と店内言葉パネルへ表示する。

## 設備購入と配置

- 皆伝後のディーラー会話から設備店を開く。
- 販売設備はスロット150コイン、3セルのポーカーテーブル100、2セルのTCGテーブル80、カジノチェア15。購入数に上限はない。
- 初期テーブル・椅子は `builtIn` で、購入在庫を消費しない。
- `おく` で未設置設備を配置する。1個なら自動選択、複数候補なら設備名を待つ。別の言葉は配置待ちを解除して通常処理する。
- テーブルは全セルが置け、隣接作業セルへ到達できる位置だけを選ぶ。
- 椅子はテーブルまたはスロット隣接の空きセルへ置き、対象方向を向く。空きがなければ移動・消費せず報告する。
- 配置待ちでないときに設備名を呼ぶと、同種の設置済み設備からランダムに選んで移動する。

## 皆伝後の来客

- カジノ入場ごとに、皆伝済みの非ディーラー師匠から最大3人を抽選する。ディーラーは常駐する。
- フレンドはこの来客枠に含めない。
- `本日のご来店` HUDは名前だけを表示する。
- 師匠へ話しかけると隣接位置へ移動して向き合い、共通会話後にポーカー・大富豪・TCGをボタンで選ぶ。未対応ゲームは無効表示。
- 会話済み師匠を `visitorMasterHistory` に記録し、ゲーム準備候補は当日来店中かつ会話履歴のある師匠に限定する。
- 師匠ごとの得意ゲームは保存するが、次ゲームを強制しない。

## 戦績

- `dealerProgress.stats` はポーカー、大富豪、インディアンポーカー、テキサスホールデム、TCG、スロットの6ゲームを正規化する。
- 勝・敗・引分、回数、コイン収支、対戦相手別成績を保持する。
- Rank 9の受注後カウンターはポーカー、大富豪、TCGだけの別状態。
- Rank 10または引退ディーラーライセンスで `勝敗表` を表示する。総合勝率、W/L/D、回数、収支、要約タイル、6軸レーダー、分析文を持つ。
- 対戦相手別の表には師匠との成績だけを表示する。通常CPU、自作デッキ、スロット台等の行は表示しない。
- 既存セーブ移行に関する説明文は、ゲーム画面内へ表示しない。
