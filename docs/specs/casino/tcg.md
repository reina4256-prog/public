# 思い出TCG仕様

状態: 一部実装

## 解放

- 思い出60枚以上、建設済みカジノへの入場、ディーラーRank 6で正式解放する。
- Rank 6では60枚デッキを作成・保存し、以後カジノ外でもデッキ編成できる。
- Rank 7はディーラー固定デッキ、Rank 8は自分の保存デッキ、Rank 9は受注後3勝の対象。

## コレクションとデッキ

- 思い出インスタンスは人物、場所、行動、アイテム、種族・進化等のカード定義へ結び付く。
- アルバム表示・世代別所有は `collections/memories_and_album.md` が所有する。
- バトル用デッキは60枚。保存デッキ、自動編成、編集UIを持つ。
- 同一名のカードは、世代・HP・攻撃力・能力値等が異なる個体を合算して1デッキ4枚までとする。カード名はマスター定義の基準名で判定する。
- 手動編成は5枚目の追加を拒否し、おまかせ編成も同一名4枚以内で構築する。旧セーブに上限超過デッキがある場合は自動削除せず、4枚以下へ直すまで保存・対戦に使用できない。
- `おまかせ編成` の確認モーダルはデッキビルダーより上に表示し、キャンセルでビルダーを残す。

## バトル

- プレイヤーとCPUはデッキ、手札、場、HP等を持ち、カードコストと効果に従ってターンを進める。
- モンスター、人物、場所、行動、アイテム等の種類ごとに配置・発動方法が異なる。
- プレイヤーとCPUのフィールドカードは独立し、同一側の同一フィールド重複を防ぎ、異なるフィールドは共存できる。
- フィールドカードも攻撃・破壊対象になり得る。
- 相手側アートは180度向けるが、詳細操作UIは読みやすい向きを保つ。
- ディーラー、来客師匠、自分の保存デッキ、オンラインの他プレイヤーデッキと非同期ゴースト戦ができる。
- ディーラーおよび来客師匠の固定デッキに入る人物カードは、その対戦相手本人の人物カード4枚だけとする。他の人物カードは混ざらない。
- 師匠固定デッキも同一名4枚制限に従う。
- 基本職6人、上級職9人（未実装職3人を含む）、兵士・隊長・王様の計18人に専用固定デッキを持たせる。兵士・隊長・王様は将来のカジノ来店に備えてデッキとCPU戦術だけ先行実装し、現在の来店候補には追加しない。
- 全固定デッキは `本人の人物4 / 単一種族モンスター44 / 署名フィールド2 / 行動6 / アイテム4 = 60枚` に統一する。モンスター44枚は基本形34枚・進化形10枚とし、二段進化の採用数は直前の進化元以下にする。
- 固定デッキ生成時に、60枚とカテゴリ別枚数、本人以外の人物カード不在、単一種族、同名4枚上限、基本形と進化形の比率、各進化元の採用数を検証する。不正なプロフィールからは対戦用デッキを生成しない。
- CPUの合法手判定は全員で共有しつつ、召喚・進化・人物・フィールド・支援の優先度、好む能力、攻撃対象、人物スキル、守護と防御用マナ温存の重みを対戦相手プロフィールから加算する。
- CPUは戦闘前に召喚、進化、人物、フィールド、行動、アイテムを1手ずつ実行し、各処理後に残りマナと盤面から次の合法手を再評価する。マナ増加・ドロー後の追加行動、召喚直後の進化、人物を出したターンの人物スキルも対象に含む。
- CPUが召喚した速攻モンスターは召喚ターンから攻撃できる。戦闘後にも再行動スキルや追加ドロー、速攻召喚によって新しい攻撃手が生じたかを再評価する。
- CPUの行動・アイテムはプレイヤー側と同じ効果実行処理を使い、対象が必要なカードは合法な味方から効果に応じた対象を選ぶ。進化後は進化元の行動可否、守護状態、受けた損傷、付与された攻撃力差分を引き継ぐ。
- CPUは相手ターン用の有効な人物スキルまたは守護に必要なマナを必要に応じて残す。プレイヤーの攻撃宣言時には人物スキルを検討した後、既存の守護またはその場で追加した守護へ攻撃を変更できる。貫通攻撃はプレイヤー側の割り込みと同様にこの守護割り込みを受けない。
- CPUの攻撃対象は守護・潜伏等の合法対象制約を通した上で、リーダーへの致死、敵の撃破、反撃損失、人物・フィールドの価値を比較して選ぶ。人物スキル、サポート対象、守護役も盤面評価で選び、健全な人物カードや同一フィールドを無意味に上書きしない。
- ディーラーと来客師匠は、CPUの行動ごとに本人の話し方を保った吹き出し台詞を表示する。モンスター召喚、進化、人物配置、フィールド展開、アクションカード、サポートカードは別イベント・別台詞とする。
- 通常時とプレイヤー行動への割り込み時の人物スキル、ターン終了前の守護付与、攻撃宣言後の守護追加・既存守護による割り込みも、それぞれ状況に対応した師匠台詞を表示する。
- ターン開始・終了、マナ温存、開始時／終了時能力、フィールド継続効果、一時効果の解除、魅了・連撃、カード・フィールドの破壊と復活、死亡時効果、プレイヤーの割り込みへの反応、勝敗にも台詞を表示する。短時間に複数イベントが発生した場合は台詞キューへ積み、勝敗台詞は優先表示する。
- カジノの共有TCGテーブルは左右2分割の画像を使い、PC/モバイルで奥行き方向へ消える見え方を作る。

## タッグ戦（現在の実装仕様）

- ディーラー免許皆伝後、カジノのTCGロビーでシングル戦とタッグ戦を選択できるようにする。
- タッグ戦では、常駐ディーラーと当日の来客師匠をNPC候補とし、その中から1人を味方として選ぶ。味方に選ばなかった候補から2人を敵チームへ選出する。
- カジノ建設には冒険家と建築士の免許皆伝が必須であり、タッグ戦解放時には自分、ディーラー、来客に選ばれる冒険家、建築士の最低4人を確保できる。来客が2人なら、相棒に選ばなかった残り2人がそのまま敵になる。来客が3人なら、相棒選択後の残り3人から敵2人をランダムに選び、1人は不参加となる。タッグ戦開始のために来客3人を要求しない。
- 当日カジノ内にいる来客は、会話済みかどうかにかかわらず相棒・敵候補に含める。
- タッグ戦の先攻チームはコイントスで決める。先攻チームの1人、後攻チームの1人、先攻チームの未行動者、後攻チームの未行動者という卓球ダブルス型の順序で行動し、以後もチームと担当者を交互に進める。
- 対戦開始前に、プレイヤーは自分と相棒のどちらが先に行動するかを選ぶ。敵チーム内の行動順はランダムに決める。
- タッグ戦の各チームは、シングル戦の2倍となる400HPをチーム内で共有する。個人単位の戦闘不能は発生しない。
- HP以外は参加者ごとに独立させる。4人がそれぞれ60枚デッキ、手札、マナ、墓地、盤面を持ち、自分は選択した保存デッキ、ディーラーと来客師匠は各自の専用固定デッキを使う。
- 行動者は自分が所有するカードをプレイ・攻撃・能動使用する。カードの「自分」と、自分の手札・マナ・山札を参照する効果は、そのカードの所有者だけに作用する。
- 「味方1体」は自分または相棒のカードから選択でき、「味方全体」は自分と相棒の両盤面へ作用する。「敵1体」は敵2人のどちらのカードも対象にでき、「敵全体」は敵2人の両盤面へ作用する。
- 攻撃者は敵2人のどちらの盤面のカードも攻撃できる。守護はチーム全体を守り、いずれかの味方盤面に有効な守護がいる間は、シングル戦と同じ例外を除いて他の味方カードと共有HPへの攻撃を防ぐ。貫通等の守護無視はシングル戦の規則を維持する。
- 敵の攻撃に対しては、現在の行動担当でない側も含む守備チームの2人が人物スキルと守護で割り込める。プレイヤー所有の反応はプレイヤーが選び、相棒の反応はCPUが判断し、費用は各カード所有者のマナから支払う。両者に反応候補がある場合は、プレイヤーの選択を先に解決してから相棒が判断する。
- 全員が初期手札5枚、最大マナ0で開始する。各参加者は自分の行動開始時に最大マナをシングル戦と同じ上限まで1増やし、現在マナを全回復する。アクションカードの1ターン1回制限も参加者ごとに管理する。
- 試合全体で最初に行動する1人だけは初回の通常ドローを行わない。残る3人は最初の自分の行動から通常どおり1枚引く。
- モンスターの攻撃可否、カードの開始時／終了時能力、状態異常の解除、「次の自分のターンまで」等の時間は、そのカード所有者の行動を基準に進める。所有者の通常行動外でも、確定済みのチーム守護と割り込みは使用できる。
- モンスター・人物等の盤面は参加者ごとに持つが、フィールド枠だけはチームで1枠を共有し、試合全体で最大2枚とする。どちらかが新しいフィールドを出すと自チームの既存フィールドを置き換え、相棒CPUはチーム全体の盤面評価に基づいて不利な上書きを避ける。
- フィールドの継続効果は4人それぞれの行動ごとには発動しない。各チームの前半担当が行動を始めるときに開始時効果を1回、後半担当が行動を終えるときに終了時効果を1回発動し、シングル戦と同じく一巡につき各チーム1回の頻度を保つ。
- 参加者はそれぞれ人物カード枠を1つ持ち、1チームに最大2枚の人物カードを配置できる。新しい人物カードは使用者本人の既存人物カードだけを置き換え、人物スキルの1ターン1回制限も所有者ごとに管理する。
- 人物カードは本人そのものではなく思い出カードとして扱うため、相棒本人と同名の人物カードをプレイヤーが出すなど、別所有者の人物カード枠に同名人物が同時に存在することを許可する。
- 片方の山札だけが空になっても敗北せず、その参加者のドローだけを不発にする。チーム2人の山札が両方空になった後、いずれかが次の通常ドローを行う時点で、そのチームを山札切れ敗北とする。効果による追加ドローの解決途中では敗北判定せず、次の通常ドローまで続行する。
- 1つのカードまたはフィールド効果を最後まで解決してから共有HPの勝敗を判定する。両チームが同じ効果解決によって同時に0HP以下になった場合は引き分けとする。
- TCG全体成績ではタッグ戦1試合を1戦として記録し、シングル戦とタッグ戦の内訳も保存する。対戦相手別成績には敵2人それぞれへ同じ結果を1件ずつ記録し、別に相棒ごとの共闘数、勝、敗、引分、勝率を保存・表示する。タッグ戦にカジノコイン報酬は付けない。
- タッグ戦の同条件再戦では、相棒、プレイヤーチーム内の行動順、使用デッキ、敵2人を維持する。敵チーム内の行動順と先攻チームのコイントスは毎試合やり直し、別の相棒または敵抽選を望む場合はロビーへ戻る。
- タッグ戦には確認付きの降参操作を常設する。確定すると通常の敗北リザルトを表示し、TCG全体へ1敗、敵2人それぞれとの対戦へ1敗、相棒との共闘へ1敗を記録する。
- プレイヤーの手札は常時表向きで表示する。相棒の手札もプレイヤーには公開するが、通常は小さく畳み、任意に展開して確認できるようにする。敵2人の手札は裏向きで枚数だけを表示し、全参加者の山札枚数、墓地枚数、マナは公開する。
- 相棒は本人固有のCPU戦術で完全に自律行動し、プレイヤーから個別カードの使用や攻撃対象を命令する機能は設けない。相棒CPUは両方の味方盤面、共有HP、両方の敵盤面を評価し、回復、強化、守護等もチーム全体から対象を選ぶ。プレイヤーは公開された相棒の手札を見て自分の行動を調整する。
- 共有HPは各チームに1つのリーダーとして扱う。リーダーへの単体効果は1回だけ適用し、全体効果でも敵が2人いることを理由に共有HPへの作用を重複させない。回復も同様に1回だけ適用し、リーダーHP参照能力は現在値と最大400を共有値から判定する。
- 破壊、手札戻し、山札戻しはカードの元の所有者の墓地、手札、山札へ送る。蘇生、進化、生贄、置換等の所有権を伴う操作は原則として実行者自身のカードだけを対象とし、相棒のカードには回復、強化等の許可された味方対象効果だけを使える。
- `evolvesFrom` を持つモンスターは、必要な進化元が本人の盤面に存在するときだけ使用でき、空き枠や十分なマナがあっても通常召喚はできない。この合法手判定はプレイヤー、相棒、敵2人で共通とする。プレイヤーの盤面に同じ進化元候補が複数ある場合は盤面から1体を選択し、CPUは合法候補から1体を選ぶ。
- 敵1人の手札、マナ、山札等を操作する効果は敵チームの参加者1人を対象とし、プレイヤーは対象者を選び、CPUは公開情報と戦況から選ぶ。敵全員を明記する効果は敵2人の双方に作用する。ランダムな敵カードは敵2人の盤面を合わせた合法対象から均等に抽選し、共有リーダーは常に1対象として数える。
- タッグ戦の開始フローは、カジノTCGロビーでシングル戦／タッグ戦を選択し、相棒、プレイヤーチーム内の先行担当、使用デッキの順に選んだ後、敵2人の抽選・公開、コイントスを経て対戦開始とする。来客2人の場合も公開演出を行うが、相棒選択後の残り2人が必ず敵となる。
- PC戦闘画面はシングル戦と同じ一枚の上下対面型テーブルを使い、敵チームを上段、プレイヤーチームを下段に置く。各段の中央だけを参加者2人分のモンスター列に分け、左端にチーム共有フィールド1枠、右端に参加者ごとの人物2枠を置く。4人を独立した大区画には分けない。
- 敵2人の顔・名前・マナ・手札枚数・山札・墓地は上部HUD、相棒とプレイヤーの同情報および味方共有HPは下部操作欄へ置く。敵共有HPは上部に、自分の手札は最下段中央に常時表示し、相棒の手札は折り畳み表示から盤面側へせり出す小型カードプレビューとして展開する。
- 現在の行動者は人物HUDと本人のモンスター列を強調し、4人の行動順を番号で常時表示し、合法対象を発光、対象を含まないモンスター列を暗くする。モバイルでも同じ一枚卓と上下関係を維持し、横スクロールで縮小カードと全枠を確認できるようにする。
- 攻撃または召喚によって現在の行動担当中に攻撃不能となっているモンスターは暗くし、カード上に `行動済み` を重ねる。気絶・化石化等は `行動不能` と区別して表示する。敵側のモンスター、人物、共有フィールドのカード本体は180度反転し、上下対面の卓でこちらと対峙している向きにする。虫眼鏡と盤面上の数値は読める向きを維持する。
- タッグ戦もシングル戦と同じ演出密度を維持する。対戦開始時に開始カットインと回転するコインおよび先攻結果を表示し、4人の各行動開始時に陣営色の斜体ターンカットインを表示する。手札からカードを使用すると所有者側から中央へカードを大写しし、その後に本人のモンスター列、人物枠、共有フィールド等の配置先へ飛ばす。人物スキル発動時も人物カードとスキル名を大写しする。
- 攻撃時は攻撃カードを実際の対象位置へ突進させ、攻撃軌道、着弾光、対象発光、画面揺れ、ダメージ数値を順に表示する。共有HPへの攻撃では斜体の `DIRECT ATTACK!!` カットインも表示し、カード反撃のダメージも攻撃者側へ数値表示する。この演出はプレイヤー、相棒、敵2人の全員に適用する。
- 相手の攻撃に対するプレイヤーの割り込み画面では、攻撃者名、攻撃カード名、攻撃力、現在ライフ、現在狙われている参加者・カードまたは共有HPを矢印付きで表示する。守護候補ごとに攻撃力、現在ライフ、最大ライフ、必要マナも表示する。プレイヤーが守護を選んだ場合は、その選択を相棒側の再判定やランダム抽選で上書きせず、攻撃移動演出と実ダメージを必ず選択した守護カードへ向ける。これは相棒のカードが元の攻撃対象だった場合も同じとする。
- プレイヤー手札は180×260のカード全体を縮小して枠内へ収め、カード左上だけを切り抜いた表示にしない。自分の手札、相棒の公開手札、両チームのモンスター、人物、共有フィールドには虫眼鏡を表示し、使用可能かどうかにかかわらず元寸法より大きいカード詳細を開けるようにする。
- CPU3人の台詞は共通キューで順番に表示し、発言者本人の顔付近へ吹き出しを出す。通常は現在行動中の師匠が話し、割り込み話者と勝敗・危機等の重要台詞を優先する。勝敗時は相棒と敵2人が短い結果台詞を順番に話し、台詞待ちで操作や進行を長時間停止させない。
- タッグ戦でもオートバトルを使用できる。オート対象はプレイヤー本人の席だけとし、プレイヤー所有の守護・割り込みも自動判断する。相棒は常に本人固有のCPU戦術で動き、プレイヤー側オートは途中で解除でき、使用による戦績上の区別やペナルティを設けない。
- タッグ戦に制限時間とラウンド上限は設けない。将来の追加カードによって循環や極端な長期戦が問題になった場合に、改めて決着安全装置を検討する。
- 初期実装では標準／高速等の演出速度切替を設けない。ただしカード移動、攻撃、台詞等の待機時間を一元的な速度設定から導出する構造にし、将来必要になった際に既存進行ロジックを作り直さず速度制御を追加できるようにする。

## 確定している将来仕様

- 占い師、科学者、販売員は上級職候補だが、職業実装と既存カード取得経路を接続する必要がある。
- 兵士・隊長・王様のカジノ来店フローを実装した際は、先行実装済みの専用デッキとCPU戦術をそのまま来客TCGへ接続する。
