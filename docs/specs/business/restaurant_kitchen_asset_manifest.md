# レストラン調理設備・画像制作リスト

状態: 未実装・仕様確定

用途: 画像制作資料

## 目的

レストランの複数工程調理へ必要な設備画像を、既存画像、流用候補、新規制作対象に分けて管理する。画像生成を別AIへ依頼する際は、このリストを制作対象の基準にする。調理挙動とレシピ工程は [`restaurant_business.md`](restaurant_business.md) が所有する。

追加機能全体の制作順と、鍛冶屋、魚、水槽・池、CDプレイヤーを含む合計数は [`../internal/missing_image_asset_manifest.md`](../internal/missing_image_asset_manifest.md) を参照する。

## 現在の実装仕様

### 既存画像の基準

- 参照画像は `restaurant_kitchen_mapchip.png` と `restaurant_luxury_kitchen_mapchip.png`。どちらも2816×1536の透過PNGアトラスである。
- 太い暗色輪郭、明確なピクセル、正面寄りで上面も少し見える視点、既存レストラン床へ置いたときに読み取りやすい形を維持する。
- 文字、設備名、メーカー名、ロゴを画像へ描かない。設備の用途は形、器具、色分けで判別できるようにする。
- AIが操作する正面を画像下側にそろえる。扉、取っ手、作業面等を、AIが下側の隣接マスから触れられる構図にする。
- 生成元は設備ごとの独立した透過PNGとして保管し、ゲーム組込み時にアトラスへまとめる。炎、湯気、水流、回転等は静止設備本体と分離し、必要ならコード側の演出として追加できるようにする。
- 初回の画像制作は各設備の基本版だけを対象にする。上位版・豪華版は、基本版をゲームへ組み込み、視認性と設備動作を確認した後に別途制作する。
- 表の占有マスは初期制作目安であり、画像完成後の視認性確認で最終決定する。

### 上位設備と流用

- 17種類の配置設備は14段階の設備解放グループとして扱い、「下処理・盛付」グループだけは野菜、魚、肉、盛付の4設備・4画像へ分かれる。
- 上位設備は一つの設備が複数工程タグへ対応できる。新規設備画像をすべて上位版まで同時制作せず、基本版の実装後に制作する。
- 既存 `item_legendary_kitchen` は、コンロ、煮込み、オーブン等の複数工程に対応する上位複合厨房の候補とする。
- 既存 `item_counter` / `item_lux_counter` は客席カウンターとして使用中のため、そのまま下処理台へ転用すると用途を見分けにくい。初期実装では仮画像流用を許可できるが、正式版は包丁・まな板等のある専用画像を推奨する。

### 複数工程の画像確認例

- 冷製カッペリーニ: 麺ゆで器 → 冷却・水場 → 盛付台 → 冷蔵庫。
- マグロの握り: 炊飯器 → 魚下処理台 → 盛付台 → 冷蔵庫。
- イチゴのショートケーキ: 製菓台 → オーブン → 製菓台の飾り付け工程 → 冷蔵庫。
- カレーライス: 野菜／肉下処理台 → 炊飯器と煮込み台 → 盛付台 → 冷蔵庫。
- メロンパフェ: 冷菓機 → 製菓台 → 冷蔵庫。
