# ランキング・非同期対戦仕様

状態: 実装済み・実機総合検証要

## ランキング

- ダンジョンはスカル・クリスタルごとに到達階とダンジョン内レベルを登録する。
- 闘技場は通常・ボスモードごとに到達WAVEとパーティを登録する。
- 防衛戦は通常・エンドレス等のモードごとに到達WAVEと防衛パーティを登録する。
- 各ランキングは上位件数を取得し、キャッシュして表示する。
- 詳細画面はプレイヤー名、AI、記録、パーティ等を表示し、フレンド追加や島訪問への入口を持つ。

## 非同期ゴースト戦

- 闘技場はフレンドまたはランキングプレイヤーの保存パーティを相手として再構成する。
- 防衛戦は保存された防衛パーティとの模擬戦を行う。
- TCGはアップロード済みデッキを取得し、CPU操作するゴーストデッキとして対戦する。
- 対戦中に相手のリアルタイム接続は不要で、相手の元データを変更しない。

## 更新・キャッシュ

- 新記録時に上位記録を更新し、通常帰還・死亡のどちらもダンジョン記録送信対象。
- モード別にキャッシュキーを分け、明示更新以外は一定期間の結果を再利用する。
- ロード時は闘技場等の進行中UI状態をリセットし、セーブ復元で戦闘途中へ誤復帰しない。

## 主な実装

- `cloud_manager.js`: 各ランキングとオンラインデッキの通信。
- `feature_arena.js`: 闘技場ランキング・幻影戦。
- `feature_defense.js`: 防衛ランキング・模擬戦。
- `dungeon_core.js`: ダンジョン記録送信。
- `tcg_core.js`: オンラインデッキ対戦。

## 確定している将来仕様

- 訪問先カジノでは、所有者が公開したデッキと正規化済みAI作戦のスナップショットを使ってTCGゴースト戦できる。
- 移転可能な報酬、島の収益、正式ランキングへ影響する結果はサーバー検証対象とし、ローカルだけで確定しない。
- リアルタイム対戦は非同期ゴースト戦から分離し、将来実装する場合は専用のサーバー権威型対戦サービスが所有する。
- 闘技場・防衛戦で住人を編成する将来仕様では、ランキングに住人本体への参照を保存せず、登録時点の能力、姿、習得語、作戦、装備効果等の戦闘用スナップショットだけを保存する。内部の住人ID、収納、所持品、予定、現在地等は送信しない。フレンド模擬戦の相手はこの習得語と作戦を再現し、相手側の元データや住人状態を変更しない。
- 各ランキングモードで最後に正常取得した上位50件と対戦用パーティスナップショットを、再起動後も残る端末内の専用領域へ保存する。通信失敗、認証切れ、空の応答では正常な保存済み記録を上書きしない。
- オンラインサービス終了後も、保存済み記録がある端末では更新されない `オフライン殿堂` としてランキング閲覧、闘技場のフレンド幻影戦、防衛戦のフレンド模擬戦を継続する。順位更新、新規相手取得、フレンド追加、島訪問等のクラウド依存操作は無効化する。保存済み記録がない端末ではオンライン由来の入口自体を表示せず、NPC等で補充しない。
- オフライン殿堂は通常のゲームセーブと分離して端末単位で保持し、ゲーム本編の完全初期化では削除しない。ゲーム設定に `保存済みオンライン記録を削除` を用意し、プレイヤーが明示した場合だけ消去する。
- 各対戦用スナップショットへ戦闘仕様バージョンを保存し、ゲーム更新後は可能な範囲で互換変換する。変換できない古い記録もランキング表示には残し、対戦操作だけを無効化して理由を表示する。
- オンラインサービスの稼働中は、未ログインのプレイヤーへランキングやオンライン由来の機能入口を表示せず、その機能の存在を前提とする案内も出さない。通常のログアウトや一時的な認証切れを、サービス終了とは扱わない。
- ゲーム更新で配布する明示的な `オンラインサービス終了済み` の状態を、通常ランキングからオフライン殿堂へ恒久切替する正規条件とする。単なる通信失敗時は、ログイン済みなら保存済み記録を一時オフライン表示して再接続を許可し、終了済み表示や不可逆な切替は行わない。終了済み状態では、端末内に保存済み記録がある場合だけログインを要求せずオフライン殿堂を表示する。
- Steamその他で正式公開・販売する時点では、開発中に登録されたランキング記録を本番記録へ移行せず、サーバー側の全開発ランキングと端末内の開発ランキングキャッシュを初期化する。公開前の順位、対戦用スナップショット、フレンド幻影・模擬戦候補を製品版のオフライン殿堂へ残さない。正式公開後のシーズンリセットやサービス終了時の殿堂保存とは別の、発売時一回限りの開発データ破棄として扱う。

## 構想段階の案

- シーズン、報酬、リプレイ、より詳細な対戦分析を追加する可能性がある。

## 未決定事項

- 不正記録対策、シーズンリセット、同率順位、ランキング報酬は未決定。
- ログイン中のランキング表示入口を育成画面側に置くか、城内に置くかは未決定。城内マップ実装時点では専用入口を追加しない。
- サービス終了を告知する具体的な画面と文章、終了済み更新を受け取れない旧版端末の扱い、長期保存形式の移行方法。
