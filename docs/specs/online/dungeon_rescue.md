# ダンジョン救助仕様

状態: 実装済み・実機総合検証要

## 救助要請

- ダンジョンで倒れたとき、マップ種別と到達階を含む救助要請をFirestoreへ送る。
- 要請状態は `waiting` とし、ローカルにも救助待ちマップ・階を保存する。
- 救助待ち画面は通常ゲーム進行をロックし、一定間隔で自分の要請状態を確認する。
- 要請をキャンセルした場合は通常死亡扱いとなり、該当ダンジョンのロスト規則を適用する。

## 救助する側

- 同じマップ種別の自分以外の `waiting` 要請をフロア生成時等に取得する。
- 対象プレイヤーを救助するコンテンツを完了すると、要請を `rescued` へ更新する。

## 救助完了

- 待機側が `rescued` を検出すると、HPを最大の半分、満腹度を50へ戻す。
- `closeDungeonUI(false, true)` の救助帰還として処理し、生還と同じ道中品返却・報酬条件を使う。
- 救助後は待機状態と監視タイマーを消す。

## 主な実装

- `cloud_manager.js`: `requestRescue()`, `fetchRescueRequests()`, `completeRescue()`, `checkMyRescueStatus()`。
- `dungeon_core.js`: 要請UI、待機、キャンセル、救助帰還。
- `dungeon_generator.js`: 救助候補の取得とフロア反映。
