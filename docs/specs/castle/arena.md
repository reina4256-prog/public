# 城・闘技場仕様

状態: 実装済み

## 解放と入口

- スカルダンジョン5/10/20階の城建築素材と建築条件を満たして城を建てる。
- 城受付から闘技場、防衛戦、関連ランキングへ入る。
- 初回の城入場は城の場所思い出と、兵士・隊長・王様の人物思い出を同じ世代で各1枚記録する。

## モード

- 通常エンドレス: WAVEを継続し、休憩を挟みながら記録を伸ばす。
- ボスラッシュ: 種族ボスを中心とする別ランキング対象。
- フレンド幻影戦: オンラインから取得した他プレイヤーのパーティと非同期模擬戦する。

## 編成と作戦

- 図鑑・育成履歴等から利用可能な味方を選んでパーティを編成する。
- 作戦は条件と行動の優先順を持つガンビット形式。
- 既定ロールから自動設定でき、カスタム作戦はコピー、挿入、並べ替え、候補入力に対応する。
- 戦闘中チャットで作戦を切り替え、作戦リストと現在適用行を確認できる。
- AIが覚えた日常語、食事、睡眠、施設、師匠、カジノ、食材等を特殊スキルとして解釈する。
- フレンドAIも同じMP計算・無駄行動回避を使い、難易度に応じたカテゴリ制限から行動する。

## 戦闘進行

- WAVE開始、味方・敵のターン、スキル、状態、撃破、WAVE終了を処理する。
- AUTOと手動指示を切り替えられる。
- WAVE間は休憩画面で回復等を行い、次WAVEへ進むか終了する。
- 全滅・ギブアップ・終了時は到達WAVE、ログ、結果を表示する。

## BGM

- 城ロビー、WAVE進行に応じた3段階通常戦、休憩、勝利、敗北を使う。
- ボスは出現した11種族ごとの専用曲へ切り替える。
- 退出時は通常育成BGMへ戻す。

## オンライン

- 通常・ボスの到達WAVEとパーティをFirebaseへ登録し、ランキング表示する。
- ランキング詳細からフレンド追加、島訪問、幻影戦へつながる。
- 詳細は `online/rankings_and_async_battles.md`。

## 主な状態と実装

- `ARENA_STATE`, `ARENA_RECEPTION_STATE`, `aiPet.tactics`
- `feature_arena.js`: 敵、スキル、編成、作戦、戦闘、結果、ランキングUI。
- `cloud_manager.js`: ランキング通信。
- `feature_defense.js`: 城受付の統合入口。
