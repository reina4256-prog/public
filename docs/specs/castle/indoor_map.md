# 城・屋内マップ仕様

状態: 実装済み

## 現在の実装仕様

- 城へ入ると `castle_map_core.js` 所有の一枚の連続屋内マップを開く。王城総合受付は存在しない。
- マップは1室14×10マス、全体42×20マスの3列×2段。並びは次で固定する。
  - 上段: 祈祷室（占い師）｜玉座の間（王様）｜研究室（科学者）
  - 下段: 作戦会議室（隊長）｜詰所（兵士）｜競売所（販売員）
- 部屋間には4マス幅の開口部を設ける。扉、クリック／タップによる部屋切替、別マップ遷移は使わない。
- 城の出入口は下段中央の詰所南側に置く。入場時は出口の一歩内側へ立ち、退出指示では出口まで実際に歩いてから屋外へ戻る。
- マップ上のクリック／タップ移動は行わない。チャットで人物名、部屋名、または関連語を指示すると、障害物とNPCを避けて対象人物の隣まで歩き、互いに向き合って到着後会話を開始する。
- 行き先一覧のボタンも座標移動を直接実行せず、同じチャット命令処理へ人物名を渡す。
- 6人は各室の定位置に置く。現在は室内巡回しない。
- 王様は通常防衛戦と、通常防衛WAVE 10クリア後のエンドレス防衛戦をクエストとして提示する。城を配置しただけで防衛戦は自動発生しない。
- 隊長は闘技場クエストを提示し、既存の通常エンドレス、ボスラッシュ、フレンド幻影戦の編成・作戦画面へつなぐ。
- 受注準備のキャンセル、戦闘からの撤退、結果確認後は、受注元の王様または隊長がいる城内マップへ戻る。
- 兵士の通常会話は「お疲れさまです！ 城内の警備は異常ありません。どうぞごゆっくり！」。
- 王様の通常会話は「よくぞ参った。島を守る覚悟があるなら、余にそなたの力を示してみよ。」。
- 隊長の通常会話は「訓練に来たか？ 闘技場では力だけでなく、準備と作戦が勝敗を分ける。」。
- 占い師、科学者、販売員は城内NPCと通常会話のみ実装済み。弟子入り・Rank課題は未実装で、会話画面には準備中と表示する。人物設定と会話文の正本は各職業仕様とする。
- 初回入場時の城の場所思い出と、兵士・隊長・王様の人物思い出は、従来どおり同じ世代で各1枚記録する。
- `CASTLE_SPRITES` は各画像につき床・壁・室内装飾の3定義、合計18定義を持つ。統合調整画面の `CASTLE（城マップチップ）` から切り取り位置、範囲、拡大率等を調整し、城マップへ即時反映できる。
- 使用するマップチップ画像は次のとおり。
  - 祈祷室: `prayroom_mapchip.png`
  - 玉座の間: `throneroom_mapchip.png`
  - 研究室: `labo_mapchip.png`
  - 作戦会議室: `operationroom_mapchip.png`
  - 詰所: `dutyroom_mapchip.png`
  - 競売所: `auctionroom_mapchip.png`
