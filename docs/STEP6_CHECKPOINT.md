# 工程6の中断・再開メモ

更新日: 2026-09-20

## 今回の区切り

- 工程6は一部実装の状態で、ユーザーの指示によりコミット・リモート保存して一旦中断する。
- 次のチャットは別の優先事項の壁打ち・仕様化から始める。工程6の再開指示があったら、以下の残作業から続ける。
- 工程7と城の中央表示移行は保留。城・カジノ・ダンジョンは従来の画面を使用する。
- 新規画像と販売員の遭遇動画も保管するが、素材の存在を機能の実装完了と解釈しない。

## 維持する実装

- 共通シーン・多重停止、マイホーム・レストラン・鍛冶屋の中央表示、共通ログ、チャットによる退出。
- 住人ID・個人財産・四人小屋・名簿・島内移動と、保存失敗時の復旧。
- 曜日別日課、個人食事、基本育成、簡易採集・釣り、試算、不在精算・報告、加齢・鮮度・寿命境界。
- プレイ中の主人公の日課は通常タスクを使い、歩行・入場・アニメーション・進捗を動かす。日課解除は手動タスクを保持する。住人の日課解除後は住宅再設定なしで通常行動へ戻る。
- 調合・裁縫の材料・抽選・成果・技能を主人公と住人で共通化。住人の日課は既存の本人Rankを必要とし、目的地への移動と入退場を経て1区間1回実行する。
- 薬剤師Rank 2は主人公・住人とも薬草＋水から風邪薬を作り、成功3回を数える。未完了の制作結果は保存・再開でき、成果を二重付与しない。

## 残作業と最初の確認箇所

1. **住人の職業進行**: 自律弟子入り、個人別の受注・受注後成果・報告・皆伝を接続する。`ai_core.js:getMasterQuestData` はまだグローバル主人公を参照するため、そのまま住人へ流用しない。主人公用の世界解放・人物カード・世代限定報酬を重複付与しない。
2. **未接続の職業実技**: 基本職6職と残る上級職の個人処理を接続する。承認済みの代替課題は [弟子入り共通仕様](specs/careers/apprenticeship_common.md) から各職業仕様へ進む。調合・裁縫2種類の接続を工程6全体の完成と扱わない。
3. **通常行動と不在計算の同等性**: `schedule_core.js:simulateActor`、`schedule_runtime.js:simulate/context` と通常の `aiPet.update` を比較する。移動・完了単位、モニュメント短縮、日次・カード等の付随効果、長時間不在後の屋内状態の整合を仕上げる。
4. **世界の不在進行**: 天候・病気経過・進化・建物や環境等の処理を、個人鮮度と同じく完了済みとは扱わない。既存店舗の実時間タイマーも全面統合されていない。
5. **実機確認**: 長期不在・停止・復帰報告・死亡／世代交代の組合せを追加確認する。Electronの終了IPCは自動テストで検証済みだが、配布版アプリの実機検証は未実施。

## カジノの追加決定

住人で一般CPU枠を補い、足りなければ人数を減らす。ゲームの最低人数に届かなければ開始できず、宝石名のCPUや住人の複製で補充しない。トランプには個人TCGデッキは不要、TCGには合法な個人デッキが必要。コード接続は未実施。参加予約・来店選出・住人別戦績の詳細は [カジノ仕様](specs/casino/casino_dealer_and_map.md) を確認して詰める。

## 再開時の検証

- `tests/*.test.js`: 保存互換・世代交代・不在精算・調合裁縫・日課解除等。今回24本すべて成功。
- `node tests/game_shell_browser.cjs`: 中央マイホーム・停止・退出。
- 同ランナーの `--test-schedule`、`--test-craft`: 通常移動・屋内日課・進捗・保存とページ再読込。
- `--test-facilities`、`--test-residents`、`--test-directory`、`--test-exam`: 各屋内と住人画面・試験の回帰検証。
- コミット直前には標準ランナー、`--test-facilities`、`--test-residents` を再実行して成功。日課・調合のページ再読込検証も直前の実装ターンで成功している。
- ブラウザテストは専用ポート4187・専用プロファイルを使い、実プレイヤーのセーブを開かない。同じポートを使うので同時実行しない。
- JavaScript構文、`npm run i18n:check`（14,531件・7言語）、`git diff --check` を確認する。

現時点の検証で進行不能は検出していないが、全セーブ・全操作の無不具合を保証するものではない。未対応の不在タスクは保持して停止するため、未実装の住人修行が通常主人公の進行を置き換えることはない。
