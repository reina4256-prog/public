# 維持条件と保留の入口

この表は現在状態への案内。原条件・例外・全API途中詳細は各所有仕様へ保持し、要約で置換しない。

## 全作業で維持

- 原入力・入力当時の知識と理解・実際の応答／経験を分離する。後の知識で原資料を書き換えず、未理解・主体・時点・極性・出所欠落を補完しない。
- 同じ入力の再読・再受信で候補／学習／経験を増やさない。新入力と反復表示を区別する。語義IDだけで経験由来scopeを転移しない。
- 独立部品の検証をゲーム本接続・本人日記生成・実ユーザー保存・再開・配布検証へ昇格しない。発話能力と理解を分離する。
- 旧AI・旧保存・実ユーザー保存・確認済み九見本と星座を非操作・非置換。対象外`%SystemDrive%/`は非操作・commit対象外。
- 最新ao〜bt人間OKを過去の未受領表示より優先。今回確認済み範囲を再確認からやり直さない。新系統の対象・成立条件は個別相談。
- 既存担当を重複した残件に数えない。未決定を永久対象外へ移して完了扱いにしない。途中保存は移動合図ではなく、新チャット移動はユーザー明示時だけ。
