# Geminiの返答と比較する

通常版は `npm run start:word` のままです。比較版は返答をGeminiの一般知識で作り、本人の理解・学習・行動は既存方式を維持します。プレイヤーの言葉を会話用ノートに残し、比較版の心の声は一旦表示／読み上げなしにしています。[保存範囲と仕様](../specs/core/word_llm_reply_comparison.md)を参照してください。

旧Gemini CLIでは、個人のGoogle AI Pro／Ultraはサポート終了のため接続できませんでした。ブラウザーの許可成功だけでは接続完了ではありません。現在は公式の後継Antigravity CLIを使うので、一度こちらで認証し直してください。

## 初回の準備

プロジェクトのターミナルで実行します。

```powershell
npm run setup:word:gemini
```

公式Windows x64 CLIをプロジェクト内のキャッシュへ取得し、固定版の検証hashを確認します。PATH変更やVS Code拡張の導入は不要です。初回取得には通信と時間がかかります。

ログイン方法は **Google OAuth** を選び、契約中の個人Googleアカウントを使ってください。**Use a Google Cloud project、APIキー、追加クレジットの購入は使いません。** 既存の他ツールの設定／MCP等も取り込まないでください。workspaceの信頼確認が出た場合は、今回のworkspaceだけを対象にします。

専用の手動認証方式を使います。CLIに表示されたURLをブラウザーで開き、Googleの案内で認証してください。「このコードをアプリケーションに貼り付けてください」と表示されたら、`npm run setup:word:gemini` を実行したVS Code下部のターミナルへ戻ります。認証コードの入力待ちの欄にCtrl＋Shift＋Vで貼り付け、Enterで確定してください。ゲームの自由入力欄やこのチャットには貼り付けません。CLIの入力画面に戻ったら `/quit` で終了します。

長い案内で「1–19 of 28 lines」のように表示され、入力欄が見えない場合は、ターミナルをクリックしてShift＋↓で案内の末尾へ進みます。認証コードは画面共有やスクリーンショットでも隠してください。

`invalid_grant` が出た場合は、キーを押して戻り、Google OAuthから新しいURLとコードを取り直します。古いコードは使いません。認証後に色の初期設定が表示されたら、`terminal` のままEnterで進められます。通常の入力画面に戻ってから `/quit` を入力します。

改善目的の利用データ提供画面では、希望しなければ選択中のチェックをEnterで外し、↓キーで`Done`へ移動してEnterで完了します。この同意設定はCLIの初期設定であり、ゲーム側のJSONから変更するものではありません。

認証情報は後継CLI自身が比較版専用homeへ保存します。旧CLIのtokenを流用せず、OS全体の共有keyringや通常版の保存を移し替えません。認証画面で別途課金やCloudの請求登録を求められた場合は、進めずに終了してください。

## 比較版の起動

```powershell
npm run start:word:gemini
```

比較版の保存先は通常版と別です。比較版の子は比較版の「つづきから」で再開します。今回の修正前に比較版で作った子も引き継ぎます。本人の声設定を選んで返答を読み上げられます。

入力、直近の生成成功会話、本人の設定、元方式の返答による状況と、関連する会話用ノートの抜粋をGoogleへ送ります。場所や周囲の物は自動送信せず、プレイヤーから伝える過程を残します。生成文から本人の知識は増やしません。一般知識で会話できることと、本人が行動に使える理解・習得は別です。

手動で話した内容は、質問も含め「この子のノート」の「お話の記録」に原文で残り、同じ子の「つづきから」でも会話に使います。返答に使うのは最大12件・計8000文字の抜粋です。元の記録は切り詰めず、新しい子へは移しません。以前の試遊ログから過去の会話を取り込む機能はありません。実装前からの本人の知識／ノートと声設定は保持します。

ゲーム中の待機・失敗案内にはAIの製品名やCLIコマンドを出しません。接続準備の案内が出た場合は、この文書のsetup手順を確認してください。比較版だけ心の声を出さず、通常版は従来どおりです。

## 利用枠と停止

既存契約の利用枠を消費しますが、**追加クレジットはOFFに固定**します。各起動で `useG1Credits:false` をsession設定として渡し、APIキー方式やGoogle Cloud従量課金へ自動切替しません。枠が尽きた場合は理由を案内して通常方式の返答を使い、枠の回復を待ちます。クレジット購入や上位契約は不要です。[Google公式の契約枠](https://antigravity.google/docs/plans/)／[CLIのクレジット設定](https://antigravity.google/docs/cli/credits)。

返答待ちの間はゲームの行動を保留します。新しい入力や「音声を止める」で取り消せます。未認証・未導入はsetup案内、サポート終了と利用枠到達はそれぞれ別に表示します。ゲームから勝手に認証を始めません。

モデルはCLIの既定です。必要なら `WORD_GEMINI_MODEL` へ、そのアカウントで利用可能なモデルIDを設定できます。モデル指定を変えても追加クレジットOFFは維持します。

別PCでは先に `npm ci` を実行し、そのPCでsetup／認証を行います。キャッシュが消えた場合もsetupを再実行します。現在の導入対象はWindows x64です。固定CLIは自動更新しません。

実CLIの無生成確認、fixtureの画面検証、実アカウントでの応答確認は区別して[現行引継ぎ](../CURRENT_IMPLEMENTATION.md)へ記録します。
