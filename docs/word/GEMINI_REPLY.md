# Geminiの返答と比較する

## 契約内モデル・入力途中の先送り・音声の調査（2026-11-20）

固定CLI1.5.12の組込み`models`、headlessの`/model`と`/effort`を読み取り専用で照会しました。現在は`gemini-4-neon-high`／`high`。3照会とも終了0、生成リクエストなし、永続settings.jsonの前後SHA一致です。ゲームのモデル・処理設定は変更していません。

短い雑談向けの比較候補は以下です。すべてこのアカウントのCLI一覧に掲載され、[公式のモデル表](https://antigravity.google/docs/models)でもGoogle AI Proの対象ですが、個別の生成成功・残りquota・応答速度／日本語の品質は今回未確認です。

| 比較候補 | CLIのID | 比較する目的 |
| --- | --- | --- |
| 現NeonをLowにする | `gemini-4-neon-low` | モデル系統を保ち、思考量を抑える効果を見る |
| Gemini 3.8 Flash Low | `gemini-3.8-flash-low` | Flash系で短い会話の速度と本人らしさを比較する |
| Gemini 4 Hydrogen Low | `gemini-4-hydrogen-low` | 速度重視の別系統も比較する |

[公式のeffort説明](https://antigravity.google/docs/cli/commands/effort)ではLowは軽い推論向けで、`--effort`はその起動だけに適用され、既定を永続変更しません。現helperはモデル指定に対応しますがeffort指定は未接続で、今回は追加しません。API専用のthinkingBudget等をGoogle OAuth CLIへそのまま渡せるとは扱いません。Orchestratorの計画／実行分担は今回の短い雑談の第一候補にしません。いずれも採用・合成比較は次の合意後です。

入力途中の先送りには次の違いがあります。

- 接続／プロセスの準備だけを先行させ、下書き本文は送らない：起動負担を入力時間と重ねられる可能性があります。前回のinit通知4.5～6.3秒が全て削れる保証はありません。継続プロセスの履歴・取消条件は別途設計が必要です。
- 下書きから推測生成する：送信後の待ちを隠せる場合はありますが、IME変換・削除・語尾の否定によって意味が変わり、作り直しやquota消費が増えます。確定文との一致を検査し、未送信・取消済み内容を本人の原文ノート／理解／行動へ混ぜないことが必要です。今回は外部送信も生成も行いません。
- [現CLIのstdin](https://antigravity.google/docs/cli/headless/)は一行ごとに一ターンを実行します。文章を少しずつ送って同じ入力の編集として扱う機能ではありません。[Live APIの増分context](https://aistudio.google.com/docs/live-api/capabilities#incremental-updates)には未完了ターンの送信手段がありますが、未完文の計算先行や具体的な短縮量の保証とは区別します。下書き送信は現在の送信範囲の拡張なので、先に相談します。

音声は次の3経路を区別します。今回マイク・音声engine・音声APIは起動していません。

| 経路 | 費用・組込み | 待ち時間と保持条件 |
| --- | --- | --- |
| 既存のPC内認識→確定文字→CLI→本人の選択声 | 現契約内CLIとローカル音声。現在は保留 | 途中認識は入力欄用で、現方式は確定／手動送信後に返答生成。音声化だけではCLI本文前の待ちはなくならず、認識／読み上げのPC負荷も残る |
| Antigravity内の音声会話 | [公式voice mode](https://antigravity.google/docs/voice-mode/)はGemini Liveを使い、雑談／割込み／継続に対応。実アカウントの音声利用可否・枠は未確認 | 公式にprint mode非対応。現在のゲームtransportからそのまま使える音声APIではない。CLI内で選ぶ声はゲームの保存済みの声とは別 |
| ゲームからDeveloper Live APIへ接続 | [料金表](https://aistudio.google.com/docs/pricing#gemini-3.8-live)に無料枠あり。CLI契約と別。請求有効化・有料API・追加購入は禁止、枠不足なら停止 | 日本語・音声逐次送信・割込み・文字起こしに対応。会話用モデルで、ローカル認識／読み上げを省ける可能性がある。現声の同一再現・PC負荷／応答時間は未確認 |

Live APIの第一調査候補は`gemini-3.8-live`。[公式の用途比較](https://aistudio.google.com/docs/live-api/thinking)は通常Liveを低遅延の会話に、Extended Thinkingを複雑な分析／長いtool処理に推奨しています。3.8通常LiveにはthinkingLevelを設定しません。3.1 Flash Liveはlegacy previewのため新規第一候補にしません。実際の無料枠は[AI Studioの対象project／model](https://aistudio.google.com/docs/rate-limits)で確認する必要があり、無料で無制限とは扱いません。

音声逐次送信では、発話中に転送／音声理解を進め、話し終わり後の待ちを減らせる可能性があります。ただし語尾の確定と発話終了検出の待ちは残ります。[VAD設定](https://aistudio.google.com/docs/live-api/capabilities#configure-automatic-vad)を短くしすぎると考え中の間や日本語の途中で切れます。押して話す方式なら明示終了で区切る案もありますが、未採用です。Live APIの再接続／会話継続はゲームの原文ノートの永続化とは別で、本人設定・ノートはゲーム側を正本とし、生成文／暫定認識を習得や実績へ採用しません。マイク原音の外部送信・無料枠の製品改善利用・声の変更・セッション履歴の範囲を合意してから試します。現音声の再導入と4修正候補は保留を維持します。

## 文字応答の初回遅延調査（2026-11-20）

既存契約の追加クレジットOFF・既定モデル・毎回別CLI起動の現方式を変えず、未変更の返答helperを合成の同一日本語入力3件で計測しました。実際の本人の保存・ノート・声設定は使用していません。本人の設定やノートを含む実会話の速度を保証する値ではありません。

| 入力からの経過時間 | 1件目 | 2件目 | 3件目 |
| --- | --- | --- | --- |
| CLIのinitイベント | 6.284秒 | 4.732秒 | 4.523秒 |
| 最初の返答本文delta | 27.093秒 | 19.225秒 | 26.470秒 |
| terminal result（返答完成） | 27.834秒 | 19.682秒 | 26.957秒 |
| helperの結果受取 | 28.711秒 | 20.496秒 | 27.964秒 |

3件とも成功、返答42～49文字。最初の本文からhelper結果までは1.271～1.618秒で、主な待ち時間は本文が届く前にあります。initまでの時間は純粋なプロセス起動時間ではなく、CLI初期化等を含みます。init後も初本文まで14.493～21.948秒かかっていますが、通信・サービス側の待ち・内部計算の内訳は分離できません。usageのthinking_tokensは1065～1768でしたが、その数値だけで遅延原因は断定しません。

この測定はCLIからhelperまでで、ElectronのIPC・実画面への表示／paintは未計測です。ゲーム側はhelper結果後に表示する現方式のまま。段階表示や接続再利用は未採用で、モデル切替・音声再開もしていません。公式CLIの[本文deltaと継続プロセス](https://antigravity.google/docs/cli/headless/)は次の検討候補ですが、取消済み返答や古い本人状態をCLI内に残すことによる送信・会話記憶の境界も先に相談します。

ユーザーの希望によりGemini側を優先し、会社契約のChatGPT Pro特典をゲーム用に使うことは前提にしません。採用／切替／高速化実装は別途合意後です。合成測定の詳細時刻・event種別／文字数／usageはlocal診断JSONに残し、CLI原出力・生成本文・内部思考・認証情報は保存していません。

## 現在の切り分け：音声を使わず起動する

音声サービス停止後はユーザーの実試遊でスムーズな会話を確認しています。音声込みの完成形は引き続き目標ですが、音声対応は現在保留中です。[現在の方針](../specs/core/word_llm_reply_comparison.md)に従い、当面は下記の文字のみコマンドを使います。

実試遊中にWindowsのメモリ不足が記録されたため、まず比較版を閉じ、次のコマンドで文字だけの会話を確認します。

```powershell
npm run start:word:gemini:text
```

同じ比較版の「つづきから」を使えます。本人・会話ノート・選択した声と調整値は保持します。この起動中だけマイク・読み上げ・試聴・師匠の音声生成を使わず、音声エンジンも自動起動しません。ゲーム内に音声を使わない確認モードの案内が出ます。再認証や本人の作り直しは不要です。

既に常駐している音声エンジンを自動終了するコマンドではありません。今回の切り分けでは承認を受けて対象エンジンを一時停止しました。通常の `npm run start:word:gemini` は音声エンジンを起動するため、確認中はこちらの `:text` を使ってください。通常起動へ戻せば保存済みの声設定を再使用します。

白画面・接続失敗の原因が確定／解消したという意味ではありません。文字だけでも再発するかを確認します。追加クレジットOFFなど、以下の条件は同じです。

本人の現在活動と、起動中の直前の休息・食事・移動を会話に使います。ときどきプレイヤーへ問いかけ、実体験のあとに本人から話すこともあります。返事がなければ催促しません。入力中／返答待ちは世界の進行を保留したまま、本人のアニメーションを継続します。本人の子・声・会話用ノートの保存、追加クレジットOFFは従来どおりです。

通常版は `npm run start:word` のままです。比較版は返答をGeminiの一般知識で作り、本人の理解・学習・行動は既存方式を維持します。プレイヤーの言葉を会話用ノートに残し、比較版の心の声は一旦表示／読み上げなしにしています。[保存範囲と仕様](../specs/core/word_llm_reply_comparison.md)を参照してください。

旧Gemini CLIでは、個人のGoogle AI Pro／Ultraはサポート終了のため接続できませんでした。ブラウザーの許可成功だけでは接続完了ではありません。現在は公式の後継Antigravity CLIを使うので、一度こちらで認証し直してください。

## 初回の準備

プロジェクトのターミナルで実行します。

```powershell
npm run setup:word:gemini
```

公式Windows x64 CLIをプロジェクト内のキャッシュへ取得し、固定版の検証hashを確認します。PATH変更やVS Code拡張の導入は不要です。初回取得には通信と時間がかかります。

ログイン方法は **Google OAuth** を選び、契約中の個人Googleアカウントを使ってください。**Use a Google Cloud project、APIキー、追加クレジットの購入は使いません。** 既存の他ツールの設定／MCP等も取り込まないでください。workspaceの信頼確認が出た場合は、今回のworkspaceだけを対象にします。

専用の手動認証方式を使います。CLIに表示されたURLをブラウザーで開き、Googleの案内で認証してください。「このコードをアプリケーションに貼り付けてください」と表示されたら、`npm run setup:word:gemini` を実行したVS Code下部のターミナルへ戻ります。認証コードの入力待ちの欄にCtrl＋Shift＋Vで貼り付け、Enterで確定してください。ゲームの自由入力欄やこのチャットには貼り付けません。CLIの入力画面に戻ったら `/quit` で終了します。

長い案内で「1–19 of 28 lines」のように表示され、入力欄が見えない場合は、ターミナルをクリックしてShift＋↓で案内の末尾へ進みます。認証コードは画面共有やスクリーンショットでも隠してください。

`invalid_grant` が出た場合は、キーを押して戻り、Google OAuthから新しいURLとコードを取り直します。古いコードは使いません。認証後に色の初期設定が表示されたら、`terminal` のままEnterで進められます。通常の入力画面に戻ってから `/quit` を入力します。

改善目的の利用データ提供画面では、希望しなければ選択中のチェックをEnterで外し、↓キーで`Done`へ移動してEnterで完了します。この同意設定はCLIの初期設定であり、ゲーム側のJSONから変更するものではありません。

認証情報は後継CLI自身が比較版専用homeへ保存します。旧CLIのtokenを流用せず、OS全体の共有keyringや通常版の保存を移し替えません。認証画面で別途課金やCloudの請求登録を求められた場合は、進めずに終了してください。

## 比較版の起動

```powershell
npm run start:word:gemini
```

比較版の保存先は通常版と別です。比較版の子は比較版の「つづきから」で再開します。今回の修正前に比較版で作った子も引き継ぎます。本人の声設定を選んで返答を読み上げられます。

入力、直近の生成成功会話、本人の設定、元方式の返答による状況と、関連する会話用ノートの抜粋をGoogleへ送ります。場所や周囲の物は自動送信せず、プレイヤーから伝える過程を残します。生成文から本人の知識は増やしません。一般知識で会話できることと、本人が行動に使える理解・習得は別です。

手動で話した内容は、質問も含め「この子のノート」の「お話の記録」に原文で残り、同じ子の「つづきから」でも会話に使います。返答に使うのは最大12件・計8000文字の抜粋です。元の記録は切り詰めず、新しい子へは移しません。以前の試遊ログから過去の会話を取り込む機能はありません。実装前からの本人の知識／ノートと声設定は保持します。

ゲーム中の待機・失敗案内にはAIの製品名やCLIコマンドを出しません。接続準備の案内が出た場合は、この文書のsetup手順を確認してください。比較版だけ心の声を出さず、通常版は従来どおりです。

比較版では、会話用ノートに残した声かけに対して「まだ十分には伝わっていません」と会話全体を否定せず、記録したことと行動につながる理解の不足を分けて案内します。返答も毎回の感謝・復唱・追加質問を避け、説明を受け取った短い反応で終えてよい方針です。実際の行動決定は既存のままで、未実行の依頼を実行する約束へ変えません。本人の実体験を会話に覚えさせる範囲は、今後の相談事項です。

## 利用枠と停止

既存契約の利用枠を消費しますが、**追加クレジットはOFFに固定**します。各起動で `useG1Credits:false` をsession設定として渡し、APIキー方式やGoogle Cloud従量課金へ自動切替しません。枠が尽きた場合は理由を案内して通常方式の返答を使い、枠の回復を待ちます。クレジット購入や上位契約は不要です。[Google公式の契約枠](https://antigravity.google/docs/plans/)／[CLIのクレジット設定](https://antigravity.google/docs/cli/credits)。

返答待ちの間はゲームの行動を保留します。新しい入力や「音声を止める」で取り消せます。未認証・未導入はsetup案内、サポート終了と利用枠到達はそれぞれ別に表示します。ゲームから勝手に認証を始めません。

モデルはCLIの既定です。必要なら `WORD_GEMINI_MODEL` へ、そのアカウントで利用可能なモデルIDを設定できます。モデル指定を変えても追加クレジットOFFは維持します。

別PCでは先に `npm ci` を実行し、そのPCでsetup／認証を行います。キャッシュが消えた場合もsetupを再実行します。現在の導入対象はWindows x64です。固定CLIは自動更新しません。

実CLIの無生成確認、fixtureの画面検証、実アカウントでの応答確認は区別して[現行引継ぎ](../CURRENT_IMPLEMENTATION.md)へ記録します。
