# Geminiの返答と比較する

通常版は従来どおり`npm run start:word`です。比較版は、同じ自由入力の返答だけをGemini自身の一般知識で作ります。理解・学習・行動と心の声は既存方式です。[保存範囲と仕様](../specs/core/word_llm_reply_comparison.md)を参照してください。

最初に、このプロジェクトのターミナルで実行します。

```powershell
npm run setup:word:gemini
```

契約しているGoogleアカウントで、CLIの案内に従ってブラウザーからログインしてください。APIキーは不要です。ログインしてCLIの入力画面に戻ったら、Ctrl+Cまたは`/quit`で終了します。認証情報は比較版専用のフォルダーに保存され、通常のGemini CLI設定を変更しません。ここでAPIキーやパスワードをチャットへ貼る必要はありません。

次に比較版を起動します。

```powershell
npm run start:word:gemini
```

比較版の保存先は通常版と別です。比較版で新しい子を始め、以後は比較版の「つづきから」で再開します。通常版で育てた子の保存は書き換えません。返答の声は、比較版でも本人の声設定から選べます。

入力、直近の生成成功会話、本人の設定、原方式の返答による状況をGoogleへ送ります。生成文から本人の知識を自動で増やしません。心の声では「意味がまだ分からない」と表示されても、Gemini側は一般知識で答えられる場合があります。

返答待ちの間は行動が止まります。新しい入力や「音声を止める」などで生成を取り消せます。未ログインや利用枠・接続の問題がある場合は、その旨を表示して通常方式の返答を使います。Geminiの契約枠が自動でAPIキーの従量課金へ切り替わることはありません。

モデルはCLIの既定選択です。Googleアカウントで利用可能な特定のモデルを比較したい場合だけ、`WORD_GEMINI_MODEL`へモデルIDを設定してから起動できます。モデル名や利用枠はCLI／Google側で確認してください。

このフォルダーを別PCへ取得した場合は先に`npm ci`を実行します。CLIはプロジェクト内の固定版を使い、グローバル導入は不要です。認証はPCごとに行います。実Googleログインと本物の応答を確認できたかどうかは、[現行引継ぎ](../CURRENT_IMPLEMENTATION.md)へ実装テストと分けて記録します。
