# 遊び方ガイド：今できること

更新日：2026-11-27

この説明書は、現在開発している **LLM中心の新方式・島のゲーム** 用です。旧版・比較版の機能は含めません。ゲーム外で読む資料で、ゲーム内に説明書画面はありません。

入力例の「この子」は、育てているキャラクターの名前に置き換えてもかまいません。返事や判断はその都度生成されるため、例と同じ台詞になるとは限りません。

## 最初に試すなら

1. 更新後のアプリを再起動し、「つづきから」で今のキャラクターを選びます。
2. 行動や人物との会話が終わった状態で「留守の間、知っている森で木材を集めて」と頼みます。この子が引き受けると予約になります。
3. 「課題を見せて」で予約を確認してから、タイトルへ戻るかアプリを正常終了します。本編にいる間は留守番採集を進めません。
4. 在庫がある場所なら25分ほど後に「つづきから」で同じ子を再開し、挨拶と実成果、「所持品を見せて」「課題を見せて」で数と途中状態を確認します。枯渇した場所だけなら、回復60分＋採集10分＋移動の時間が必要です。距離や資源残数により成果は変わり、25分で2個を保証するものではありません。

特定の一地点へ行きたい場合は、下の「場所を示す・確認する・歩く」の手順を使います。

建築士の二課題を終え、建築士のハートが3以上なら、会いに行くと自分の家の相談ができます。建築士が提案し、この子が自分で応じます。操作の流れは[マイホームを建てる](#マイホームを建てる)を参照してください。建築用のボタンはありません。

## 起動・キャラクターの作成と続き

開発用の起動は、プロジェクトの `public` ディレクトリで次を実行します。

```powershell
npm run start:word:native -- --fast-trial
```

- ロゴ画面をクリックするとタイトルへ進みます。
- **はじめから**：七つの質問に答え、姿を確認して名前・一人称・プレイヤーの呼び方・声を決め、手描きのサインをして開始します。
- **つづきから**：保存済みのキャラクターを再開します。複数いる場合は選択できます。
- **タイトルにもどる**：別のキャラクターを選ぶときに使います。返答の生成中は切り替えできません。

「はじめから」で別の子を作っても、既存の子のセーブは残ります。同じ姿の子では声の設定が共通なので、声の変更は同じ姿の別の子にも関係します。

## 話しかける・教える・訂正する

入力欄に文章を入れ、「送信」を押します。会話、お願い、言葉や出来事についての説明、以前伝えた内容の訂正ができます。

例：

- 「こんにちは。今日はどんなものが見える？」
- 「この場所を、おいらたちの出発点と呼ぼう」
- 「さっきの説明を訂正するね。……」

教えた原文と、この子がどう受け取ったかは区別して残ります。教えたことや返事の文章だけで、実際に歩いた・採った・技能を習得したことにはなりません。

返答待ちの「中止」は、その返答を中止する操作です。既に送った原発言は残ります。

## 場所を示す・確認する・歩く

森・山など、今この子に見える実際の対象を、会話で丸印にしてもらえます。

| 手順 | 入力例 | 起きること |
| --- | --- | --- |
| 対象を相談 | 「近くの山に丸をつけて」 | 候補の山を示す |
| 一致を確認 | 「うん、その山」 | その山だと確認する |
| 別の入力で移動 | 「その山に歩いて行って」 | 実際に通れる経路があれば、山のそばまで歩く |
| 歩行を止める | 「止まって」 | 歩行を停止する |

丸だけ、または「うん」だけでは出発しません。「うん、その山に歩いて行って」のように確認と移動を一緒に伝えても、まず確認までになります。その後、改めて歩くよう伝えてください。

歩くのは対象のそばまでです。レストランなどが見えても、入店や食事までできる意味ではありません。通れる地面や道がなければ、架空の道を作って進むことはありません。

## 冒険家に会う・依頼に参加する

冒険家は森や山を移動しています。**相手が実際に滞在している場所へ到着したとき**に会えます。外のフィールドには人物の姿や現在地を表示しません。以前会った場所に、今もいるとは限りません。

初回の出会いには動画が入り、会話窓でこの子と冒険家のやり取りが進みます。台詞は声と文字で進むので、読み上げや保存の完了を待ってください。

冒険家は森の木材や山の石を二個探して戻る依頼をすることがあります。この子が参加するか、辞退するか、プレイヤーに相談するかを判断します。相談されたら、例えば「冒険家さんの木材探しに参加して」と具体的に伝えます。「うん」だけで参加はしません。

参加すると、現地へ歩く → 二回の探索と発見 → 元の場所へ戻る → 報告と相手の返事、という流れで進みます。**前から持っていた素材の数と、今回の依頼で採った数は別**です。

途中でチャットに話しかける、別のタブを読む、画面を隠すなどすると、会話や探索が中断されることがあります。再開したいときは、例えば「中断している木材探しを再開して」と、対象と再開を明示してください。表示を開閉したり、起動し直したりするだけでは再開しません。既に失敗・終了した会話は、再開できる途中の課題とは異なります。

## 人物を近い順に探してもらう

一地点ずつ指示する代わりに、まとめて探索を頼めます。

> 近い順に山か森に歩いて行って、冒険家さんがいたら教えて

> 近い順に山をまわって、冒険家さんを探してみて

> 近い順に森に歩いて行って、建築士さんがいたら教えて

この子が引き受けると、実際に見える場所から、通れる道のりが近い順に歩きます。**建築士を探せるのは紹介後で、森だけを探します。** 山か森と頼んだ場合も建築士は森だけ、冒険家に森だけと頼んだ場合も森だけです。歩く途中で新しく見えた該当の場所も候補に加え、同じ探索で訪問した場所は繰り返しません。**この一括探索では、場所ごとの丸確認と歩行指示は不要です。** 普通の一地点訪問は従来の確認手順を使います。

実際に指定した人物に会えたら探索を止め、その人物の遭遇演出と会話へ進みます。別人のいる場所に着いただけでは探索を終えません。会えずに候補が尽きた場合は、今回見て回れた範囲での未発見を画面に表示して止まります。島のどこにもいないという意味ではありません。探索の途中や未発見報告のために追加の生成・音声は呼び出しません。現在の対象は冒険家と紹介済みの建築士です。今後の人物も同じ頼み方を使う方針ですが、まだ登場していない人物を探せるわけではありません。

「止まって」で中断できます。終了・画面を隠す・返答の取消・ロードや本人切替の後に勝手に続行しません。もう一度頼むときは、上の例のように探索内容を明示してください。「うん」や丸の表示だけでは開始しません。探すことへの引受と、出会った後の依頼への参加やコンパスの受取は別の本人判断です。

## 自分たちで採集する

冒険家の依頼がなくても、声かけを受けたこの子の判断で採集に出かけられます。

| 採るもの | 入力例 | 条件 |
| --- | --- | --- |
| 木材 | 「あの森で木材を集めてきて」 | 見える実在の森に未採集分があり、往復できる |
| 石 | 「あの山で石を集めてきて」 | 見える実在の山に未採集分があり、往復できる |
| 花 | 「あの森で花を集めてきて」 | 森に未採集分があり、往復できる |
| 水 | 「あの森で水をくんできて」 | 空の水筒を持ち、対応する森・山に未採集分があり、往復できる |

「あの森」「あの山」が曖昧なら、先に丸で場所を相談してください。採集では本人の状態や他の行動中かどうかも確認され、お願いが必ず実行されるとは限りません。

自由採集は現地で二回探索し、元の場所へ戻ります。通常採集の現地待機は一回6秒です。既存の森の木材・花・水、山の石・水は、地点・品種ごとに実時間60分で1個、最大2個まで回復します。満杯の間に余分な回復を貯め込むことはありません。贈呈や納入そのものでは回復せず、古い現物IDや贈呈・納入履歴も消えません。水が回復していても空の水筒が必要です。旧セーブには導入前の不在成果を追加しません。

## 留守の間の採集と再開の挨拶

通常の声かけで頼み、この子が引き受けて保存に成功すると一件だけ予約できます。木材か石の一種類だけが対象です。

- 「留守の間、知っている森で木材を集めて」：依頼時に見えていて到達可能な森の範囲で、次の本編再開まで続けます。
- 「留守の間、知っている山で石を5個集めて」：指定の5個まで集め、出発点へ戻ります。
- 一地点だけなら、先に森／山を示して一致を確認し、「留守の間、この森で木材を集めて」のように頼みます。未知の道や採集地へは行きません。

一個の採集に現実10分、さらに実際の道の往復時間がかかります。一往復では採れる分を最大2個持ち帰り、依頼数量まで、指定がなければ次の本編再開まで繰り返します。全候補が枯れたら回復を待ちます。総計2個・一日・周回数・放置時間による固定上限はありません。所持品への追加は一個の採集完了時で、未帰還の取得品も本人のものです。

予約しただけでは始まりません。タイトル・本人切替・正常終了が離席の境界です。一時停止、日記・星座、入力待ち、一時的な非表示だけでは留守番に変わりません。突然終了した場合は最後に保存できた本編活動時刻を目安にします。移動・採集や冒険家の未完依頼・会話がある場合は、まずその行動を終えるか明示的に取り消してください。

「つづきから」で再開すると、移動途中の位置、採集途中の時間、既取得品を残して自動周回を止めます。「課題を見せて」で状態と取得総数を確認できます。「留守番採集を続けて」「留守番採集から戻って」は、その途中計画の続行／帰還を予約し、再び本編を離れてから進めます。「留守番採集を取り消して」は以後の作業を止め、位置と取得品を残します。通常の短時間採集へ勝手に切り替わることはありません。別の移動や通常採集を新しく明示して始める場合も、残っていた計画は取消として残ります。

最終の本編活動から5分以上離れた「つづきから」では、挨拶と実成果を合わせて一度だけ話します。留守中の生成・音声はありません。未依頼なら挨拶だけで、留守中の暮らしや交流を創作せず、不在で好感度・空腹・疲労を悪化させません。初めて基準を作る旧セーブでは不在時間を決めつけません。生成の失敗・取消でも確定済み素材は残り、自動再送はしません。実数は所持品と課題欄、後の質問で確認できます。

時計が逆戻りした間は追加の回復・取得を行いません。保存容量に達した場合は途中で安全に止まり、課題欄に未清算の期間を表示して保持します。本人試遊での実モデルの自然な引受・報告や実声質は、模擬検証とは別の確認対象です。

## 所持品・水筒・贈り物

最初の木材・石の採集依頼を実際に達成して帰還すると、冒険家から水筒を一つ受け取れます。既に達成済みのセーブでは、次の新しい実対面で受け取る形です。最初から持っているわけではありません。

水筒が空なら一回分の水をくめます。満水なら追加ではくめません。現在は水を飲む操作はありません。

冒険家との交流では、**この子自身が余剰の所持品から贈り物を選ぶ**ことがあります。贈らないこともあります。プレイヤーが品物を選んで強制的に渡す操作はありません。

- 一度の出会いで最大一個です。依頼に必要な分は確保します。
- 相手が受け取った場合だけ所持数が減り、断られた場合は残ります。
- 水を贈っても、水筒本体は空で残ります。
- 好みは、実際の贈り物と相手の反応から少しずつ受け取っていきます。

## 状況を表示する・閉じる

島の中の表示は、直接の開閉ボタンではなく、会話から開閉します。下の例は、疑問形にせず一つずつ伝えると確認しやすくなります。

| 表示 | 開く例 | 閉じる例 | 分かること |
| --- | --- | --- | --- |
| 所持品 | 「所持品を見せて」 | 「所持品をしまって」 | 木材・石・花・水の実所持数、水筒の空満 |
| 課題 | 「課題を見せて」 | 「課題をしまって」 | 冒険家の依頼と、建築士の二課題・納入途中／完了・預かり材 |
| 好感度 | 「好感度を見せて」 | 「好感度をしまって」 | 会った冒険家・建築士それぞれのハート、関係の説明、直近の変化理由 |

表示を開く・閉じるだけでは、参加、移動、再開、好感度の変化は起きません。自由採集や建築士への訪問が、課題欄の冒険家の依頼を置き換えるわけではありません。

人物や課題が欄に収まらない場合は、欄の中をスクロールすると続きや預かり数を確認できます。

## 冒険家と親しくなる・建築士を紹介してもらう

冒険家からこの子への好感度は、ハート0〜5で表されます。プレイヤーとこの子の関係とは別です。実際の会話や行動に応じて変わり、一度の出会いでの変化は最大一段階です。依頼を達成したり品物を渡したりすれば、必ず上がるという方式ではありません。

| ハート | 台詞の距離感の目安 |
| --- | --- |
| 0 | 慎重 |
| 1 | 丁寧 |
| 2 | 顔なじみ |
| 3 | 信頼 |
| 4 | 個人的な気遣い |
| 5 | 会うこと自体を喜ぶ |

これは固定台詞の切り替えではなく、実際の交流も踏まえた話し方の方針です。丁寧な辞退や中断、通信・保存の失敗だけで自動的に減点されることはありません。

**ハート3以上になった後の、次の新しい実対面**で、冒険家が一度だけ建築士を紹介します。後で好感度が下がっても、紹介済みの履歴は消えません。

紹介後は「近い順に森に歩いて行って、建築士さんがいたら教えて」とまとめて探してもらえます。一地点だけ訪ねる場合は、紹介された森を確認し、別の入力で「建築士さんに会いに、その森へ歩いて行って」と人物を名指ししてください。その森に建築士がいれば会話できます。

建築士は木を測量するため、森だけを移動しています。紹介された森は紹介時点の情報なので、既に移動している場合があります。会えた後は、下の二つの課題を引き受けられます。

## 建築士の二つの課題と材料預かり

建築士からこの子への好感度もハート0〜5、初期1です。以前会ったセーブも1から始まり、過去の会話を採点し直しません。一遭遇の変化は合計最大±1で、建築士が実際に聞いた返事と知っている行動をもとに評価します。課題完了だけで必ず加点されず、丁寧な辞退や中断だけで自動減点されることもありません。

ハート1から、対面で次の課題を順に一度ずつ提案されます。

1. **小屋の柱用の木材2個**
2. 木材の納入完了後、**基礎用の石2個**

引き受けるか、所持品を何個渡すかは、この子が自分で判断します。プレイヤーの「うん」や素材名だけで受諾・納入はしません。以前集めた木材・石も使え、手元にあれば引受と納入の両方を本人が決めて同じ対面で渡せます。引受だけにして改めて訪ねたときに納入してもよく、一個ずつの分割納入もできます。必要数を超えて渡しません。引受済みの課題や納入分は、好感度が下がっても残ります。

引受後に自動で採集へは出かけません。例えば「あの森で木材を集めてきて」と頼み、素材を持ったら「近い順に森に歩いて行って、建築士さんがいたら教えて」と再訪を相談してください。既に必要な素材を持っていれば、新しく集める必要はありません。再起動や表示の開閉だけでは、移動・納入・途中の会話は再開しません。

納入した素材は手元から減り、**この子専用の建築預かり材**になります。「課題を見せて」で二課題の進行と、預かり木材・石の数を確認できます。「好感度を見せて」では建築士のハートも確認できます。冒険家の依頼・今回採った数とは別に表示します。

預かり材は家の総費用へ全数充当するための保存です。二課題完了とハート3の条件を満たした後は、下の「マイホームを建てる」へ進めます。納入で技能や語彙、実績を自動取得することはありません。返答や保存の失敗時には、所持品と課題の保存済み状態を確認してください。既に確定した納入を繰り返し消費しません。

## 人物の移動と日時・季節

冒険家は森・山、建築士は森の間を、現実時間で約30分ごとに移ります。候補がなければ留まります。会話で滞在時間を延長する仕組みではなく、会話中に期限を過ぎると、会話を閉じた後に移動します。受諾済みの冒険家の採集依頼では、報告先を保持します。

「日時と季節」から時刻の基準と半球を変更できます。初期は端末のタイムゾーンに合わせ、季節はブラジルポルトガル語では南半球、他の対応言語では北半球に合わせます。季節が変わっただけで、資源が復活したり季節素材が生まれたりすることはありません。

## 旅人の通信コンパス

受け取ったコンパスは、所持品欄に真鍮色の丸い本体と赤青の針の絵、品名、数量「× 1」で表示されます。「所持品を見せて」と頼んで確認できます。

初めからは持っていません。冒険家の最初の木材／石の依頼で二個を集め、実際に帰還すると、安全のため予備を譲る提案を受けられます。この子が受け取ると決めた場合にだけ、一つ所持し、冒険家と連絡先を交換します。既に依頼を達成したセーブでは、次に冒険家と実際に会ったときに提案されます。起動だけでは増えません。

帰還時の最後の返事で提案された場合は、まだその場にいる間に「コンパスを受け取って」と相談できます。受け取るかを決めるのはこの子です。辞退しても、後の対面で交換できます。建築士の連絡先は、コンパスを持ってから本人と実際に会い、双方が交換したときに加わります。紹介を聞いただけでは登録されません。

- 「コンパスで冒険家に連絡して、今いる場所を聞いてみて」
- 「コンパスで建築士に連絡して、そこで待ち合わせできるか聞いてみて」

この子が使うと決めたら、一人に連絡し、相手の返事とこの子の応答が続きます。会話欄に受信した場所・時刻が残ります。所在地を聞くだけでは、その人の待機も、この子の出発も始まりません。

双方が待ち合わせに同意すると、成立から**現実の10分間**だけ相手がその場所に留まります。期限は会話欄に表示されます。再起動しても延長されず、期限後は通常の巡回へ戻ります。古い返事の場所を、今もいる保証として使わないでください。

「受信した場所に丸をつけて」と頼み、場所の一致を伝えた後、**別の入力**で「その森へ歩いて行って」と頼みます。建築士に会いに行く場合は「建築士さんに会いに、その森へ歩いて行って」と人物も明示します。画面外の実地点も確認でき、確認表示中だけその地点へ画面が寄ります。丸・肯定・通信・待ち合わせ成立だけでは歩きません。人物の姿はフィールドには表示されません。

途中で中止した通信は、自動再送／自動再開しません。保存できた受信は残りますが、双方の同意まで済んでいない待ち合わせは成立しません。

## 声・言語・記録を読む

- **この子の声**：声を選び、「声をきく」で試聴し、「この声にする」で決められます。「声をつくる」では特徴の選択と任意の短い説明で声を作れます。読み上げのON/OFFも変更できます。
- **冒険家の声**：冒険家に会った後、本人とは別に声を設定できます。建築士には独立した標準声がありますが、現在、建築士専用の声選び画面はありません。
- **言語**：日本語、英語、簡体字中国語、ロシア語、スペイン語、ブラジルポルトガル語、ドイツ語に対応しています。既に保存した本人の発言やプレイヤーが付けた名前は、後から言語を切り替えても書き換えません。
- **日記**：見えた場所・歩いた結果や、教えたこと／訂正の受け取りを読み返せます。「会話の原文を見る」で元の発言も確認できます。
- **星座**：星を選ぶと、言葉の原発言や実体験の根拠を確認できます。星があることは、その言葉や技能を習得済みという認定ではありません。

声の接続・設定の詳しい手順は[音声の操作資料](NATIVE_VOICE.md)にあります。同資料の古い会話手順より、現在の出会い・依頼の操作はこの説明書を優先してください。

## 止まった・うまく進まないとき

| 状況 | 確認すること |
| --- | --- |
| 丸を付けたのに歩かない | 対象の一致を伝えた後、別の入力で歩くよう頼んでください。 |
| 探索が途中で止まっている | 入力欄に書きかけがないか、一時停止中や日記・星座の閲覧中でないか確認し、必要なら具体的に探索の再開を頼んでください。画面の「再開」だけで中断した依頼への再参加はしません。 |
| 冒険家や建築士に会えない | その場所に今もいるとは限りません。人物名を指定して近い順の一括探索を頼めます。建築士は紹介後の森が対象です。コンパスを所持し、連絡先を交換済みなら、所在や待ち合わせも相談できます。古い返事と期限を確認してください。 |
| 同じ場所で採れない | 採り尽くしている可能性があります。別の実在する採集地を相談してください。 |
| 声が出ない | 読み上げ設定を確認してください。音声に失敗しても、保存できた文字の返答は残ります。 |
| 返答や最後の報告で失敗表示が出た | 既に取得した品物や実行結果と、返事の成功は別です。失敗した会話は自動再送されません。繰り返し操作する前に、所持品・課題の実状態を確認してください。 |
| 保存できないという表示が出た | 進行を続けず、終了して保存先の状態を確認してください。セーブを消したり、「はじめから」で修復しようとしたりしないでください。 |

「一時停止」は画面進行を休める操作、「止まって」は歩行停止、「中止」は生成中の返答の取消です。人物の巡回は現実時間を基準にしているため、画面を止めても同じ場所に居続ける保証にはなりません。

## マイホームを建てる

建築士の二課題が完了し、建築士のハートが3以上になると建築相談ができます。一度得た資格や、建てた家は、その後ハートが下がっても失いません。「課題を見せて」で条件と進行を確認できます。

留守番採集の途中など、別の作業が残っている場合は、終了または明示取消を先に行います。例えば「留守番採集を取り消して」と頼み、課題欄で状態を確認してください。取得済みの品物は残ります。

1. 「近い順に森に歩いて行って、建築士さんがいたら教えて」などで会いに行きます。資格があれば建築士から小さな家の話を持ちかけ、この子が自分で相談に応じるか決めます。材料不足でも相談できます。この時点では材料を使いません。
2. この子が家の相談に応じたら、「家を建てる場所に丸をつけて」と頼みます。近くの実在する空き地を提案します。道や資源を消さずに建てられる場所がなければ保留です。別の場所へ実際に歩いてから相談できます。
3. 場所がよければ「うん」と確認します。これだけでは着工しません。不足分があれば採集を頼んでそろえます。場所を変更するときは「家の建築を取り消して」から相談し直します。
4. 建築士にもう一度会いに行きます。確認した場所と実際の材料について建築士が提案し、この子が費用と工事を自分で了承した場合に、保存できたときだけ素材を使って着工します。別途「ここに家を建てて」と頼む必要はありません。断った場合や判断・保存に失敗した場合は着工しません。移動や採集は引き続き明示的な依頼が必要です。
5. 工期は実時間10分です。タイトルや正常終了を挟んでも進み、再開時に完了を確認できます。留守中や完成時に工事用の自動生成・音声は追加しません。
6. 完成後は「家に入って」と頼むと、通れる実経路を歩いて玄関から入ります。室内には床・壁・入口・寝床があり、滞在できます。「家から出て」「外に出て」で室内の入口まで歩き、暗転を挟んで外へ戻ります。「止まって」で途中停止できます。入場への移動や退出の途中で本編を離れた場合、再開後に改めて入場・退出を頼んでください。

家は小さな木の小屋一軒です。**総費用は木材8個＋石4個。課題で預けた木材2個＋石2個を全数充当するので、追加で渡すのは木材6個＋石2個です。** 所持品から追加材料だけを使い、元の納入履歴と現物の記録を残します。不足数は課題欄で確認できます。お金や免許は要求しません。

室内では「家の外にでてくれる？」「一旦家の外にでてほしいんだけど、できる？」という丁寧な退出依頼も使えます。この子が引き受け、保存に成功した場合だけ入口へ歩きます。「外に出られる？」という可否質問、否定、引用した台詞、「うん」だけでは退出しません。既に退出中なら新しい退出は重ねません。

外観と屋内の床・壁・ベッドは、旧版で使っていた画像です。屋外ではキャラクターが家より手前に表示され、屋内では旧版の上下左右の向きを持つ姿になります。屋内は入口とベッドのある最小構成です。「家の中には何が見える？」と聞くと、実在するベッド・入口・床・壁の情報をもとに答えます。ベッドで休む機能は、まだ使えません。更新後にアプリを再起動すると、既に建てた家にも適用されます。

家・山・森へ実際に入る時は、フィールドの姿が縮小して暗転し、外へ戻る時は暗転明けに拡大します。再会では既存の挨拶を入場演出と並行して準備するため、会話開始までの待ちを一部重ねられます。会話や音声を追加で生成する仕組みではなく、初対面動画は従来どおりです。一時停止や日記閲覧中は演出も止まり、タイトルや再起動では演出を繰り返しません。

着工前の計画取消では材料を失いません。**着工後の取消・移築はできません。** 睡眠による回復、収納、コンシェルジュ、家具編集、増築、自力建築はまだ利用できません。生成・保存の失敗時は、再指示の前に課題欄と所持品の実状態を確認してください。

## まだできないこと

- 留守番での花・水の採集、未確認地点への自動探索。
- 家での睡眠回復・収納・家具編集・コンシェルジュ、増築・移築・自力建築。
- 水を飲む、売買、戦闘、旧版の職業・技能報酬や免許皆伝。
- 見えているレストランなどへの入店や食事。旧版にある機能が、この新方式でも使えるとは限りません。

実装済み機能についても、生成される台詞の自然さや声質は、模擬検証と本人の試遊を区別しています。
