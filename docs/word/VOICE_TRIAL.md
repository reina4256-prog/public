# PC内VOICEVOXで声の演出を試す

今回は日本語の会話をPC内で生成し、ゲームで種族に合う響きを加える試作です。Windowsの開発起動では導入済みVOICEVOXも同時起動できます。ゲームに音声エンジンやモデルを同梱していません。しぐさは従来の端末の別声で読みます。

## コマンド1つでゲームと起動する（Windowsの開発環境）

展開したエンジン一式を `game/voicevox_engine/` に置き、その中に `run.exe`・`model`・DLL等がある状態にします。ゲームのソースは隣の `game/public/` です。エンジンはGit管理へ追加しません。

`public` で従来どおり `npm run start:word` を実行してください（`start:words` も同じです）。ゲームを開くのと並行して `run.exe --host 127.0.0.1 --port 50021` をバックグラウンドで起動します。接続先の許可設定は変更しません。エンジン初期化には少し時間がかかるため、接続できなければ数秒待ってゲームの接続ボタンを押してください。独立起動のエンジンログはゲームの端末へ流しません。

すでに標準ポートで起動中なら再利用し、二重起動しません。2026-11-11終了障害への修正後は、ゲームを閉じてもVOICEVOXを残し、次回そのまま再利用します。ゲームからエンジンや他のアプリを強制終了しません。エンジンが見つからない・起動に失敗した場合もゲームは開き、端末に状態を表示します。

この自動起動は開発用Electron起動の機能です。公開Webページ・`start:web:words`・パッケージ版では別途起動してください。音声で文字を入力する機能はVOICEVOXとは別です。[デスクトップ音声入力](VOICE_INPUT.md)を参照してください。

## 始め方

1. [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/)からWindows版を導入し、上記コマンドまたは手動で起動します。[利用規約](https://voicevox.hiroshiba.jp/term/)と、使用する各音声ライブラリの利用条件を確認してください。
2. ゲームの「音声の設定」→「この子の声を選ぶ」を開きます。新しく始める場合は設問後の姿の横に同じ設定があります。
3. 「声を作る方法」を「PC内のVOICEVOX（演出付き）」に変更し、「VOICEVOXに接続・声を更新」を押します。標準の接続先は `http://127.0.0.1:50021` です。設定を開いただけでは接続しません。
4. 会話の声を選び、セリフのボタンで試聴します。「この子らしい響きの強さ」で調整できます。0で演出なし、高さ／速さも従来どおり調整できます。
5. 実際の返答にも適用したいときは、会話欄の「返答を読み上げる」をオンにします。試聴だけではオンになりません。

## 接続できない場合

- VOICEVOXが起動中か、`http://127.0.0.1:50021/docs`を同じPCのブラウザーで確認してください。これが開かない場合はゲームより先にエンジン側の起動／ポートを確認します。ポート変更や別PCへの接続は今回のUIに含みません。
- 公開ページの接続元は `https://reina4256-prog.github.io` です。VOICEVOX側の許可originへこの接続元を追加する必要があります。URLの`/public/`やファイル名は含めません。設定欄にも現在の接続元を表示します。ブラウザーからローカルネットワークへの接続許可を求められた場合も確認してください。
- エンジンを直接起動する場合の例は `run.exe --host 127.0.0.1 --port 50021 --allow_origin https://reina4256-prog.github.io` です。配布版によって実行ファイル名や設定方法は異なるため、[公式Engine README](https://github.com/VOICEVOX/voicevox_engine#readme)のCORS設定と、その配布版の起動オプションを確認してください。ゲームからエンジンの接続許可を変更したり、全サイトの許可やLANへの公開は行いません。
- PC内の開発用ページ（localhost／127.0.0.1）からはVOICEVOXの既定の許可対象で試せます。公開HTTPSページからの許可／ブラウザー動作は環境依存です。
- VOICEVOX方式は日本語だけです。他の言語では「端末の声」を使ってください。しぐさ用に、ブラウザーから使える現在言語の端末音声が1つ以上必要です。
- エラー時も文字の会話とゲームは継続できます。別の声や外部サービスへ自動で切り替えません。

## 戻す場合と将来の②

「声を作る方法」を「端末の声」に戻すと、従来方式を使えます。VOICEVOXの声の選択と演出強度は残ります。再読込後にVOICEVOXへ戻した場合は、接続ボタンを押してください。

将来②の外部音声サービスを追加した後も、①のVOICEVOXを削除せず切替候補として残す設計です。声の選択は生成元ごとに保存するため、②を試した後に①の選択へ戻せます。演出は共通ですが、元の声が異なるので同じ設定でも聞こえ方は変わります。声やモデルが提供終了・削除された場合は再選択が必要です。

②のサービス・課金・サーバーは今回未実装です。PC内のVOICEVOXへ渡すのは試聴／読み上げる文章だけで、学習記録全体やノートは渡しません。生成した音声データは保存せず再生に使います。実装の所有は[音声所有仕様](../specs/core/word_constellation_and_voice.md)を参照してください。
