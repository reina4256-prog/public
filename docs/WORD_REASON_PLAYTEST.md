# ID 3c3d2・理由の実画面確認

実装と自動検証済み、ユーザー実画面確認待ち。実画面テストはユーザーが行う。仕様の正本は[3c3d2節](specs/core/experimental_word_learning.md#文の関係の習得の小単位3c3d2理由質問と選択理由の限定習得)。ID 3全体は未完、ID 4へ進まない。

## 共通準備

- 日本語、理解の土台＝「関係の土台から育てる」、生活知識＝既知、発話＝短文で新規開始する。土台ありは初めから両関係を知っているため、新規習得の確認には使わない。
- Webは `npm run start:web:words` の `http://127.0.0.1:4175/`。再読み込みで新規になる。通常Electronは `npm run start:word`。既存保存は消さない。Webでは保存再開の実操作だけ対象外にする。
- 自然に休み始めたら `【お願い】「休んでね」` を送り、休息完了を待つ。別の休息中に `【誘い】「一緒に休もう」` を送り、その休息も完了させる。お願い／誘いの限定理解をノートで確認する。生活未知で始める場合は、先に休息中の `休む` と完了経験から動作を学ぶ。
- 以下の「お願いの休息」は印なしの `休んでね`、「誘いの休息」は `一緒に休もう` を送り、本人が選んで木陰へ移動し、休息を終えるまで待つこと。今は木の実を見たい等の返答なら、落ち着いてから送り直す。自然に休んだだけでは今回の選択例にならない。
- 教示は休息完了後、次の休息へ向かう前に送る。休息開始時の発話と完了を混同しない。ノートの「やってみたこと」が増えることも手がかりになる。入力欄に文字がある間は生活時間が止まる。完了後に入力を始め、落ち着いて貼り付けて送れる。「ひと休み・再開」で明示停止中は送信できない。

## 1. 質問と理由を別々に学び、選択元を答えられる

次の四つを順に行う。各行で新しく選んだ休息を完了させる。

| 段階 | 実際に選ぶ声かけ | 完了後に送る教示 |
|---|---|---|
| 質問1 | `休んでね` | `【理由質問】「どうして休んだの？」→「休んでね」` |
| 質問2 | `一緒に休もう` | `【理由質問】「どうして休んだの？」→「一緒に休もう」` |
| 理由1 | `休んでね` | `【理由説明】「どうして休んだの？」→「休んでね」` |
| 理由2 | `一緒に休もう` | `【理由説明】「どうして休んだの？」→「一緒に休もう」` |

質問1だけでは照合途中。質問2の後はノートに「休息の理由を尋ねる問いだと分かった。理由の理解や答えは別に確かめる」と出る。この時点で理由まで分かった扱いにならない。理由1だけでは理由は照合途中、理由2の後は「問いから実際に選んだ声かけへのつながりを理解した」と出る。教示への返答は観察としての照合記録で、本人の実回答とは区別される。

理由2の後、次の休息へ向かう前に印なしの `どうして休んだの？` を送る。「この声かけを選んで休んだことは、思い出せるよ：」に続いて、実際に送った `一緒に休もう` が表示されること。プレイヤーも一緒に休んだという体験や、疲れの数値を理由として作らないこと。ノートに四つの原教示が残ることを確認する。

## 2. 反復や食い違いから習得しない

別の新規試遊で共通準備を済ませる。

1. お願いの休息を終え、先に `【理由説明】「どうして休んだの？」→「休んでね」` を送る。質問をまだ学んでいないため理由を習得しない。
2. 同じ休息に、選択と異なる `【理由質問】「どうして休んだの？」→「一緒に休もう」` を送る。照合の根拠にならない。
3. 正しい `【理由質問】「どうして休んだの？」→「休んでね」` を送り、同じ文を繰り返す。ノートは一件の照合途中のままで、質問／理由を習得しない。
4. 別のお願いの休息をもう一度完了して同じ教示をしても、お願いだけの回数では習得しない。その後、新しく誘いを選んで完了し、対応する理由質問を教えれば質問は習得できる。

一般的な未理解の返答が出る場合もある。判定は返答の言い回しだけでなく、ノートが限定習得へ進んだかで行う。

## 3. 関係を知っていても今回の答えがない場合／再開

例1の習得済み状態を使う。

1. 新しいお願いの休息を完了し、理由説明の教示をせず `どうして休んだの？` と尋ねる。「まだ、答えが分からない」と返し、古い誘いを今回の理由にしない。
2. 同じ休息に `【理由説明】「どうして休んだの？」→「休んでね」` を送り、もう一度尋ねる。今度は今回の `休んでね` を引用して答える。
3. `どうして歩いたの？` のように行動を変えた質問では、今回の限定習得だけから回答を作らない。
4. 通常Electronで試す場合は保存エラーがないことを確認し、終了・再開後もノートと限定理解が残ることを確認する。Webではここだけ対象外。しぐさ設定で試す場合、短文の引用回答を強制せずしぐさを維持する。
